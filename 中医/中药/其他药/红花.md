# 红花

[TOC]

## 概述

红花为菊科植物红花 *Carthamus tinctorius* L. 的干燥管状花。主产于河南、新疆、四川、浙江等地。夏季花由黄变红时采摘，阴干或晒干。

> 注意与**藏红花（西红花）**区分——两者是完全不同的药物。红花价格较低廉，活血化瘀用途广泛；藏红花极昂贵，兼有凉血解毒、解郁安神之功。

## 性味归经

- **性味**：辛、温
- **归经**：心、肝

## 功效

| 功效 | 应用 |
|------|------|
| **活血通经** | 血瘀经闭、痛经、产后恶露不下 |
| **散瘀止痛** | 跌打损伤、瘀血肿痛 |
| **活血消斑**（外用） | 瘀斑、紫癜 |

## 使用注意

| 注意 | 说明 |
|------|------|
| 用量 | 煎服 3 ~ 10 g |
| 孕妇 | **禁用**（兴奋子宫平滑肌，可致流产） |
| 出血倾向 | 月经过多者、有出血性疾病者慎用 |

## 现代研究

| 成分 | 作用 |
|------|------|
| 红花黄色素 (Safflower Yellow) | 抗血小板聚集、改善微循环 |
| 红花苷 | 抗凝血、轻度扩张血管 |
| 羟基红花黄色素 A (HSYA) | 保护心肌（缺血再灌注损伤防护） |

主要药理：① 抗血小板聚集/抗凝血；② 扩张冠状动脉/改善心肌供血；③ 降血脂；④ 抗氧化。

> 红花注射液曾是中国临床上心脑血管疾病常用中药注射剂之一（因不良反应报道近年使用趋谨慎）。

## 常用方剂

| 方剂 | 功效 | 红花的作用 |
|------|------|-----------|
| 血府逐瘀汤 | 活血化瘀、行气止痛 | 与桃仁为活血祛瘀对药 |
| 桃红四物汤 | 四物汤+桃仁+红花 | 养血活血（妇科调经基础方） |
| 复元活血汤 | 活血祛瘀、疏肝通络 | 跌打损伤瘀血肿痛 |
