# 铁皮石斛

[TOC]

## 概述

铁皮石斛为兰科植物铁皮石斛 *Dendrobium officinale* Kimura et Migo 的干燥茎。主产于云南、浙江、安徽、广西等地。11 月至翌年 3 月采收。

铁皮石斛是石斛中的上品，因茎表皮呈铁绿色而得名。加工后呈螺旋状或弹簧状，称"铁皮枫斗"或"耳环石斛"。

> 唐代《道藏》将铁皮石斛与天山雪莲、三两重人参、百二十年首乌、花甲之茯苓、深山野灵芝、海底珍珠、冬虫夏草、苁蓉并称"中华九大仙草"。

## 性味归经

- **性味**：甘、微寒
- **归经**：胃、肾

## 功效

| 功效 | 应用 |
|------|------|
| **益胃生津** | 胃阴不足、热病伤津——口干烦渴、食少干呕、病后虚热 |
| **滋阴清热** | 肾阴亏虚——目暗不明、筋骨痿软、阴虚火旺 |

## 使用注意

| 注意 | 说明 |
|------|------|
| 用量 | 煎服 6 ~ 12 g，鲜品 15 ~ 30 g |
| 禁忌 | 温热病初起（有表邪）、湿温尚未化燥者忌用 |
| 煎煮 | 宜久煎（有效成分不易溶出） |

## 现代研究

铁皮石斛的主要活性成分：

| 成分 | 作用 |
|------|------|
| 石斛多糖 | 增强免疫、抗氧化、抗疲劳 |
| 石斛碱 (Dendrobine) | 退热、止痛 |
| 联苄类化合物 | 抗肿瘤活性 |
| 毛兰素 | 抗血管生成 |

主要药理作用：① 促进唾液分泌（缓解口干）；② 增强免疫；③ 抗氧化、延缓衰老；④ 改善胃粘膜屏障。

## 品质鉴别

| 指标 | 优质特征 |
|------|---------|
| 品种 | 铁皮石斛 > 金钗石斛 > 鼓槌石斛 |
| 外观 | 茎短而壮实、节间短、嚼之黏性足（多糖含量高） |
| 渣少 | 嚼后渣滓越少品质越好——纤维化程度低 |
| 加工 | 铁皮枫斗（螺旋状）利于保存和运输 |

> 市场混乱，常见用金钗石斛、鼓槌石斛等冒充铁皮石斛。铁皮石斛价格远高于普通石斛，近几年人工栽培技术（组培苗+大棚/仿野生）发展迅速，价格趋于理性。
