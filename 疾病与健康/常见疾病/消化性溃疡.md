# 消化性溃疡与胃炎

## 一、消化性溃疡

### 1.1 概述

消化性溃疡 (Peptic Ulcer) 是胃或十二指肠黏膜被胃酸和胃蛋白酶自身消化而形成的慢性溃疡。

> 两大核心因素：**幽门螺杆菌 (Hp) 感染** + **非甾体抗炎药 (NSAIDs)** 使用。

### 1.2 病因与发病机制

```
黏膜防御与攻击因子失衡

攻击因子增强                防御因子减弱
        │                        │
        ├─ 胃酸和胃蛋白酶          ├─ 黏液-碳酸氢盐屏障
        ├─ Hp 感染（70% GU、90% DU） ├─ 黏膜血流
        ├─ NSAIDs、阿司匹林         ├─ 前列腺素
        ├─ 吸烟、饮酒              ├─ 上皮再生能力
        └─ 精神应激               └─ 十二指肠反馈抑制

        → 失衡 → 溃疡形成
```

### 1.3 胃溃疡 vs 十二指肠溃疡

| | 胃溃疡 (GU) | 十二指肠溃疡 (DU) |
|:---|------|------|
| 占比 | ~25% | ~75% |
| 好发部位 | 胃角/胃窦 | 十二指肠球部 |
| 疼痛节律 | 餐后 0.5~1h 痛 → 下餐前缓解 | 空腹/夜间痛 → 进食缓解 |
| 胃酸 | 正常或偏低 | 偏高 |
| 恶变可能 | **有（< 1%）** | 无 |
| 典型描述 | "餐后痛" | "饥饿痛" |

### 1.4 临床表现

```
消化性溃疡症状
        │
        ├─ 上腹痛（最典型）
        │   ├─ 慢性过程：反复发作数年至数十年
        │   ├─ 周期性发作：秋冬季多发
        │   └─ 节律性疼痛
        │
        ├─ 伴随症状：反酸、嗳气、恶心
        └─ 体征：剑突下或偏右局限性压痛
```

### 1.5 并发症

| 并发症 | 表现 | 紧急程度 |
|--------|------|:---:|
| **上消化道出血** | 呕血（咖啡渣样）+ 黑便（柏油样） | 🔴急症 |
| **穿孔** | 突发的剧烈腹痛，板状腹 | 🔴急症手术 |
| **幽门梗阻** | 反复呕吐宿食、胃振水音 | 🟡需处理 |
| **癌变** | 疼痛节律改变、消瘦（仅 GU） | 🟡警惕 |

### 1.6 诊断

| 方法 | 用途 |
|------|------|
| **胃镜 + 活检** | 诊断金标准——确认溃疡、排除恶性、取 Hp 检测 |
| ¹³C/¹⁴C 尿素呼气试验 | 无创检测 Hp（首选的复查方式） |
| 粪便 Hp 抗原检测 | 替代呼气试验 |
| 血清 Hp 抗体 | 不能区分现症与既往感染 |
| X 线钡餐 | 已少用（渐被胃镜取代） |

### 1.7 治疗

```
消化性溃疡治疗策略
        │
        ├─ 抑制胃酸
        │   ├─ PPI（质子泵抑制剂）：奥美拉唑、泮托拉唑（基础用药 4~8 周）
        │   └─ H2 受体拮抗剂：法莫替丁（PPI 替代）
        │
        ├─ 根除 Hp（四联疗法 × 14 天）
        │   ├─ PPI + 铋剂 + 阿莫西林 + 克拉霉素
        │   └─ 或 PPI + 铋剂 + 甲硝唑 + 四环素
        │
        ├─ 保护胃黏膜
        │   ├─ 铋剂：枸橼酸铋钾
        │   └─ 硫糖铝、米索前列醇
        │
        └─ 停用 NSAIDs/阿司匹林（如可能）
```

> 根除 Hp 是预防溃疡复发的关键——根除后年复发率从 60~80% 降至 < 5%。

## 二、胃炎

### 2.1 急性胃炎

```
急性胃炎
        │
        ├─ 病因：NSAIDs、酒精、应激、感染
        ├─ 病理：黏膜充血水肿 → 糜烂 → 出血
        ├─ 症状：上腹不适、恶心呕吐、黑便（出血时）
        └─ 治疗：去除诱因 + PPI 抑酸 + 黏膜保护剂
```

### 2.2 慢性胃炎

| 类型 | 病因 | 病理特点 |
|------|------|---------|
| **慢性浅表性胃炎** | Hp 感染、饮食不当 | 炎症限于黏膜浅层 |
| **慢性萎缩性胃炎** | Hp 持续感染 + 自身免疫 | 固有腺体萎缩、肠上皮化生 |
| **特殊类型** | 胆汁反流、嗜酸性粒细胞 | 各有特点 |

### 2.3 慢性萎缩性胃炎与癌变风险

```
Correa 级联反应（Hp → 胃癌的演化路径）
        │
  正常胃黏膜
       ↓
  Hp 感染 → 慢性浅表性胃炎
       ↓
  慢性萎缩性胃炎
       ↓
  肠上皮化生 ← 癌前病变开始
       ↓
  异型增生（低级别 → 高级别）
       ↓
  胃癌
```

> 萎缩性胃炎合并肠化生者建议每 1~3 年复查胃镜。

## 三、功能性消化不良

功能性消化不良是指无器质性病变的上腹不适综合征。

| 亚型 | 主要症状 |
|:---|------|
| 上腹痛综合征 (EPS) | 上腹痛、灼烧感 |
| 餐后不适综合征 (PDS) | 早饱、餐后饱胀 |

治疗：促动力药（莫沙必利）+ PPI ± 根除 Hp。
