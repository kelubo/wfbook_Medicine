# 饮食养生

## 概述

饮食养生又称食疗，是在中医理论指导下，利用食物的性味偏性来调整机体阴阳平衡、防治疾病的方法。中医素有"药食同源"之说。

> 《素问·脏气法时论》："五谷为养，五果为助，五畜为益，五菜为充，气味合而服之，以补精益气。"

---

## 一、饮食养生的基本原则

### 1.1 四大原则

```
饮食养生原则
        │
        ├─ 饮食有节：不过饥不过饱，定时定量
        │   └─ "早饭宜好，午饭宜饱，晚饭宜少"
        │
        ├─ 五味调和：酸苦甘辛咸各有所入、各有所伤
        │   ├─ 酸入肝——过食伤脾（肉消而唇揭）
        │   ├─ 苦入心——过食伤肺（皮槁而毛拔）
        │   ├─ 甘入脾——过食伤肾（骨痛而发落）
        │   ├─ 辛入肺——过食伤肝（筋急而爪枯）
        │   └─ 咸入肾——过食伤心（脉凝涩而变色）
        │
        ├─ 辨证进食：根据体质和季节调整
        │   └─ 阳虚畏寒→温补；阴虚内热→养阴清热
        │
        └─ 食不过杂、不偏嗜
            └─ 每种食物各有偏性，过犹不及
```

## 二、食物的性味

### 2.1 四性（四气）

| 性 | 作用 | 代表食物 |
|:---|------|------|
| 寒 | 清热泻火、凉血解毒 | 苦瓜、西瓜、绿豆、莲藕 |
| 凉 | 清热养阴——较寒性缓和 | 梨、冬瓜、鸭肉 |
| 温 | 温中散寒、助阳 | 姜、大枣、羊肉、核桃 |
| 热 | 温阳散寒——较温性更强 | 辣椒、胡椒、肉桂 |

> 平性食物：不寒不热，适合大多数人——粳米、山药、土豆、鸡蛋。

### 2.2 五味

| 味 | 归经 | 作用 | 代表食物 | 过食之伤 |
|:---|:---|------|------|------|
| 酸 | 肝 | 收敛、固涩 | 醋、山楂、柠檬 | 伤脾——肌肉萎缩 |
| 苦 | 心 | 清热、燥湿、降泄 | 苦瓜、莲子心、黄连 | 伤肺——皮肤干枯 |
| 甘 | 脾 | 补益、和中、缓急 | 大枣、蜂蜜、甘草、粳米 | 伤肾——骨痛脱发 |
| 辛 | 肺 | 发散、行气、活血 | 姜、葱、蒜、辣椒 | 伤肝——筋脉挛急 |
| 咸 | 肾 | 软坚散结、润下 | 海带、盐、牡蛎 | 伤心——血脉凝涩 |

## 三、体质与饮食

### 3.1 九种体质的饮食调养

| 体质 | 饮食原则 | 宜食 | 慎食/忌食 |
|:---|------|------|------|
| 平和质 | 均衡即可 | 多样化 | 无需特别禁忌 |
| **气虚质** | 益气健脾 | 小米、山药、大枣、鸡肉 | 生冷、萝卜（破气） |
| **阳虚质** | 温阳补肾 | 羊肉、核桃、韭菜、桂圆 | 寒凉食物——西瓜、苦瓜 |
| **阴虚质** | 滋阴清热 | 银耳、百合、鸭肉、梨 | 辛辣——辣椒、羊肉 |
| **痰湿质** | 健脾化湿 | 薏苡仁、赤小豆、冬瓜 | 肥甘厚腻 |
| **湿热质** | 清热利湿 | 绿豆、苦瓜、薏苡仁 | 辛辣、酒、油腻 |
| **血瘀质** | 活血化瘀 | 山楂、醋、黑木耳、红酒（少量） | 过寒——寒主收引 |
| **气郁质** | 疏肝理气 | 玫瑰花茶、佛手、柑橘 | 肥腻、黏滞 |
| **特禀质** | 避免过敏原 | 清淡、平性食物 | 自己过敏的食物 |

## 四、常见食疗方

### 4.1 补气类

| 食疗方 | 材料 | 适用 |
|:---|:---|:---|
| 四君子粥 | 党参、白术、茯苓、炙甘草 → 煎汤煮粥 | 脾胃气虚——乏力、食欲不振 |
| 黄芪炖鸡汤 | 黄芪 + 老母鸡 | 气虚——易感冒、乏力 |
| 大枣桂圆茶 | 红枣 + 桂圆 + 红糖 | 气血两虚 |

### 4.2 补血类

| 食疗方 | 材料 | 适用 |
|:---|:---|:---|
| 四物汤炖排骨 | 当归、熟地、白芍、川芎 + 排骨 | 血虚——面色苍白、月经量少 |
| 枸杞红枣乌鸡汤 | 枸杞 + 红枣 + 乌鸡 | 滋阴补血 |
| 黑芝麻糊 | 黑芝麻 + 糯米 | 补肝肾、益精血 |

### 4.3 祛湿类

| 食疗方 | 材料 | 适用 |
|:---|:---|:---|
| 赤小豆薏仁汤 | 赤小豆 + 薏苡仁 | 湿热——水肿、小便不利 |
| 茯苓山药粥 | 茯苓 + 山药 + 粳米 | 脾虚湿盛 |
| 陈皮生姜茶 | 陈皮 + 生姜 | 寒湿——腹胀、恶心 |

### 4.4 润燥类

| 食疗方 | 材料 | 适用 |
|:---|:---|:---|
| 冰糖雪梨 | 雪梨 + 冰糖 + 川贝母 | 肺燥咳嗽——干咳少痰 |
| 银耳百合羹 | 银耳 + 百合 + 冰糖 | 肺胃阴亏——口干、皮肤干燥 |
| 蜂蜜柠檬水 | 蜂蜜 + 柠檬 | 润燥、生津 |

### 4.5 温阳类

| 食疗方 | 材料 | 适用 |
|:---|:---|:---|
| 当归生姜羊肉汤 | 当归 + 生姜 + 羊肉 | 虚寒——畏寒肢冷 |
| 核桃仁炒韭菜 | 核桃 + 韭菜 | 肾阳不足——腰膝酸冷 |
| 桂圆红糖姜茶 | 桂圆 + 红糖 + 生姜 | 寒性痛经 |

## 五、饮食禁忌

### 5.1 常见配伍禁忌

| 搭配 | 原因 |
|:---|:---|
| 柿子 + 螃蟹 | 寒上加寒，柿中鞣酸与蟹中蛋白质形成不易消化物 |
| 韭菜 + 蜂蜜 | 性味相反——易致泄泻 |
| 羊肉 + 西瓜 | 伤阳气 |
| 萝卜 + 人参 | 萝卜破气，人参补气——相互抵消 |
| 白酒 + 胡萝卜 | 肝中产生毒素 |

### 5.2 不同时段的饮食宜忌

| 时段 | 原则 |
|:---|:---|
| 早晨 | 吃好——温热、易消化、营养丰富 |
| 中午 | 吃饱——保证充足能量（一天的主餐） |
| 晚上 | 吃少——清淡、少量、早吃（睡前 2~3h 停止进食） |

### 5.3 特殊时期的饮食

| 时期 | 要点 |
|:---|------|
| 孕期 | 营养均衡、忌活血食物（当归、红花慎用） |
| 产后 | 温补气血——生化汤、鲫鱼汤、红糖姜水 |
| 感冒时 | 风寒→姜汤；风热→薄荷茶；忌滋补 |
| 服药期间 | 遵医嘱——常忌茶水送服、忌绿豆（解药性） |
