# 妇科基础

## 概述

妇科学是研究女性生殖系统疾病及生理特点的临床医学分支。从中西医两个角度涵盖了月经病、带下病、妊娠病、产后病及妇科杂病等范畴。

---

## 一、女性生殖生理

### 1.1 女性一生各阶段

```
女性生理阶段
        │
        ├─ 新生儿期：出生后 4 周——受母体激素影响可有假月经
        ├─ 儿童期：4 周 ~ 12 岁——生殖器缓慢发育
        ├─ 青春期：10 ~ 19 岁——月经初潮（平均 12~13 岁）
        ├─ 性成熟期（育龄期）：18 ~ 48 岁——卵巢功能最旺盛时期
        ├─ 围绝经期：45 ~ 55 岁——卵巢功能衰退→绝经
        └─ 老年期：60 岁以后——卵巢功能完全衰竭
```

### 1.2 月经周期

```
月经周期（约 28 天）
        │
        ├─ 卵泡期（增生期）：第 1~14 天
        │   ├─ FSH 刺激卵泡发育
        │   ├─ 雌激素升高 → 子宫内膜增生
        │   └─ 雌激素正反馈 → LH 峰
        │
        ├─ 排卵期：第 14 天左右
        │   └─ LH 峰 → 卵泡排出
        │
        └─ 黄体期（分泌期）：第 15~28 天
            ├─ 黄体形成 → 分泌孕激素
            ├─ 子宫内膜 → 分泌期改变
            └─ 未受孕 → 黄体萎缩 → 月经来潮
```

| 正常月经参数 | 范围 |
|:---|:---|
| 周期 | 21 ~ 35 天 |
| 经期 | 3 ~ 7 天 |
| 经量 | 5 ~ 80 mL（超过 80 mL 为月经过多） |
| 颜色 | 暗红色 |

## 二、常见月经病

### 2.1 月经失调

| 类型 | 定义 | 常见原因 |
|:---|:---|:---|
| 月经过多 | 经量 > 80mL 或经期 > 7d | 子宫肌瘤、功能失调性子宫出血 |
| 月经过少 | 经量 < 5mL | 宫腔粘连、卵巢功能减退 |
| 月经先期 | 周期 < 21 天 | 黄体功能不全 |
| 月经后期 | 周期 > 35 天 | 多囊卵巢、高催乳素血症 |
| 闭经 | ≥ 6 个月无月经（非孕期） | 卵巢/垂体/下丘脑原因 |

### 2.2 痛经

| | 原发性痛经 | 继发性痛经 |
|:---|:---|:---|
| 原因 | 无器质性病变——前列腺素释放过多 | 器质性疾病：子宫内膜异位症、子宫腺肌病 |
| 年龄 | 青少年多见 | 育龄期 |
| 治疗 | NSAIDs（布洛芬）+ 口服避孕药 | 治疗原发病 |

> 中医认为痛经病机：**不通则痛**（气滞血瘀/寒凝血瘀）与**不荣则痛**（气血亏虚/肝肾不足）。

### 2.3 中医对月经病的治疗

| 证型 | 主方 | 要点 |
|:---|:---|:---|
| 气虚 | 举元煎 | 经行先期、量多色淡 |
| 血虚 | 人参养荣汤 | 经行后期、量少色淡 |
| 血热 | 清经散 | 经期提前、量多色鲜红 |
| 血寒 | 温经汤 | 经期延后、色暗有块、少腹冷痛 |
| 肝郁气滞 | 逍遥散 | 经前乳胀、烦躁 |
| 血瘀 | 桃红四物汤 | 色暗有块、痛经 |

## 三、带下病

### 3.1 正常白带与异常白带

| | 正常白带 | 异常白带 |
|:---|:---|:---|
| 量 | 少量 | 增多 |
| 色 | 白或透明 | 黄、绿、灰 |
| 质 | 蛋清样或稀糊状 | 泡沫状、豆渣样 |
| 气味 | 无臭 | 腥臭 |
| 伴随症状 | 无 | 外阴瘙痒、灼痛 |

### 3.2 常见阴道炎鉴别

| | 细菌性 | 霉菌性（念珠菌） | 滴虫性 |
|:---|:---|:---|:---|
| 白带 | 稀薄灰白色、鱼腥味 | 白色稠厚豆渣样 | 黄绿色泡沫状、臭味 |
| 瘙痒 | 轻 | **很痒** | 中等 |
| 治疗 | 甲硝唑 | 局部/口服抗真菌药 | 甲硝唑（夫妇同治） |

> 中医：脾虚生湿→带下。完带汤——健脾燥湿止带。

## 四、妇科肿瘤

### 4.1 常见良性肿瘤

| 肿瘤 | 特点 |
|:---|:---|
| 子宫肌瘤 | 最常见的子宫良性肿瘤（育龄期 20~50%） |
| 卵巢囊肿 | 多为功能性——定期随访 |

### 4.2 常见恶性肿瘤筛查

| 癌症 | 筛查方法 | 筛查频率 |
|:---|:---|:---|
| 宫颈癌 | TCT + HPV | 21~65 岁：每 3~5 年 |
| 乳腺癌 | 乳腺超声 + 钼靶 | 40 岁以上：每年 |
| 子宫内膜癌 | 经阴道超声 | 围绝经期异常出血者 |

> 宫颈癌是唯一可**预防**的癌症——**HPV 疫苗 + 定期筛查**。

## 五、围绝经期综合征

| 症状 | 表现 |
|:---|:---|
| 血管舒缩 | 潮热、盗汗——最常见 |
| 精神神经 | 失眠、烦躁、情绪波动 |
| 泌尿生殖 | 阴道干涩、反复尿路感染 |
| 远期影响 | 骨质疏松、心血管风险增加 |

**治疗**：激素替代治疗 (HRT)——在窗口期（< 60 岁或绝经 < 10 年）风险效益比最佳。

## 六、子宫内膜异位症与子宫腺肌病

### 6.1 子宫内膜异位症

子宫内膜组织出现于宫腔以外部位，虽为良性病变却具有侵袭/种植/复发性。

```
好发部位
        │
        ├─ 卵巢：巧克力囊肿（最常见）
        ├─ 盆腔腹膜：骶韧带、子宫直肠陷凹
        ├─ 输卵管
        └─ 少见部位：剖宫产瘢痕、肠道、膀胱、肺
```

| 项目 | 内容 |
|------|------|
| 典型症状 | 继发性、进行性加重痛经 + 性交痛 + 不孕 |
| 体征 | 后穹窿触痛结节 |
| 诊断金标准 | 腹腔镜 |
| 治疗 | NSAIDs 止痛；激素抑制（GnRH-a、口服避孕药）；腹腔镜手术 |

> 约 30%~50% 内异症患者合并不孕。

### 6.2 子宫腺肌病

子宫内膜侵入子宫肌层，属于内异症的特殊类型。

| | 子宫腺肌病 | 子宫内膜异位症 |
|:---|:---|:---|
| 病变位置 | 子宫肌层内 | 宫腔外 |
| 典型症状 | 月经过多 + 严重痛经 | 痛经 + 性交痛 |
| 子宫 | **球形增大**、质地硬 | 正常或稍大 |
| 治疗终点 | 重度常需子宫切除 | 可保留子宫 |

## 七、多囊卵巢综合征 (PCOS)

育龄期最常见的内分泌代谢紊乱，患病率约 5%~10%。

```
PCOS 病理生理
        │
        ├─ 胰岛素抵抗 + 高胰岛素血症（核心）
        │   └─ 刺激卵巢间质 → 雄激素升高
        │
        ├─ LH 异常升高 → 卵泡发育停滞
        │   └─ 多个小卵泡（≥ 12 个 / 卵巢）→ 无排卵
        │
        └─ 临床表现
            ├─ 月经稀发/闭经
            ├─ 高雄激素表现：多毛、痤疮、脱发
            ├─ 超声：卵巢多囊样改变
            └─ 肥胖（约 50%）
```

| 项目 | 内容 |
|------|------|
| 诊断标准（鹿特丹，3 选 2） | ① 稀发排卵/无排卵 ② 临床或生化高雄激素 ③ 超声多囊卵巢 |
| 远期风险 | 2 型糖尿病、子宫内膜增生/癌、心血管病 |
| 基础治疗 | **生活方式干预（减重 5%~10%）**——一线方案 |
| 药物治疗 | 二甲双胍（改善胰岛素抵抗）+ 口服避孕药（调经抗雄） |
| 促排卵 | 来曲唑（一线）/ 克罗米芬 |

## 八、盆底功能障碍

盆底肌群和筋膜支撑膀胱、子宫、直肠。损伤后导致功能障碍。

```
盆底功能障碍
        │
        ├─ 盆腔器官脱垂
        │   ├─ 膀胱膨出（前壁）
        │   ├─ 子宫/穹窿脱垂（中盆）
        │   └─ 直肠膨出（后壁）
        │
        ├─ 压力性尿失禁
        │   └─ 咳嗽/大笑/跳跃时漏尿
        │
        └─ 危险因素
            ├─ 妊娠和分娩（最主要）
            ├─ 年龄、肥胖、慢性咳嗽、便秘
            └─ 家族遗传
```

| 分级 | 治疗 |
|:---|------|
| 轻度 | 盆底肌训练 (Kegel) + 生活方式 |
| 中度 | 子宫托 |
| 重度 | 盆底重建手术 / 尿道中段悬吊术 (TVT) |

## 九、常见妇科手术

| 手术 | 适应症 | 途径 |
|------|------|:---:|
| 子宫肌瘤剔除术 | 有症状或影响生育的肌瘤 | 腹腔镜/开腹 |
| 全子宫切除术 | 多发大肌瘤、子宫腺肌病、恶性肿瘤 | 腹腔镜/经阴道/开腹 |
| 卵巢囊肿剥除术 | 持续存在的囊肿、巧克力囊肿 | 腹腔镜 |
| 输卵管切除术 | 异位妊娠、输卵管积水 | 腹腔镜 |
| 宫腔镜手术 | 息肉、粘连、黏膜下肌瘤 | 经宫颈（无切口） |
| 宫颈锥切术 (LEEP/CKC) | CIN II~III 级 | 经阴道 |

## 十、常用妇科检查

| 检查 | 用途 |
|:---|:---|
| 妇科双合诊 | 基础查体 |
| 阴道分泌物常规 | 感染 |
| TCT + HPV | 宫颈癌筛查 |
| 盆腔超声 | 子宫、卵巢形态 |
| 性激素六项 | 卵巢功能评估 |
| 宫腔镜 | 宫腔内病变 |
| 腹腔镜 | 内异症、不孕原因探查（诊 + 治一体） |
| CA125 | 卵巢肿瘤标志物（辅助，非特异性） |

---

## 总结

妇科涵盖从青春期到老年期的女性生殖健康：月经、带下、妊娠、产后、更年期管理、肿瘤筛查。中医药在调经、种子、安胎方面有独特优势，中西医结合诊治可获得更佳效果。
