# 千金要方

[TOC]

## 简介

《千金要方》全名《备急千金要方》，唐代**孙思邈**（约 581—682）著，成书于永徽三年（652 年）。全书 30 卷，分 232 门，载方 5300 余首，是中医学史上第一部综合性临床百科全书。

> 孙思邈被尊为"药王"，其名言"人命至重，有贵千金，一方济之，德逾於此"——为书名"千金"之由来。

## 核心内容

| 卷次 | 内容 |
|:---:|------|
| 卷一 | 序例——大医精诚、大医习业 |
| 卷二 ~ 四 | 妇人方（妇科列为卷首——尊重妇女地位的体现） |
| 卷五 | 少小婴孺（儿科，中医最早的儿科专论之一） |
| 卷六 | 七窍病（五官科） |
| 卷七 ~ 十 | 风毒脚气、诸风、伤寒方 |
| 卷十一 ~ 二十 | 五脏六腑各论 |
| 卷二十一 ~ 二十五 | 消渴、淋闭、尿血、水肿等内科各论 |
| 卷二十六 | **食治**（食疗专篇——最早的食疗系统论述） |
| 卷二十七 | 养性（养生——导引、按摩、调气） |
| 卷二十八 | 平脉（脉学） |
| 卷二十九 ~ 三十 | 针灸 |

## 大医精诚

> 凡大医治病，必当安神定志，无欲无求，先发大慈恻隐之心，誓愿普救含灵之苦……不得问其贵贱贫富，长幼妍蚩，怨亲善友，华夷愚智，普同一等，皆如至亲之想。（《备急千金要方·大医精诚》）

这篇被称为中医伦理最高准则的文献，规定了医生应具备的道德素养——仁爱、无差别对待、专注、不矜、不自私。

## 学术贡献

1. 将妇人、小儿病单独列出——开创中医妇科学、儿科学
2. 食治专篇——药物毒性认知，先以食物调治
3. 详述糖尿病——患消渴者忌饮酒、节制房事等
4. 最早论及营养不良性夜盲（用动物肝脏治疗 → 现代证明：维生素 A）
5. 最早论及甲状腺肿（瘿病——用海藻、昆布含碘疗治）
6. 记录下颌关节脱位的复位手法

## 与《千金翼方》的关系

《千金翼方》是孙思邈晚年（约 682 年）为补《千金要方》之不足而作，30 卷，增补了药物（唐代外来药）和伤寒内容。二者合称《千金方》。
