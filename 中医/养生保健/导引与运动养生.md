# 导引与运动养生

## 概述

导引是以肢体运动配合呼吸吐纳来疏通经络、调和气血的传统养生方法。包括太极拳、八段锦、五禽戏、易筋经等，均为中医运动养生的重要组成部分。

> 《素问》："上古之人，其知道者，法于阴阳，和于术数……不妄作劳，故能形与神俱。"

---

## 一、中医运动养生的特点

与西方体育锻炼相比：

| | 中医运动养生 | 西方体育锻炼 |
|:---|------|------|
| 核心 | 形神合一、内外兼修 | 肌肉力量/心肺功能为主 |
| 强度 | 柔和适度 | 可激烈 |
| 呼吸 | 与动作协调的腹式呼吸 | 自动呼吸调节 |
| 目的 | 调气血、和脏腑、养心神 | 体能、竞技 |
| 年龄适应性 | 老少皆宜 | 强度分层 |

**基本原则**："不妄作劳"——运动不过度、不超出身体承受范围。

## 二、八段锦

八段锦是流传最广的传统导引功法之一，共八式，动作柔和缓慢。

| | 式名 | 主要功效 | 作用描述 |
|:---:|:---|:---|:---|
| 1 | 双手托天理三焦 | 调节三焦气机 | 通调水道、舒展胸腔 |
| 2 | 左右开弓似射雕 | 强肺通经 | 宽胸理气、强健肩臂 |
| 3 | 调理脾胃须单举 | 调理脾胃 | 一升一降→健脾和胃 |
| 4 | 五劳七伤往后瞧 | 疏通颈项 | 解颈部疲劳、活气血 |
| 5 | 摇头摆尾去心火 | 清心降火 | 引火归原、安神定志 |
| 6 | 两手攀足固肾腰 | 强腰固肾 | 拉伸腰背、强肾壮腰 |
| 7 | 攒拳怒目增气力 | 增强气力 | 强筋壮骨、培养气势 |
| 8 | 背后七颠百病消 | 通达全身 | 轻微震动通经活络 |

八段锦最适宜：
- 中老年日常保健
- 久坐办公室人群
- 慢性病康复期

## 三、太极拳

### 3.1 太极拳的养生原理

```
太极拳特点
        │
        ├─ 缓慢柔和：不使心率骤升——适合各种年龄
        ├─ 呼吸深长：腹式呼吸——增加膈肌运动、促进气血运行
        ├─ 重心控制：持续微调重心——锻炼平衡能力→防跌防摔
        ├─ 意念先行：以意领气、以气运身——形神合一
        ├─ 连绵不断：弧形运动——舒张血管、降低血压
        └─ 动静结合：动中生静——养心安神
```

### 3.2 各流派特点

| 流派 | 特点 | 适合人群 |
|:---|:---|:---|
| 陈式 | 刚柔相济、快慢相间、有发力动作 | 年轻人、追求功夫者 |
| 杨式 | 舒展大方、柔和平稳、速度均匀 | 最普及——男女老少皆宜 |
| 吴式 | 拳架紧凑、柔化细腻 | 体质较弱者 |
| 孙式 | 步活身灵、开合明显 | 一般人群 |
| 武式 | 紧凑严密、内劲含蓄 | 内家功夫爱好者 |

### 3.3 太极拳的医学作用

| 方面 | 作用 |
|:---|------|
| 心血管 | 降低血压、改善血管内皮功能 |
| 骨骼关节 | 增强骨密度、改善膝关节（正确姿势下） |
| 平衡系统 | 减少老年人跌倒率 40~50% |
| 神经系统 | 改善睡眠、减轻焦虑抑郁 |
| 代谢 | 辅助控糖、改善血脂 |

## 四、五禽戏

神医华佗创编，模仿五种动物的习性和神态。

| 禽 | 应五脏 | 动作特点 | 功效 |
|:---:|:---:|:---|:---|
| 虎 | 肝 | 刚猛有力、虎视眈眈 | 舒肝理气、强筋健骨 |
| 鹿 | 肾 | 柔和舒展、回望盼顾 | 强腰固肾、疏通督脉 |
| 熊 | 脾 | 憨厚沉稳、摩腹晃腔 | 充实四肢、健脾和胃 |
| 猿 | 心 | 灵活敏捷、快速摘果 | 养心调神、轻身健体 |
| 鹤（鸟） | 肺 | 悠然自得、展翅高飞 | 调和呼吸、扩肺补气 |

## 五、易筋经

易筋经是传统的健身功法，以伸展筋骨、强健肢体为主。

**核心要领**：
- 筋长一寸、延寿十年——静态拉伸促进气血流通
- 强调"力"与"气"的结合
 
**适宜人群**：筋骨僵硬者、中老年、慢性颈椎腰椎病者。

## 六、日常运动养生建议

### 6.1 运动量与频率

| 人群 | 建议 |
|:---|:---|
| 一般成人 | 每周 ≥ 5 次，每次 30~60 分钟 |
| 老年人 | 每天温和运动——太极拳、散步、八段锦 |
| 慢性病患者 | 遵医嘱——不可强行运动 |

### 6.2 运动时间

| 时段 | 适合的运动 |
|:---|:---|
| 早晨（日出后） | 太极拳、八段锦——升发阳气 |
| 傍晚（日落前） | 散步、瑜伽——收敛心神 |
| 饭后 | 饭后 30 分钟轻散步——"饭后百步走，活到九十九" |

> 忌：剧烈运动后立即停坐、汗出当风、大汗淋漓饮水冷不忌。

### 6.3 运动中的注意事项

- 运动前热身——活动关节
- 循序渐进——不突然增加强度
- 冬日运动注意保暖——汗出不过多
- 出现胸闷、头晕→立即停止
- 补水：少量多次——不一次性大量饮水
