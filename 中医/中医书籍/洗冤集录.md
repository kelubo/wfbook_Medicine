# 洗冤集录

[TOC]

## 简介

《洗冤集录》是南宋**宋慈**（字惠父，1186—1249）所著，成书于淳祐七年（1247 年）。全书 5 卷、53 条，是世界上第一部系统的法医学专著。

> 比欧洲最早的同类著作——意大利菲德里（Fortunato Fedele）的《医生的报告》（1602 年）早 350 余年。该书被翻译成日、韩、英、法、德、俄等多种文字。

## 性质

严格来说，《洗冤集录》不属于"医书"而属于**法医学著作**，但其内容涉及了大量尸体检验、死因鉴别等医学相关领域，常被归入广义中国古代科技名著范畴。

## 内容概述

| 卷次 | 内容 |
|:---:|------|
| 卷一 | 检验总论——尸检工作的规则和纪律 |
| 卷二 | 尸体现象——死后变化、季节影响、缢死/勒死的鉴别 |
| 卷三 | 死因鉴别——溺死、自缢/他杀/自杀缢区别、中毒、火伤等 |
| 卷四 | 意外死因——塌压、雷击、动物咬伤等 |
| 卷五 | 急救方——"救死方" |

## 核心贡献

1. **自缢与死后悬尸的鉴别**——索沟形状、深浅、方向不同
2. **溺死与死后入水的鉴别**——口鼻有无蕈沫、手中是否握有泥沙水草
3. **中毒征象**——银钗验毒法（实际不可靠，受当时知识限制）
4. **骨骼检验**——男女骨盆鉴别、生前伤/死后伤的辨别

## 局限

受时代限制，书中也存在一些不科学的认识（如银钗验毒——银钗变黑实际上是接触硫化物，并非所有毒药都含硫），应当以历史的眼光看待。

## 历史地位

世界法医学的奠基石，体现了中国古代实证和检验精神的最高水准。
