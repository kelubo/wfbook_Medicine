# 右归丸

[TOC]

## 来源

《景岳全书》（明代张介宾——张景岳，温补学派代表人物）

## 组成

| 药物 | 作用 |
|------|------|
| 熟地黄 | 滋肾填精（阴中求阳） |
| 山药 | 补脾固精 |
| 山茱萸 | 补肝肾、涩精 |
| 枸杞子 | 滋补肝肾 |
| 菟丝子 | 补肝肾、固精缩尿 |
| 鹿角胶 | 温补肾阳、益精血 |
| 杜仲 | 补肝肾、强筋骨 |
| 肉桂 | 温补命门之火 |
| 当归 | 养血活血 |
| 制附子 | 温补肾阳（逐渐加入） |

## 功效与主治

- **功效**：温补肾阳、填精止遗
- **主治**：肾阳虚（命门火衰）——腰膝酸冷、畏寒肢冷、阳痿遗精、大便溏薄、小便自遗、神疲乏力

## 方解

右归丸是"**阴中求阳**"的代表方，体现了张景岳的学术思想：

> 善补阳者，必于阴中求阳——则阳得阴助而生化无穷

在大量滋肾填精的补阴药（熟地、山茱萸、山药、枸杞）基础上，加入温阳药（附子、肉桂、鹿角胶），使阳气有物质基础（阴精化生阳气），而非单纯的火上加油。

## 与左归丸的对比

| | 右归丸 | 左归丸 |
|---|---|---|
| 治法 | 温补肾阳 | 滋补肾阴 |
| 方向 | 右（阳） | 左（阴） |
| 核心药 | 熟地+附子+肉桂+鹿角胶 | 熟地+龟板胶+牛膝 |
| 主证 | 肾阳虚——畏寒、肢冷 | 肾阴虚——潮热、盗汗 |
| 理论 | 阴中求阳 | 阳中求阴 |

> 左归丸 与 右归丸 是张景岳的姊妹篇——左归丸滋养肾阴、右归丸温补肾阳。同时张景岳还有 左归饮、右归饮（药味较丸剂少）。

## 与金匮肾气丸的区别

| | 右归丸 | 金匮肾气丸 |
|---|---|---|
| 来源 | 《景岳全书》 | 《金匮要略》 |
| 核心 | 补肾阳兼填精 | 化气行水 |
| 滋阴药 | 多而力峻（鹿角胶、枸杞等） | 较少（仅地黄、山茱萸、山药） |
| 适用 | 纯粹肾阳虚、精血亏 | 肾阳虚兼水气不化 |
