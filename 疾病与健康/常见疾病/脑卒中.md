# 脑血管疾病（脑卒中）

## 概述

脑卒中 (Stroke) 又称"中风"，是由于脑部血管突然破裂或阻塞导致血液不能流入大脑而引起的脑组织损伤。具有高发病率、高致残率、高死亡率、高复发率的特点。

> 中国脑卒中发病率居全球首位，是成人致残的第一位病因。

---

## 一、分型

```
脑卒中分型
        │
        ├─ 缺血性脑卒中（70~80%）
        │   ├─ 脑血栓形成：动脉粥样硬化基础上原位血栓形成
        │   ├─ 脑栓塞：心脏或大血管栓子脱落（如房颤）
        │   └─ 腔隙性脑梗死：小穿支动脉闭塞（与高血压相关）
        │
        └─ 出血性脑卒中（20~30%）
            ├─ 脑出血：高血压是主因 → 基底节区最常见
            └─ 蛛网膜下腔出血：多为动脉瘤破裂
```

---

## 二、危险因素

| 可控因素 | 不可控因素 |
|----------|-----------|
| 高血压（最最重要） | 年龄 |
| 心房颤动（心源性栓塞） | 性别（男性 > 女性） |
| 糖尿病 | 种族 |
| 血脂异常 | 遗传/家族史 |
| 吸烟、酗酒 | 既往卒中/TIA 史 |
| 肥胖、缺乏运动 | |

---

## 三、临床表现

### 3.1 快速识别 — FAST/BEFAST 原则

| 字母 | 含义 | 症状 |
|:---:|------|------|
| **B** (Balance) | 平衡 | 突发头晕、行走困难 |
| **E** (Eyes) | 眼睛 | 突发视力模糊或视野缺损 |
| **F** (Face) | 面部 | 一侧面部下垂、口角歪斜 |
| **A** (Arms) | 手臂 | 一侧手臂无力或麻木 |
| **S** (Speech) | 语言 | 言语含糊、不能说话或听不懂 |
| **T** (Time) | 时间 | 立即拨打 120！ |

> **时间就是大脑**：每延迟 1 分钟，约 190 万个神经元死亡。

### 3.2 常见局灶性神经功能缺损

| 血管 | 症状 |
|------|------|
| 大脑中动脉 | 对侧偏瘫+偏身感觉障碍+同向偏盲（三偏） |
| 大脑前动脉 | 对侧下肢瘫+尿失禁 |
| 颈内动脉 | 同侧单眼一过性黑矇+对侧偏瘫 |
| 椎基底动脉 | 眩晕、共济失调、交叉性瘫痪 |

## 四、辅助检查

| 检查 | 用途 |
|------|------|
| **头颅 CT（首选急查）** | 快速区分出血 vs 缺血——出血立即可见高密度影 |
| **头颅 MRI + DWI** | 缺血性卒中早期诊断——发病数分钟内可显示 |
| CTA/MRA | 评估颅内外血管 |
| 心电图 | 排除房颤——寻找栓塞来源 |
| 颈动脉超声 | 评估动脉粥样硬化程度 |

| CT 表现 | 提示 |
|:---|------|
| 高密度影 | **脑出血** |
| 低密度影（24h 后才明显） | 脑梗死 |
| 鞍上池/脑沟高密度 | 蛛网膜下腔出血 |

## 五、治疗

### 5.1 缺血性脑卒中急性期治疗

```
时间窗至关重要

≤ 4.5 小时
    │
    ├─ 静脉溶栓 (rt-PA/阿替普酶)——首选、最有效
    │   禁忌证：出血、近期手术、严重高血压、低血糖
    │
    └─ + 机械取栓（大血管闭塞，≤ 6~24h 符合影像筛选条件）

> 4.5 小时或溶栓禁忌
    │
    ├─ 机械取栓评估
    ├─ 抗血小板：阿司匹林 + 氯吡格雷（双抗）
    ├─ 抗凝：心源性栓塞（房颤）→ 华法林或新型抗凝药
    └─ 他汀强化降脂
```

### 5.2 脑出血治疗

| 措施 | 细节 |
|------|------|
| 控制血压 | 目标 SBP < 140 mmHg（相对缓慢降压） |
| 止血/降颅压 | 甘露醇脱水降颅压 |
| 逆转抗凝 | 华法林患者 → 维生素 K |
| 手术 | 血肿 > 30mL、意识恶化、小脑出血 |
| 对症支持 | 血糖管理、预防癫痫、深静脉血栓预防 |

### 5.3 二级预防（已发生卒中后的预防）

| 措施 | 具体 |
|------|------|
| 抗血小板 | 阿司匹林或氯吡格雷（非心源性） |
| 抗凝 | 房颤 → 华法林 / NOAC（达比加群、利伐沙班） |
| 降压 | 目标 < 140/90（即使血压正常也需轻度降压） |
| 他汀 | 强化降脂 LDL-C < 1.8 mmol/L |
| 颈动脉内膜剥脱 (CEA) | 症状性重度狭窄 (70~99%) |
| 生活方式 | 戒烟、限酒、运动、减重 |

---

## 六、预防（一级预防）

- **控制血压**：最重要措施——SBP 每降低 10 mmHg，卒中风险降低约 1/3
- **房颤筛查与抗凝**：房颤患者卒中风险高 5 倍
- 控制血糖、血脂
- 戒烟、限酒
- 健康饮食（地中海饮食或 DASH）
- 定期运动
