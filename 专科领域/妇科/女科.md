# 女科（中医妇科）

> 女科有四纲：**经、带、胎、产**。此四纲以气血为本、肝肾为源、冲任为要。

---

## 一、总纲

女科：经，带，胎，产

经：调经种子

带：妇科杂病

胎：安胎待产

产：分娩产后

女性生理病理特点：

1. 气血为纲
2. 多虚多郁
3. 易衰老易修复

---

## 二、女性生理基础（中医）

### 2.1 脏腑与女科

| 脏腑 | 功能 | 失常表现 |
|:---|:---|:---|
| 肾 | 藏精、主生殖，为天癸之源 | 月经不调、不孕、早衰 |
| 肝 | 藏血、主疏泄 | 月经紊乱、经前乳胀、痛经 |
| 脾 | 统血、运化水湿 | 月经过多、带下病、浮肿 |
| 心 | 主血脉 | 经行情志异常、失眠 |

### 2.2 气血与冲任

```
女子以血为本，气为血帅
        │
        ├─ 气血充盈 → 月经如期、胎孕正常
        ├─ 气血亏虚 → 月经量少/闭经、胎萎不长
        ├─ 气滞血瘀 → 痛经、癥瘕（肌瘤/囊肿）
        └─ 血热妄行 → 月经先期、量多、崩漏
```

> **冲为血海，任主胞胎**——冲任二脉是联系脏腑与胞宫的关键通道。

### 2.3 《黄帝内经》女子七岁律

| 年龄 | 生理变化 |
|:---:|------|
| 7 岁 | 肾气盛，齿更发长 |
| 14 岁 | 天癸至，任脉通，太冲脉盛，月事以时下 |
| 21 岁 | 肾气平均，真牙生而长极 |
| 28 岁 | 筋骨坚，发长极，身体盛壮 |
| 35 岁 | 阳明脉衰，面始焦，发始堕 |
| 42 岁 | 三阳脉衰于上，面皆焦，发始白 |
| 49 岁 | 任脉虚，太冲脉衰少，天癸竭，地道不通 |

## 三、经 —— 调经种子

### 3.1 月经生理

| 要素 | 正常 | 异常 |
|:---|:---|:---|
| 周期 | 28 天（±7d） | 先期/后期/先后不定期 |
| 经期 | 3~7 天 | 延长/缩短 |
| 经量 | 适中，5~80mL | 过多/过少 |
| 经色 | 暗红，无块 | 淡红（虚）、紫暗有块（瘀） |
| 伴随 | 轻微不適 | 严重痛经、乳胀、头痛 |

### 3.2 月经病辨证

```
月经病辨证要点
        │
        ├─ 先期：多属血热或气虚
        │   ├─ 量多色鲜红 → 血热（清经散）
        │   └─ 量多色淡 → 气虚（举元煎）
        │
        ├─ 后期：多属血寒或血虚
        │   ├─ 色暗有块、腹痛 → 血寒（温经汤）
        │   └─ 量少色淡 → 血虚（人参养荣汤）
        │
        ├─ 先后不定期：多属肝郁或肾虚
        │   ├─ 胸胁乳胀 → 肝郁（逍遥散）
        │   └─ 腰膝酸软 → 肾虚（固阴煎）
        │
        ├─ 痛经
        │   ├─ 经前/经期痛、拒按 → 实证（气滞血瘀/寒凝血瘀）
        │   └─ 经后痛、喜按 → 虚证（气血虚弱/肝肾亏损）
        │
        ├─ 崩漏（经血非时暴下或淋漓）
        │   ├─ 塞流（止血）、澄源（求因）、复旧（固本）—— 三法治崩
        │   └─ 血热/血瘀/脾虚/肾虚四型论治
        │
        └─ 闭经
            ├─ 虚证：肾虚、脾虚、血虚 → 补而通之
            └─ 实证：气滞血瘀、痰湿阻滞 → 泻而通之
```

### 3.3 调经常用方

| 证型 | 主方 | 关键药 |
|------|------|--------|
| 气血两虚 | 八珍汤 | 党参、当归、熟地 |
| 肝郁气滞 | 逍遥散 | 柴胡、当归、白芍 |
| 血瘀 | 桃红四物汤 | 桃仁、红花 |
| 血寒 | 温经汤 | 吴茱萸、当归、桂枝 |
| 血热 | 清经散 | 丹皮、地骨皮、黄柏 |
| 肾虚 | 左归丸（肾阴虚）/ 右归丸（肾阳虚） | 熟地、山萸肉、菟丝子 |

### 3.4 种子（助孕）

| 治法 | 说明 |
|------|------|
| 补肾填精 | 基础——"肾主生殖" |
| 调肝理气 | 疏肝解郁——身心同治 |
| 健脾养血 | 后天养先天 |
| 活血化瘀 | 内异症、盆腔炎后遗症 |
| 祛痰化湿 | 多囊卵巢综合征（痰湿型） |

## 四、带 —— 带下病

### 4.1 带下辨证

```
带下辨证
        │
        ├─ 脾虚带下：色白或淡黄、量多、质稀、无臭 → 完带汤
        ├─ 肾虚带下：色白质稀、腰膝酸冷 → 内补丸
        ├─ 湿热下注：色黄、质稠、腥臭 → 止带方
        └─ 湿毒蕴结：黄绿如脓、腥臭味重 → 五味消毒饮
```

### 4.2 带下与体质

| 体质 | 易患带下类型 | 调护 |
|------|------------|------|
| 脾虚痰湿 | 白带多而稀 | 健脾利湿 |
| 阴虚火旺 | 带少阴道干涩 | 滋阴润燥 |
| 湿热体质 | 黄带腥臭 | 清热利湿 |

> **治带先治脾，治带必利湿。**

## 五、胎 —— 安胎待产

### 5.1 孕期生理

```
孕期特点
        │
        ├─ 阴血下聚养胎 → 全身阴血相对不足，阳气偏亢
        ├─ 肾气系胎、脾气载胎
        └─ 逐月养胎—— "一月名始胚，二月名始膏……"
```

### 5.2 妊娠病

| 疾病 | 病机 | 主治 |
|------|------|------|
| 恶阻（孕吐） | 冲气上逆、胃失和降 | 香砂六君子汤 / 橘皮竹茹汤 |
| 胎漏/胎动不安 | 肾虚（主因）、气血不足、血热 | 寿胎丸（菟丝子+桑寄生+续断+阿胶） |
| 滑胎（习惯性流产） | 肾气亏损、气血两虚 | 补肾固冲——孕前即调 |
| 子肿 | 脾虚水泛、肾阳虚 | 白术散（脾虚）/ 真武汤（肾虚） |
| 子痫 | 肝风内动 | 羚角钩藤汤（重症急症） |

> 保胎核心：**补肾 + 益气 + 清热**。寿胎丸是安胎第一方。

### 5.3 孕期调护

| 方面 | 要点 |
|------|------|
| 饮食 | 清淡易消化，忌生冷辛辣 |
| 情志 | 怡情养性、避免惊恐 |
| 起居 | 劳逸适度，孕早期/晚期禁房事 |
| 逐月禁忌 | 遵从"逐月养胎"法 |

## 六、产 —— 分娩产后

### 6.1 产后生理特点

```
产后多虚多瘀
        │
        ├─ 多虚：分娩失血耗气 → 气血两亏
        ├─ 多瘀：恶露未净 → 瘀血内阻
        └─ 易感：腠理疏松 → 易受外邪
```

### 6.2 产后病

| 疾病 | 病机 | 主治 |
|------|------|------|
| 产后恶露不绝 | 血瘀 / 气虚 / 血热 | 生化汤（血瘀）/ 补中益气汤（气虚） |
| 产后身痛 | 血虚不濡 / 风寒侵袭 | 黄芪桂枝五物汤 |
| 产后缺乳 | 气血虚弱 / 肝郁气滞 | 通乳丹（气血虚）/ 下乳涌泉散（肝郁） |
| 产后汗证 | 气虚自汗 / 阴虚盗汗 | 玉屏风散（自汗） |
| 产后抑郁 | 血不养心、肝气郁结 | 甘麦大枣汤 + 逍遥散 |

> **生化汤**——产后第一方：当归+川芎+桃仁+炮姜+炙甘草。生新血、化瘀血。

### 6.3 产后调护

| 阶段 | 调护重点 |
|------|---------|
| 产后 1 周 | 化瘀生新——生化汤 |
| 产后 2~3 周 | 健脾益气 |
| 产后 4~6 周 | 补肾固本 |
| 全程 | 避风寒、调情志、均衡营养、充足睡眠 |

## 七、妇科杂病

### 7.1 常见杂病

| 疾病 | 病机 | 方药 |
|------|------|------|
| 癥瘕（肌瘤/囊肿） | 气滞血瘀、痰湿瘀结 | 桂枝茯苓丸 |
| 不孕 | 肾虚为本，肝郁/痰湿/血瘀为标 | 辨证选方：毓麟珠/开郁种玉汤/苍附导痰丸/少腹逐瘀汤 |
| 脏躁（更年期综合征） | 肾阴不足、心肝火旺 | 知柏地黄丸 + 甘麦大枣汤 |
| 阴挺（子宫脱垂） | 气虚下陷 | 补中益气汤 |

### 7.2 桂枝茯苓丸

| 项目 | 内容 |
|------|------|
| 组成 | 桂枝 + 茯苓 + 丹皮 + 桃仁 + 芍药 |
| 功用 | 活血化瘀、缓消癥块 |
| 主治 | 子宫肌瘤、卵巢囊肿、内异症（血瘀型） |
| 特点 | **缓消**——攻邪不伤正，可长期服用 |

## 总结

中医女科以"调气血、和脏腑、通冲任"为核心，以经、带、胎、产为纲，强调**治未病**——月经调则种子易，胎前调则产后安。临床常与现代医学结合，优势互补。
