# 妇人良方大全

[TOC]

## 简介

《妇人良方大全》全名《妇人大全良方》，是南宋**陈自明**（字良甫，约 1190—1270）撰，成书于嘉熙元年（1237 年）。全书 24 卷，分为调经、众疾、求嗣、胎教、妊娠、坐月、产难、产后八门，集宋以前妇科之大成。

> 陈自明是南宋著名妇科和外科医家——另有《外科精要》传世，均极有影响。

## 内容结构

| 门类 | 内容 |
|------|------|
| 调经门 | 月经不调、痛经、经闭 |
| 众疾门 | 妇科杂病（百合病、骨蒸、血风劳等） |
| 求嗣门 | 不孕症论治 |
| 胎教门 | 孕期调护（最早的胎教专论） |
| 妊娠门 | 孕期各月病证（恶阻、子痫、胎漏） |
| 坐月门 | 临月护理 |
| 产难门 | 难产各证（横产、倒产、偏产等） |
| 产后门 | 恶露、血晕、身痛、缺乳、产后发热等 |

## 贡献

1. 南宋以前妇科文献学整理的高峰
2. 首次确立了调经（经）、带下（带）、妊娠（胎）、产后（产）四大部分的妇科体系
3. 注重实际——每病证后都附有详细的处理办法
4. 收录了大量单验方和民间经验
5. 对明代王肯堂《女科证治准绳》（《证治准绳》的女科部分）有直接影响

## 胎教论述（节要）

> 自妊娠之后，则须行坐端严，性情和悦，常处静室，多听美言，令人讲读诗书、陈礼说乐……如此则生子形容端正、才智过人。

陈自明认为孕妇的情绪状态和行为对胎儿有直接的影响——"内象成子"说。虽然其中糅合了一些非科学因素，但其核心观念（孕期精神平和、良好环境）与现代围产医学不谋而合。
