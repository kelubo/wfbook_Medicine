# 天雄

[TOC]

## 概述

天雄为毛茛科植物乌头 *Aconitum carmichaeli* Debx. 的子根（不带附子的独根），或指生长三年以上的老根。主产于四川、陕西等地。

> 附子、乌头、天雄同出一源——母根为乌头、子根为附子、独生而不附子的为天雄。三者皆有毒，但各有所长："附子走下（温肾），乌头走表（祛风），天雄走上（补阳）"。

## 性味归经

- **性味**：辛、热、有大毒
- **归经**：心、肾、脾

## 功效

| 功效 | 应用 |
|------|------|
| **补火助阳** | 阳虚诸证——肾阳虚衰、命门火衰、腰膝冷痛 |
| **祛风散寒** | 风寒湿痹、肢体关节疼痛 |
| **益精壮骨** | 肾阳虚所致的阳痿、不孕 |

## 使用注意

| 注意 | 说明 |
|------|------|
| 用量 | 炮制后用 3 ~ 10 g（先煎 1 小时以上以减毒） |
| 生品 | **严禁直接入药**——含乌头碱剧毒（致死量 2~4 mg） |
| 禁忌 | 阴虚火旺者、孕妇忌用 |
| 十八反 | 反半夏、瓜蒌、贝母、白蔹、白及 |

## 与附子、乌头的区别

| | 天雄 | 附子 | 乌头（川乌） |
|---|---|---|---|
| 来源 | 独根（不生附子） | 子根 | 母根 |
| 性味 | 辛热大毒 | 辛甘大热大毒 | 辛热大毒 |
| 偏行 | 偏补上焦、壮阳 | 偏补下焦、回阳 | 偏走经络、祛风 |
| 经典方 | 天雄散 | 四逆汤、真武汤 | 乌头汤 |

## 现代认识

天雄在现代临床中已**极少使用**——因安全原因，绝大多数临床场合已由附子替代。天雄和附子的主要区别在于植株形态（是否产生附子），其化学成分（乌头碱类二萜生物碱）基本相同。目前《中国药典》未单独收载天雄，临床应谨慎对待。
