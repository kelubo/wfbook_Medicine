# 红曲

[TOC]

## 概述

红曲为曲霉科真菌紫色红曲霉 *Monascus purpureus* Went 接种于大米上发酵而成。主产于福建、浙江、广东等地。历史悠久，既是中药又是传统食品着色剂（如红腐乳、叉烧肉）。

> 1970 年代日本学者远藤章从红曲中发现的**莫纳可林 K (Monacolin K)**，后被开发为经典的降血脂药物——洛伐他汀 (Lovastatin)。

## 性味归经

- **性味**：甘、温
- **归经**：肝、脾、大肠

## 功效

| 用法 | 功效 | 应用 |
|------|------|------|
| **健脾消食** | 活血化瘀、消食化积 | 饮食积滞、脘腹胀满 |
| **活血化瘀** | 产后恶露不尽、跌打损伤瘀滞作痛 | 瘀血腹痛 |

## 现代研究

红曲含有丰富的活性次生代谢产物：

| 成分 | 作用 |
|------|------|
| 莫纳可林 K (Monacolin K) | **天然他汀**——抑制 HMG-CoA 还原酶 → 强效降 LDL-C |
| γ-氨基丁酸 (GABA) | 辅助降血压 |
| 红曲色素 | 天然食用色素、抗氧化 |
| 麦角甾醇 | 维生素 D2 前体 |

> 中国临床上常用的调脂中成药"血脂康"即由特制红曲精制而成，其降脂效果经大型临床试验验证。目前临床调脂指南中将他汀类药物（全合成药）与血脂康（天然发酵药）并列为一级推荐。

## 使用注意

| 注意 | 说明 |
|------|------|
| 用量 | 煎服 6 ~ 12 g |
| 脾胃虚弱 | 可配伍健脾之品 |
| 特殊工艺品 | 降脂用的红曲产品多为特殊发酵工艺的提取物，与烹饪用红曲米不同 |

## 红曲米与功能性红曲的区别

| | 红曲米（食品用） | 功能性红曲（药用） |
|---|---|---|
| 菌种 | 普通红曲霉 | 特选高产莫纳可林 K 的菌株 |
| Monacolin K | 微量或未检出 | 标准化含量 |
| 用途 | 食物着色（红糟/腐乳） | 降血脂 |
| 监管 | 食品添加剂 | 药品 / 保健食品 |

> 家庭自行用普通红曲米煮饭不能替代降脂药物，因不含或极少含有效剂量的 Monacolin K。
