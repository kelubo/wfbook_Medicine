# 中医儿科

## 概述

中医儿科是研究儿科疾病辨证论治的学科，涵盖新生儿疾病、呼吸道疾病、消化道疾病等。

---

## 一、新生儿疾病

### 1.1 胎黄

```
胎黄辨证论治
        │
        ├─ 生理性黄疸：出生后2-3天出现，7-10天消退
        │
        ├─ 病理性黄疸：出生后24小时内出现，持续时间长
        │
        ├─ 湿热熏蒸
        │   ├─ 症状：面目皮肤发黄、色泽鲜明
        │   ├─ 治法：清热利湿退黄
        │   └─ 方药：茵陈蒿汤
        │
        └─ 寒湿阻滞
            ├─ 症状：面目皮肤发黄、色泽晦暗
            ├─ 治法：温中化湿退黄
            └─ 方药：茵陈理中汤
```

### 1.2 脐风

```
脐风辨证论治
        │
        ├─ 症状：牙关紧闭、苦笑面容、四肢抽搐
        ├─ 病因：断脐不当、感染风毒
        ├─ 治法：祛风止痉，清热解毒
        └─ 方药：撮风散
```

### 1.3 脐部疾患

```
脐部疾患辨证论治
        │
        ├─ 脐湿
        │   ├─ 症状：脐部湿润、渗液
        │   ├─ 治法：收敛固涩
        │   └─ 方药：龙骨散
        │
        ├─ 脐疮
        │   ├─ 症状：脐部红肿、糜烂
        │   ├─ 治法：清热解毒
        │   └─ 方药：金黄散
        │
        └─ 脐突
            ├─ 症状：脐部膨出
            ├─ 治法：收敛固涩
            └─ 方药：二豆散
```

## 二、呼吸道疾病

### 2.1 感冒

```
小儿感冒辨证论治
        │
        ├─ 风寒感冒
        │   ├─ 症状：恶寒发热、无汗、鼻塞流清涕
        │   ├─ 治法：辛温解表
        │   └─ 方药：荆防败毒散
        │
        ├─ 风热感冒
        │   ├─ 症状：发热微恶风、有汗、鼻塞流黄涕
        │   ├─ 治法：辛凉解表
        │   └─ 方药：银翘散
        │
        ├─ 暑邪感冒
        │   ├─ 症状：发热、心烦口渴、肢体困重
        │   ├─ 治法：清暑解表
        │   └─ 方药：新加香薷饮
        │
        └─ 时邪感冒
            ├─ 症状：高热、头痛、呕吐
            ├─ 治法：清热解毒
            └─ 方药：银翘散合普济消毒饮
```

## 五、传染病

```
麻疹辨证论治
        │
        ├─ 初热期（前驱期）

        │   ├─ 治法：辛凉透表，清宣肺卫
        │   └─ 方药：宣毒发表汤

        ├─ 出疹期
        │   ├─ 症状：皮疹按顺序出疹
        │   ├─ 治法：清热解毒，透疹达邪
        │   └─ 方药：清解透表汤
        │
        └─ 恢复期
            ├─ 症状：皮疹消退、皮肤脱屑
            ├─ 治法：养阴生津，清解余邪
            └─ 方药：沙参麦冬汤
```

        │
        ├─ 急惊风
        │   ├─ 感受风邪：发热、抽搐
        │   │   ├─ 治法：疏风清热，息风镇惊
        │   │   └─ 方药：银翘散

        │   ├─ 温热疫毒：高热、抽搐
        │   │   ├─ 治法：清热解毒，息风开窍
        │   │   └─ 方药：清瘟败毒饮
        │   │
        │   └─ 暴受惊恐：惊惕不安、抽搐
        │       ├─ 治法：镇惊安神
        │       └─ 方药：琥珀抱龙丸
        │
        └─ 慢惊风
            ├─ 脾虚肝旺：抽搐无力、面色萎黄
            │   ├─ 治法：温中健脾，缓肝理脾
            │   └─ 方药：缓肝理脾汤

                └─ 方药：大定风珠

## 总结

中医儿科通过辨证论治治疗各种儿科疾病，强调小儿生理特点（脏腑娇嫩、形气未充）和病理特点（发病容易、传变迅速），根据不同的病因和证型采用不同的治疗方法。
