# 检验医学基础

## 概述

检验医学是通过实验室检查为疾病诊断、治疗和预防提供依据的学科，包括血液检查、生化检查、微生物检查等。

---

## 一、检验医学分类

### 1.1 临床检验分类

```
临床检验分类
        │
        ├─ 血液检验：血常规、凝血功能、血型
        ├─ 生化检验：肝功能、肾功能、血糖、血脂
        ├─ 免疫检验：抗体检测、抗原检测
        ├─ 微生物检验：细菌培养、病毒检测
        ├─ 分子生物学检验：核酸检测、基因检测
        └─ 细胞学检验：病理细胞学检查
```

### 1.2 检验项目

```
常用检验项目
        │
        ├─ 血常规：白细胞、红细胞、血小板
        ├─ 生化全项：肝功能、肾功能、血糖、血脂
        ├─ 凝血功能：凝血酶原时间、活化部分凝血活酶时间
        ├─ 尿液分析：尿常规、尿培养
        ├─ 粪便检查：大便常规、隐血试验
        └─ 肿瘤标志物：CEA、AFP、CA125、PSA
```

## 二、血液检验

### 2.1 血常规

```
血常规指标
        │
        ├─ 白细胞（WBC）
        │   ├─ 总数：4-10×10^9/L
        │   ├─ 分类计数：中性粒细胞、淋巴细胞、单核细胞、嗜酸性粒细胞、嗜碱性粒细胞
        │   ├─ 升高：感染、炎症、白血病
        │   └─ 降低：病毒感染、骨髓抑制
        │
        ├─ 红细胞（RBC）
        │   ├─ 总数：男性4.0-5.5×10^12/L，女性3.5-5.0×10^12/L
        │   ├─ 血红蛋白（Hb）：男性120-160g/L，女性110-150g/L
        │   ├─ 升高：脱水、真性红细胞增多症
        │   └─ 降低：贫血
        │
        └─ 血小板（PLT）
            ├─ 总数：100-300×10^9/L
            ├─ 升高：感染、创伤、血小板增多症
            └─ 降低：血小板减少性紫癜、骨髓抑制
```

### 2.2 贫血诊断

```
贫血诊断标准
        │
        ├─ 男性：Hb < 120g/L
        ├─ 女性：Hb < 110g/L
        ├─ 孕妇：Hb < 100g/L
        │
        ├─ 贫血分类（按MCV、MCH、MCHC）
        │   ├─ 小细胞低色素性贫血：缺铁性贫血
        │   ├─ 大细胞性贫血：巨幼细胞性贫血
        │   └─ 正常细胞性贫血：再生障碍性贫血、溶血性贫血
        │
        └─ 贫血原因
            ├─ 铁缺乏：缺铁性贫血
            ├─ 维生素B12缺乏：巨幼细胞性贫血
            ├─ 叶酸缺乏：巨幼细胞性贫血
            └─ 骨髓功能障碍：再生障碍性贫血
```

### 2.3 凝血功能

```
凝血功能指标
        │
        ├─ 凝血酶原时间（PT）：11-13秒
        │   ├─ 延长：凝血因子缺乏、抗凝药物
        │   └─ 缩短：高凝状态
        │
        ├─ 活化部分凝血活酶时间（APTT）：31-43秒
        │   ├─ 延长：内源性凝血因子缺乏
        │   └─ 缩短：高凝状态
        │
        ├─ 纤维蛋白原（FIB）：2-4g/L
        │   ├─ 升高：感染、炎症、肿瘤
        │   └─ 降低：DIC、肝脏疾病
        │
        └─ 凝血酶时间（TT）：16-18秒
            ├─ 延长：纤维蛋白原缺乏、肝素治疗
            └─ 缩短：高纤维蛋白原血症
```

## 三、生化检验

### 3.1 肝功能

```
肝功能指标
        │
        ├─ 转氨酶：ALT、AST
        │   ├─ ALT（谷丙转氨酶）：5-40U/L
        │   ├─ AST（谷草转氨酶）：5-40U/L
        │   ├─ 升高：肝细胞损伤
        │   └─ AST/ALT比值：判断肝损伤类型
        │
        ├─ 胆红素：总胆红素、直接胆红素、间接胆红素
        │   ├─ 总胆红素：3.4-17.1μmol/L
        │   ├─ 升高：黄疸
        │   ├─ 直接胆红素升高：胆道梗阻
        │   └─ 间接胆红素升高：溶血
        │
        ├─ 白蛋白和球蛋白
        │   ├─ 白蛋白：35-55g/L
        │   ├─ 球蛋白：20-30g/L
        │   ├─ 白蛋白降低：肝脏疾病、营养不良
        │   └─ 球蛋白升高：慢性感染、自身免疫病
        │
        └─ 碱性磷酸酶（ALP）和γ-谷氨酰转移酶（GGT）
            ├─ ALP：40-150U/L
            ├─ GGT：11-50U/L
            └─ 升高：胆道梗阻、肝胆疾病
```

### 3.2 肾功能

```
肾功能指标
        │
        ├─ 肌酐（Cr）：男性53-106μmol/L，女性44-97μmol/L
        │   ├─ 升高：肾功能损伤
        │   └─ 估算肾小球滤过率（eGFR）：评估肾功能
        │
        ├─ 尿素氮（BUN）：3.2-7.1mmol/L
        │   ├─ 升高：肾功能损伤、脱水、高蛋白饮食
        │   └─ 降低：肝功能障碍
        │
        ├─ 尿酸（UA）：男性208-428μmol/L，女性155-357μmol/L
        │   ├─ 升高：高尿酸血症、痛风
        │   └─ 降低：肝功能障碍
        │
        └─ 电解质：钾、钠、氯、碳酸氢根
            ├─ 钾：3.5-5.5mmol/L
            ├─ 钠：135-145mmol/L
            ├─ 氯：96-106mmol/L
            └─ 碳酸氢根：22-27mmol/L
```

### 3.3 血糖和糖化血红蛋白

```
血糖指标
        │
        ├─ 空腹血糖（FPG）：3.9-6.1mmol/L
        │   ├─ 升高：糖尿病
        │   └─ 糖尿病诊断：FPG ≥ 7.0mmol/L
        │
        ├─ 餐后2小时血糖（2hPG）：< 7.8mmol/L
        │   ├─ 升高：糖耐量异常
        │   └─ 糖尿病诊断：2hPG ≥ 11.1mmol/L
        │
        ├─ 随机血糖：< 11.1mmol/L
        │   └─ 糖尿病诊断：随机血糖 ≥ 11.1mmol/L，伴糖尿病症状
        │
        └─ 糖化血红蛋白（HbA1c）：4%-6%
            ├─ 反映近2-3个月平均血糖
            ├─ 糖尿病诊断：HbA1c ≥ 6.5%
            └─ 糖尿病控制目标：HbA1c < 7%
```

### 3.4 血脂

```
血脂指标
        │
        ├─ 总胆固醇（TC）：< 5.2mmol/L
        ├─ 甘油三酯（TG）：< 1.7mmol/L
        ├─ 低密度脂蛋白胆固醇（LDL-C）：< 2.6mmol/L
        │   └─ 升高：动脉粥样硬化危险因素
        ├─ 高密度脂蛋白胆固醇（HDL-C）：> 1.0mmol/L
        │   └─ 降低：动脉粥样硬化危险因素
        └─ 血脂异常分类
            ├─ 高胆固醇血症：TC升高
            ├─ 高甘油三酯血症：TG升高
            ├─ 混合型高脂血症：TC和TG均升高
            └─ 低高密度脂蛋白血症：HDL-C降低
```

## 四、免疫检验

### 4.1 感染性疾病检测

```
感染性疾病检测
        │
        ├─ 病毒检测
        │   ├─ 乙肝病毒：HBsAg、HBsAb、HBeAg、HBeAb、HBcAb
        │   ├─ 丙肝病毒：HCV抗体、HCV RNA
        │   ├─ 艾滋病病毒：HIV抗体、HIV RNA
        │   └─ 流感病毒：流感抗原、流感核酸
        │
        ├─ 细菌检测
        │   ├─ 结核分枝杆菌：结核菌素试验、结核抗体、结核核酸
        │   ├─ 幽门螺杆菌：幽门螺杆菌抗体、碳13/碳14呼气试验
        │   └─ 链球菌：链球菌抗原、链球菌抗体
        │
        └─ 其他病原体检测
            ├─ 梅毒螺旋体：梅毒抗体
            ├─ 支原体：支原体抗体、支原核酸
            └─ 衣原体：衣原体抗体、衣原体核酸
```

### 4.2 自身免疫性疾病检测

```
自身免疫性疾病检测
        │
        ├─ 类风湿关节炎：类风湿因子、抗CCP抗体
        ├─ 系统性红斑狼疮：抗核抗体、抗双链DNA抗体、抗Sm抗体
        ├─ 干燥综合征：抗SSA抗体、抗SSB抗体
        ├─ 硬皮病：抗Scl-70抗体
        └─ 多发性肌炎/皮肌炎：抗Jo-1抗体
```

### 4.3 肿瘤标志物

```
肿瘤标志物
        │
        ├─ 癌胚抗原（CEA）：< 5ng/mL
        │   ├─ 升高：结直肠癌、胃癌、肺癌
        │   └─ 注意：吸烟、炎症也可能升高
        │
        ├─ 甲胎蛋白（AFP）：< 25ng/mL
        │   ├─ 升高：原发性肝癌、生殖细胞肿瘤
        │   └─ 注意：肝炎、肝硬化也可能升高
        │
        ├─ CA125：< 35U/mL
        │   ├─ 升高：卵巢癌、子宫内膜癌
        │   └─ 注意：盆腔炎、子宫内膜异位症也可能升高
        │
        ├─ PSA：< 4ng/mL
        │   ├─ 升高：前列腺癌
        │   └─ 注意：前列腺增生也可能升高
        │
        └─ CA19-9：< 37U/mL
            ├─ 升高：胰腺癌、胆管癌、结直肠癌
            └─ 注意：胆管炎、胰腺炎也可能升高
```

## 五、微生物检验

### 5.1 细菌培养

```
细菌培养流程
        │
        ├─ 标本采集：血液、痰液、尿液、脓液
        ├─ 接种培养：接种到培养基
        ├─ 菌落观察：观察菌落形态
        ├─ 细菌鉴定：生化鉴定或质谱鉴定
        ├─ 药敏试验：测定抗生素敏感性
        └─ 报告结果：细菌种类和药敏结果
```

### 5.2 药敏试验

```
药敏试验方法
        │
        ├─ 纸片扩散法：将抗生素纸片贴在接种细菌的培养基上
        ├─ 稀释法：测定最低抑菌浓度（MIC）
        ├─ E-test法：定量测定MIC
        └─ 自动化药敏系统：快速药敏检测
```

### 5.3 抗生素敏感性判断

```
抗生素敏感性判断标准
        │
        ├─ 敏感（S）：细菌对药物敏感，治疗有效
        ├─ 中介（I）：细菌对药物中度敏感，需高剂量
        └─ 耐药（R）：细菌对药物耐药，治疗无效
```

## 六、分子生物学检验

### 6.1 核酸检测

```
核酸检测技术
        │
        ├─ PCR（聚合酶链式反应）：扩增DNA
        ├─ RT-PCR：扩增RNA
        ├─ qPCR（实时荧光定量PCR）：定量检测核酸
        ├─ NGS（下一代测序）：高通量测序
        └─ 核酸杂交：检测特定核酸序列
```

### 6.2 基因检测

```
基因检测应用
        │
        ├─ 遗传病诊断：染色体异常、单基因遗传病
        ├─ 肿瘤基因检测：肿瘤基因突变检测
        ├─ 药物基因组学：药物代谢基因检测
        └─ 亲子鉴定：DNA比对
```

## 七、检验结果解读

### 7.1 结果解读原则

```
检验结果解读原则
        │
        ├─ 结合临床：结合患者症状和体征
        ├─ 动态观察：对比多次检查结果
        ├─ 注意干扰因素：药物、饮食、标本采集
        ├─ 参考范围：结合实验室参考范围
        └─ 综合判断：综合多项检查结果
```

### 7.2 危急值报告

```
危急值项目
        │
        ├─ 血常规：白细胞显著升高或降低、血小板显著降低
        ├─ 生化：血钾显著升高或降低、血糖显著升高或降低
        ├─ 凝血功能：PT和APTT显著延长
        └─ 血气分析：严重酸中毒或碱中毒
```

---

## 总结

检验医学是临床医学的重要组成部分，通过实验室检查为疾病诊断、治疗和预防提供重要依据。掌握常用检验项目的意义和解读方法，对于临床工作至关重要。
