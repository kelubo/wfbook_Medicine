# 心血管疾病

## 概述

心血管疾病是影响心脏和血管的疾病总称，是全球主要的死亡原因之一。

---

## 一、冠心病

### 1.1 冠心病的概念

冠心病是由于冠状动脉粥样硬化导致心肌缺血缺氧的疾病。

```
冠心病类型
        │
        ├─ 无症状性心肌缺血：无症状，但有缺血证据
        │
        ├─ 心绞痛：暂时性心肌缺血引起胸痛
        │   ├─ 稳定型心绞痛：劳动诱发
        │   └─ 不稳定型心绞痛：休息时也可能发作
        │
        ├─ 心肌梗死：冠状动脉完全堵塞
        │   ├─ ST段抬高型心肌梗死
        │   └─ 非ST段抬高型心肌梗死
        │
        └─ 缺血性心肌病：长期缺血导致心肌纤维化
```

### 1.2 冠心病症状

```
冠心病症状
        │
        ├─ 胸痛：压榨性、紧缩性疼痛
        │   ├─ 部位：胸骨后
        │   ├─ 放射：向左肩、左臂、颈部、下颌放射
        │   └─ 持续时间：数分钟
        │
        ├─ 胸闷：胸部压迫感
        ├─ 呼吸困难：气短、喘息
        ├─ 心悸：心慌
        └─ 其他：恶心、呕吐、出冷汗
```

### 1.3 冠心病诊断

```
冠心病诊断方法
        │
        ├─ 心电图：记录心脏电活动
        │   ├─ 静息心电图
        │   └─ 运动负荷试验
        │
        ├─ 冠状动脉造影：金标准
        │   ├─ 显示冠状动脉狭窄程度
        │   └─ 指导治疗
        │
        ├─ 超声心动图：观察心脏结构和功能
        ├─ 血液检查：心肌酶、肌钙蛋白
        └─ 冠状动脉CT：无创检查
```

### 1.4 冠心病治疗

```
冠心病治疗方法
        │
        ├─ 药物治疗
        │   ├─ 抗血小板药物：阿司匹林、氯吡格雷
        │   ├─ 他汀类药物：阿托伐他汀、瑞舒伐他汀
        │   ├─ β受体阻滞剂：美托洛尔
        │   ├─ 硝酸酯类：硝酸甘油
        │   └─ 钙通道阻滞剂：硝苯地平
        │
        ├─ 介入治疗
        │   ├─ 冠状动脉支架植入术
        │   └─ 球囊扩张术
        │
        └─ 手术治疗
            └─ 冠状动脉旁路移植术（搭桥手术）
```

## 二、心律失常

### 2.1 心律失常的概念

心律失常是心脏节律异常的疾病。

```
心律失常分类
        │
        ├─ 窦性心律失常
        │   ├─ 窦性心动过速：心率 > 100次/分钟
        │   ├─ 窦性心动过缓：心率 < 60次/分钟
        │   └─ 窦性心律不齐：节律不规则
        │
        ├─ 房性心律失常
        │   ├─ 房性早搏：提前出现的房性搏动
        │   ├─ 心房颤动：心房不规则跳动
        │   └─ 心房扑动：心房快速规则跳动
        │
        ├─ 室性心律失常
        │   ├─ 室性早搏：提前出现的室性搏动
        │   ├─ 室性心动过速：连续3个以上室性早搏
        │   └─ 心室颤动：心室不规则跳动，危及生命
        │
        └─ 传导阻滞
            ├─ 房室传导阻滞：心房到心室传导延迟
            └─ 室内传导阻滞：心室内传导延迟
```

### 2.2 心律失常症状

```
心律失常症状
        │
        ├─ 心悸：心慌、心跳不规律
        ├─ 胸闷：胸部不适
        ├─ 头晕：眩晕感
        ├─ 黑朦：眼前发黑
        ├─ 晕厥：突然晕倒
        └─ 呼吸困难：气短
```

### 2.3 心律失常治疗

```
心律失常治疗方法
        │
        ├─ 药物治疗：抗心律失常药物
        ├─ 电复律：电击恢复正常节律
        ├─ 射频消融：消除异常起搏点
        ├─ 起搏器植入：治疗心动过缓
        └─ 植入式心律转复除颤器：治疗危及生命的心律失常
```

## 三、心力衰竭

### 3.1 心力衰竭的概念

心力衰竭是心脏泵血功能下降的疾病。

```
心力衰竭分类
        │
        ├─ 按部位分
        │   ├─ 左心衰竭：左心室功能障碍
        │   ├─ 右心衰竭：右心室功能障碍
        │   └─ 全心衰竭：左右心室均受累
        │
        ├─ 按功能分
        │   ├─ 收缩性心力衰竭：收缩功能下降
        │   └─ 舒张性心力衰竭：舒张功能下降
        │
        └─ 按程度分
            ├─ Ⅰ级：日常活动不受限
            ├─ Ⅱ级：日常活动轻度受限
            ├─ Ⅲ级：日常活动明显受限
            └─ Ⅳ级：休息时也有症状
```

### 3.2 心力衰竭症状

```
心力衰竭症状
        │
        ├─ 左心衰竭症状
        │   ├─ 呼吸困难：劳力性、夜间阵发性、端坐呼吸
        │   ├─ 咳嗽：白色泡沫痰
        │   ├─ 乏力：疲劳感
        │   └─ 少尿：尿量减少
        │
        └─ 右心衰竭症状
            ├─ 水肿：下肢水肿、腹水
            ├─ 腹胀：肝肿大
            ├─ 颈静脉怒张：颈部静脉充盈
            └─ 食欲不振：胃肠淤血
```

### 3.3 心力衰竭治疗

```
心力衰竭治疗方法
        │
        ├─ 药物治疗
        │   ├─ 利尿剂：呋塞米、螺内酯
        │   ├─ ACEI/ARB：卡托普利、缬沙坦
        │   ├─ β受体阻滞剂：美托洛尔
        │   ├─ 正性肌力药：地高辛
        │   └─ 血管扩张剂：硝酸甘油
        │
        ├─ 非药物治疗
        │   ├─ 心脏再同步化治疗
        │   ├─ 植入式心律转复除颤器
        │   └─ 心脏移植
        │
        └─ 生活方式管理
            ├─ 限制钠盐摄入
            ├─ 控制体重
            ├─ 适度运动
            └─ 戒烟限酒
```

## 四、心血管疾病预防

```
心血管疾病预防措施
        │
        ├─ 控制危险因素
        │   ├─ 控制血压：高血压患者规律服药
        │   ├─ 控制血糖：糖尿病患者控制血糖
        │   ├─ 控制血脂：高血脂患者服药
        │   ├─ 戒烟限酒：戒烟，限酒
        │   └─ 控制体重：避免肥胖
        │
        ├─ 健康生活方式
        │   ├─ 均衡饮食：多吃蔬菜水果，少吃油腻
        │   ├─ 规律运动：每周至少150分钟有氧运动
        │   └─ 保持心理平衡：减轻压力
        │
        └─ 定期体检
            ├─ 心电图检查
            ├─ 血压测量
            ├─ 血脂检查
            └─ 血糖检查
```

---

## 总结

心血管疾病是常见的慢性疾病，通过控制危险因素、保持健康生活方式和定期体检，可以有效预防和管理心血管疾病。
