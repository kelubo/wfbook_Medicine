# 病理学

## 概述

病理学是研究疾病发生、发展和转归规律的科学，是医学的重要基础学科。

---

## 一、疾病概论

### 1.1 疾病的概念

疾病是机体在一定病因作用下发生的异常生命活动过程。

```
疾病过程
        │
        ├─ 病因：引起疾病的原因
        ├─ 发病机制：疾病发生发展的机制
        ├─ 病理变化：形态、功能、代谢改变
        └─ 转归：痊愈、死亡、后遗症
```

### 1.2 病因学

病因学研究疾病的原因。

```
病因分类
        │
        ├─ 生物因素：细菌、病毒、寄生虫
        ├─ 物理因素：机械力、温度、辐射
        ├─ 化学因素：毒物、药物
        ├─ 营养因素：缺乏或过剩
        ├─ 遗传因素：基因突变
        ├─ 免疫因素：自身免疫、过敏
        └─ 环境因素：污染、气候
```

## 二、细胞和组织的适应、损伤与修复

### 2.1 适应

适应是细胞和组织对环境变化的反应。

| 适应类型 | 表现 | 意义 |
|----------|------|------|
| 萎缩 | 体积缩小 | 节省能量 |
| 肥大 | 体积增大 | 增强功能 |
| 增生 | 数量增多 | 增强功能 |
| 化生 | 类型转变 | 适应新环境 |

### 2.2 损伤

损伤是细胞和组织受到的破坏。

```
损伤类型
        │
        ├─ 可逆性损伤
        │   ├─ 细胞水肿：钠钾泵功能障碍
        │   ├─ 脂肪变性：脂肪堆积
        │   ├─ 玻璃样变性：蛋白质沉积
        │   └─ 病理性钙化：钙盐沉积
        │
        └─ 不可逆性损伤
            ├─ 细胞死亡
            │   ├─ 坏死：病理性死亡
            │   └─ 凋亡：程序性死亡
            └─ 组织坏死
                ├─ 凝固性坏死
                ├─ 液化性坏死
                └─ 坏疽
```

### 2.3 修复

修复是组织损伤后的愈合过程。

```
修复过程
        │
        ├─ 再生：同种细胞修复
        │   ├─ 完全再生：功能恢复
        │   └─ 不完全再生：疤痕修复
        │
        ├─ 纤维性修复：结缔组织修复
        │   ├─ 肉芽组织形成
        │   └─ 疤痕组织形成
        │
        └─ 创伤愈合
            ├─ 一期愈合：伤口整齐
            └─ 二期愈合：伤口较大
```

## 三、炎症

### 3.1 炎症的概念

炎症是机体对损伤的防御反应。

```
炎症过程
        │
        ├─ 血管反应
        │   ├─ 血管扩张：血流加快
        │   ├─ 血管通透性增加：液体渗出
        │   └─ 白细胞渗出：炎症细胞浸润
        │
        ├─ 炎症介质
        │   ├─ 血管活性物质：组胺、缓激肽
        │   ├─ 细胞因子：白细胞介素、肿瘤坏死因子
        │   └─ 前列腺素：发热、疼痛
        │
        └─ 炎症细胞
            ├─ 中性粒细胞：急性炎症
            ├─ 淋巴细胞：慢性炎症
            └─ 巨噬细胞：吞噬作用
```

### 3.2 炎症类型

| 炎症类型 | 特点 | 常见疾病 |
|----------|------|----------|
| 浆液性炎 | 渗出液为主 | 皮肤水泡 |
| 纤维素性炎 | 纤维蛋白渗出 | 白喉、大叶性肺炎 |
| 化脓性炎 | 中性粒细胞渗出 | 脓肿、蜂窝织炎 |
| 出血性炎 | 红细胞渗出 | 流行性出血热 |

### 3.3 炎症的临床表现

```
炎症表现
        │
        ├─ 红：血管扩张
        ├─ 肿：液体渗出
        ├─ 热：代谢增强
        ├─ 痛：炎症介质刺激
        └─ 功能障碍：组织损伤
```

## 四、肿瘤

### 4.1 肿瘤的概念

肿瘤是机体细胞异常增生形成的肿块。

```
肿瘤分类
        │
        ├─ 良性肿瘤：生长缓慢，不转移
        ├─ 恶性肿瘤：生长迅速，可转移
        │   ├─ 癌：上皮组织来源
        │   └─ 肉瘤：间叶组织来源
        └─ 交界性肿瘤：介于良恶性之间
```

### 4.2 肿瘤的特征

| 特征 | 良性肿瘤 | 恶性肿瘤 |
|------|----------|----------|
| 生长速度 | 缓慢 | 迅速 |
| 浸润性 | 无 | 有 |
| 转移 | 无 | 有 |
| 分化程度 | 高 | 低 |
| 复发 | 无 | 有 |

### 4.3 肿瘤的扩散

```
肿瘤扩散方式
        │
        ├─ 直接蔓延：侵犯邻近组织
        │
        ├─ 淋巴道转移：通过淋巴管转移
        │   └─ 淋巴结肿大
        │
        └─ 血道转移：通过血液转移
            ├─ 肺转移
            ├─ 肝转移
            └─ 骨转移
```

## 五、心血管系统疾病

### 5.1 动脉粥样硬化

动脉粥样硬化是血管内膜脂质沉积形成斑块。

```
动脉粥样硬化过程
        │
        ├─ 脂质条纹期：脂质沉积
        ├─ 纤维斑块期：纤维组织增生
        ├─ 粥样斑块期：脂质坏死
        └─ 复合病变期：斑块破裂、出血、钙化
```

### 5.2 高血压

高血压是血压持续升高。

```
高血压类型
        │
        ├─ 原发性高血压：原因不明
        ├─ 继发性高血压：由其他疾病引起
        │   ├─ 肾性高血压
        │   ├─ 内分泌性高血压
        │   └─ 血管性高血压
        └─ 恶性高血压：血压急剧升高
```

### 5.3 心力衰竭

心力衰竭是心脏泵血功能下降。

| 类型 | 表现 |
|------|------|
| 左心衰竭 | 呼吸困难、肺水肿 |
| 右心衰竭 | 水肿、肝肿大 |
| 全心衰竭 | 两者同时存在 |

## 六、呼吸系统疾病

### 6.1 肺炎

肺炎是肺部的炎症。

```
肺炎类型
        │
        ├─ 大叶性肺炎：肺泡炎症
        │   ├─ 充血水肿期
        │   ├─ 红色肝样变期
        │   ├─ 灰色肝样变期
        │   └─ 溶解消散期
        │
        ├─ 小叶性肺炎：细支气管炎症
        └─ 间质性肺炎：肺间质炎症
```

### 6.2 慢性阻塞性肺疾病

慢性阻塞性肺疾病是气道慢性炎症。

```
COPD组成
        │
        ├─ 慢性支气管炎：气道慢性炎症
        │   ├─ 咳嗽、咳痰
        │   └─ 持续3个月以上
        │
        └─ 肺气肿：肺泡过度充气
            ├─ 呼吸困难
            └─ 桶状胸
```

## 七、消化系统疾病

### 7.1 胃炎

胃炎是胃黏膜的炎症。

```
胃炎类型
        │
        ├─ 急性胃炎：短期发作
        │   ├─ 急性单纯性胃炎
        │   └─ 急性糜烂出血性胃炎
        │
        └─ 慢性胃炎：长期存在
            ├─ 慢性浅表性胃炎
            └─ 慢性萎缩性胃炎
```

### 7.2 消化性溃疡

消化性溃疡是胃或十二指肠黏膜的溃疡。

```
溃疡特点
        │
        ├─ 胃溃疡：胃黏膜溃疡
        │   ├─ 疼痛：餐后半小时至1小时
        │   └─ 部位：胃窦部
        │
        └─ 十二指肠溃疡：十二指肠黏膜溃疡
            ├─ 疼痛：空腹或夜间
            └─ 部位：十二指肠球部
```

## 八、泌尿系统疾病

### 8.1 肾小球疾病

肾小球疾病是肾小球的炎症。

```
肾小球疾病类型
        │
        ├─ 急性肾小球肾炎：链球菌感染后
        │   ├─ 血尿、蛋白尿
        │   ├─ 水肿
        │   └─ 高血压
        │
        ├─ 慢性肾小球肾炎：长期存在
        │   ├─ 蛋白尿、血尿
        │   ├─ 水肿
        │   └─ 肾功能损害
        │
        └─ 肾病综合征：大量蛋白尿
            ├─ 大量蛋白尿
            ├─ 低蛋白血症
            ├─ 水肿
            └─ 高脂血症
```

### 8.2 肾功能衰竭

肾功能衰竭是肾脏功能严重障碍。

```
肾功能衰竭类型
        │
        ├─ 急性肾功能衰竭：短期内发生
        │   ├─ 少尿期：尿量减少
        │   ├─ 多尿期：尿量增多
        │   └─ 恢复期：功能恢复
        │
        └─ 慢性肾功能衰竭：长期发展
            ├─ 肾功能代偿期
            ├─ 肾功能失代偿期
            ├─ 肾功能衰竭期
            └─ 尿毒症期
```

## 九、免疫病理

### 9.1 超敏反应

超敏反应是机体对某些抗原产生的异常免疫应答。

| 类型 | 机制 | 代表疾病 | 发生时间 |
|:---:|------|----------|:---:|
| I 型（速发型） | IgE + 肥大细胞 → 组胺释放 | 过敏性鼻炎、荨麻疹、过敏性休克 | 数分钟 |
| II 型（细胞毒型） | IgG/IgM → 靶细胞破坏 | 自身免疫性溶血性贫血、输血反应 | 数小时 |
| III 型（免疫复合物型） | 免疫复合物沉积 → 补体激活 | 系统性红斑狼疮 (SLE)、血清病 | 数小时 |
| IV 型（迟发型） | T 细胞介导 | 结核菌素反应、接触性皮炎、移植排斥 | 24~72 小时 |

### 9.2 自身免疫病

免疫系统攻击自身组织所致的疾病。

| 疾病 | 靶组织 | 临床特征 |
|------|--------|---------|
| 系统性红斑狼疮 (SLE) | 全身多系统 | 面部蝶形红斑、肾损害、关节痛 |
| 类风湿关节炎 | 关节滑膜 | 对称性多关节炎、晨僵 |
| 1 型糖尿病 | 胰岛 β 细胞 | 胰岛素绝对缺乏，需终身注射 |
| 桥本氏甲状腺炎 | 甲状腺 | 甲状腺功能减退 |
| 重症肌无力 | 乙酰胆碱受体 | 肌肉无力、易疲劳 |

### 9.3 免疫缺陷病

```
免疫缺陷病分类
        │
        ├─ 原发性免疫缺陷：基因突变所致（如严重联合免疫缺陷 SCID）
        └─ 继发性免疫缺陷
            ├─ 获得性免疫缺陷综合征 (AIDS)：HIV 病毒破坏 CD4+ T 细胞
            ├─ 药物性：免疫抑制剂、化疗药物
            └─ 营养不良、恶性肿瘤
```

## 十、传染病

传染病由病原微生物引起，具有传染性和流行性。

### 10.1 传染病的基本特征

| 特征 | 说明 |
|------|------|
| 病原体 | 细菌、病毒、真菌、寄生虫等 |
| 传染性 | 能从患者或携带者传给他人 |
| 流行性 | 在人群中可广泛传播 |
| 免疫性 | 病后可获得不同程度的免疫力 |

### 10.2 传染病传播途径

```
传播途径
        │
        ├─ 呼吸道传播：飞沫、空气（流感、肺结核、COVID-19）
        ├─ 消化道传播：食物、水（霍乱、甲肝、伤寒）
        ├─ 血液传播：输血、注射（乙肝、丙肝、HIV）
        ├─ 接触传播：直接/间接接触（性传播疾病、皮肤感染）
        ├─ 虫媒传播：蚊、蜱等叮咬（疟疾、登革热）
        └─ 垂直传播：母婴传播（乙肝、HIV、梅毒）
```

### 10.3 常见传染病病理

| 疾病 | 病原体 | 主要病理改变 |
|------|--------|-------------|
| 肺结核 | 结核分枝杆菌 | 干酪样坏死、肉芽肿（结核结节） |
| 肝炎 | HAV/HBV/HCV | 肝细胞变性坏死、炎症浸润 → 纤维化 → 肝硬化 |
| 流行性感冒 | 流感病毒 | 呼吸道黏膜充血、水肿、上皮坏死 |
| 细菌性痢疾 | 志贺菌 | 结肠黏膜溃疡、假膜形成 |
| 艾滋病 | HIV | CD4+ T 细胞进行性减少 → 免疫崩溃 → 机会性感染 |

### 10.4 感染的发生发展

```
感染过程
        │
        ├─ 潜伏期：病原体进入机体到出现症状
        ├─ 前驱期：非特异症状（乏力、发热）
        ├─ 症状明显期：典型临床表现
        └─ 转归期：恢复或转为慢性/死亡
```

## 十一、遗传性疾病

遗传病是由遗传物质（DNA/染色体）改变引起的疾病。

### 11.1 遗传病分类

```
遗传病分类
        │
        ├─ 单基因遗传病（孟德尔遗传）
        │   ├─ 常染色体显性：多指症、马凡综合征
        │   ├─ 常染色体隐性：白化病、苯丙酮尿症
        │   ├─ X 连锁显性：抗维生素 D 佝偻病
        │   └─ X 连锁隐性：血友病 A、红绿色盲
        │
        ├─ 多基因遗传病：高血压、糖尿病、唇腭裂（基因+环境）
        │
        └─ 染色体病
            ├─ 数目异常：21 三体（唐氏综合征）、Turner 综合征 (45,XO)
            └─ 结构异常：染色体缺失、易位、倒位
```

### 11.2 遗传病的特征

| 特征 | 说明 |
|------|------|
| 家族聚集性 | 在同一家族中多人患病 |
| 垂直传递 | 从上一代传给下一代 |
| 先天性 | 多数出生时即已存在（但不等于先天性疾病） |
| 终身性 | 通常终身存在，难以根治 |

## 总结

病理学研究疾病的发生发展规律，为疾病诊断和治疗提供理论依据，是医学的重要基础学科。
