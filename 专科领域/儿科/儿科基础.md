# 儿科基础

## 概述

儿科学是研究小儿各时期生长发育、疾病防治的临床医学分支。小儿不是"缩小版成人"——其解剖、生理、免疫、病理和疾病谱均有独特性。

> 年龄范围：自胎儿期至青春期（0~18 岁）。

---

## 一、小儿年龄分期

| 分期 | 年龄 | 特点 |
|:---|:---|------|
| 胎儿期 | 受精 ~ 出生 | 器官分化发育关键期；药物/感染致畸敏感期 |
| 新生儿期 | 出生 ~ 28 天 | 适应宫外环境；死亡率最高期 |
| 婴儿期 | 出生 ~ 1 岁 | 生长发育第一个高峰期 |
| 幼儿期 | 1 ~ 3 岁 | 活动范围扩大→意外伤害高发 |
| 学龄前期 | 3 ~ 6/7 岁 | 智力发展迅速；可塑性强 |
| 学龄期 | 6/7 ~ 11/12 岁 | 除生殖系统外各器官趋成熟 |
| 青春期 | 女 9~12 起、男 11~13 起 | 第二性征发育；生长发育第二个高峰 |

### 2.2 生长发育规律

```
生长发育规律
        │
        ├─ 由上到下：先抬头→抬胸→坐→走
        ├─ 由近到远：先躯干→再四肢
        ├─ 由粗到细：全掌握物→拇食指捏取
        ├─ 由低级到高级：先视/听感觉→思维能力
        └─ 由简单到复杂：单字→词→短句→复句
```

## 三、小儿生理特点

### 3.1 免疫特点

```
小儿免疫发育
        │
        ├─ 被动免疫（母传抗体）
        │   ├─ IgG 通过胎盘——出生后 6 个月内保护
        │   └─ IgA 通过母乳——保护肠道和呼吸道黏膜
        │
        └─ 主动免疫
            ├─ 出生时 IgG 合成能力低 → 6 月后母体抗体衰减 →"免疫空白期"
            ├─ SigA 产生不足 → 易患呼吸道和肠道感染
            └─ 渐趋完善：5~6 岁后接近成人水平
```

### 3.2 中医小儿生理特点

| 特点 | 含义 |
|:---|------|
| 脏腑娇嫩 | 五脏六腑形气未充——肺脾肾常不足 |
| 形气未充 | 物质基础和功能活动未完善 |
| 生机蓬勃 | 生长发育迅速——"纯阳之体" |
| 发病容易 | "易虚易实、易寒易热"——传变迅速 |
| 康复迅速 | 脏气清灵——随拨随应、恢复较快 |

## 四、小儿常见疾病

### 4.1 呼吸系统

| 疾病 | 病因 | 处理要点 |
|:---|:---|:---|
| 急性上呼吸道感染（感冒） | 病毒为主 | 对症支持——多饮水、休息；慎用复方感冒药（< 2 岁不推荐） |
| 急性支气管炎 | 病毒/细菌 | 对症止咳化痰 |
| 肺炎 | 细菌/病毒/支原体 | **危险信号**：气促、鼻翼煽动、三凹征→立即就医 |
| 急性喉炎 | 病毒——声门下水肿 | **急诊**：犬吠样咳嗽、吸气性喉鸣 |

### 4.2 消化系统

| 疾病 | 要点 |
|:---|:---|
| 小儿腹泻病 | 最重要的治疗——**预防和纠正脱水**（口服补液盐 ORS） |
| 肠套叠 | 阵发性哭闹 + 果酱样便 → 急诊空气灌肠复位 |
| 秋季腹泻 | 轮状病毒——水样蛋花汤样便 |

### 4.3 营养性疾病

| 疾病 | 要点 |
|:---|:---|
| 维生素 D 缺乏性佝偻病 | 早期：夜惊、多汗、枕秃 → 强调补充 VitD（出生后即可开始） |
| 缺铁性贫血 | 高峰期 6~24 月——需及时添加含铁辅食 |
| 营养不良 | 体重下降是最早表现 |

### 4.4 中医儿科常见病

| 疾病 | 主治法 |
|:---|:---|
| 小儿积食 | 消食导滞——保和丸、捏脊 |
| 小儿夜啼 | 脾寒/心热/惊恐——辨证施治 |
| 小儿遗尿 | 温补肾阳——缩泉丸、针灸关元/三阴交 |
| 小儿疳积 | 健脾消积——疳积散、四缝穴点刺 |

## 六、儿科用药注意事项

| 要点 | 说明 |
|:---|------|
| 按体重计算剂量 | 最常用——mg/kg |
| 喹诺酮类 | **禁用**于 < 18 岁——影响软骨发育 |
| 四环素类 | **禁用**于 < 8 岁——牙齿黄染 |
| 氨基糖苷类 | 慎用——耳毒性和肾毒性 |
| 阿司匹林 | < 12 岁病毒感染时禁用——Reye 综合征风险 |
