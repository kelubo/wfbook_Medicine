# 药理学

## 概述

药理学是研究药物与机体相互作用规律的科学，包括药物代谢动力学和药物效应动力学。

---

## 一、药物代谢动力学

### 1.1 药物吸收

药物从给药部位进入血液循环的过程。

```
给药途径与吸收
        │
        ├─ 口服给药
        │   ├─ 优点：方便、安全
        │   ├─ 缺点：吸收慢、首过效应
        │   └─ 吸收部位：胃肠道
        │
        ├─ 注射给药
        │   ├─ 静脉注射：直接入血，快速
        │   ├─ 肌内注射：吸收较快
        │   ├─ 皮下注射：吸收较慢
        │   └─ 优点：吸收快、无首过效应
        │
        ├─ 吸入给药：直接进入呼吸道
        ├─ 皮肤给药：局部作用
        └─ 舌下给药：避免首过效应
```

### 1.2 药物分布

药物从血液循环到达组织器官的过程。

```
药物分布影响因素
        │
        ├─ 药物的理化性质：脂溶性、分子量
        ├─ 血浆蛋白结合率：结合药物不发挥作用
        ├─ 组织器官的血流量：血流量大的器官分布多
        ├─ 组织亲和力：药物与组织的结合能力
        └─ 血脑屏障：阻止药物进入脑组织
```

### 1.3 药物代谢

药物在体内发生化学变化的过程。

```
药物代谢部位
        │
        ├─ 肝脏：主要代谢器官
        │   ├─ 氧化反应
        │   ├─ 还原反应
        │   ├─ 水解反应
        │   └─ 结合反应
        │
        ├─ 肾脏：部分代谢
        ├─ 肠道：肠道细菌代谢
        └─ 其他器官：肺、皮肤
```

### 1.4 药物排泄

药物及其代谢产物排出体外的过程。

```
药物排泄途径
        │
        ├─ 肾脏排泄：主要途径
        │   ├─ 肾小球滤过
        │   ├─ 肾小管重吸收
        │   └─ 肾小管分泌
        │
        ├─ 胆汁排泄：肝脏代谢产物
        ├─ 肠道排泄：未吸收药物
        ├─ 肺排泄：挥发性药物
        └─ 皮肤排泄：少量药物
```

## 二、药物效应动力学

### 2.1 药物作用机制

药物通过与靶点结合产生作用。

```
药物作用靶点
        │
        ├─ 受体：药物与受体结合
        │   ├─ 激动剂：激活受体
        │   ├─ 拮抗剂：阻断受体
        │   └─ 部分激动剂：部分激活受体
        │
        ├─ 酶：药物抑制或激活酶活性
        ├─ 离子通道：药物调节离子通道
        └─ 核酸：药物影响基因表达
```

### 2.2 药物剂量与效应关系

药物剂量与效应之间的关系。

```
剂量-效应曲线
        │
        ├─ 最小有效剂量：产生效应的最小剂量
        ├─ 治疗剂量：治疗疾病的剂量
        ├─ 最大效应：药物产生的最大效应
        ├─ 半数有效量：50%个体产生效应的剂量
        └─ 毒性剂量：产生毒性的剂量
```

### 2.3 药物不良反应

药物在治疗过程中产生的有害反应。

| 不良反应类型 | 表现 | 原因 |
|--------------|------|------|
| 副作用 | 治疗剂量下的轻微反应 | 药物作用广泛 |
| 毒性反应 | 严重的有害反应 | 剂量过大或长期使用 |
| 过敏反应 | 免疫反应 | 个体差异 |
| 后遗效应 | 停药后的残留效应 | 药物在体内蓄积 |
| 依赖性 | 生理或心理依赖 | 长期使用 |

## 四、药物相互作用

### 4.1 药物相互作用类型

药物之间的相互影响。

```
药物相互作用类型
        │
        ├─ 药效学相互作用
        │   ├─ 协同作用：效果增强
        │   └─ 拮抗作用：效果减弱
        │
        └─ 药代动力学相互作用
            ├─ 吸收相互作用：影响吸收
            ├─ 分布相互作用：影响分布
            ├─ 代谢相互作用：影响代谢
            └─ 排泄相互作用：影响排泄
```

### 4.2 药物相互作用示例

| 药物组合 | 相互作用 | 结果 |
|----------|----------|------|
| 阿司匹林 + 华法林 | 协同作用 | 出血风险增加 |
| 抗生素 + 益生菌 | 拮抗作用 | 益生菌活性降低 |
| 酮康唑 + 红霉素 | 代谢抑制 | 酮康唑血药浓度升高 |
| 利尿剂 + 降压药 | 协同作用 | 降压效果增强 |

## 五、合理用药

### 5.1 合理用药原则

```
合理用药原则
        │
        ├─ 明确诊断：根据病情用药
        ├─ 选择合适药物：根据疾病和患者情况
        ├─ 选择合适剂量：个体化给药
        ├─ 选择合适给药途径：根据病情和药物特性
        ├─ 注意药物相互作用：避免不良反应
        └─ 注意不良反应：及时处理
```

### 5.2 特殊人群用药

| 人群 | 用药特点 |
|------|----------|
| 老年人 | 药物代谢能力下降，剂量需调整 |
| 儿童 | 药物代谢能力不完善，剂量需计算 |
| 孕妇 | 避免对胎儿有害的药物 |
| 肝肾功能不全者 | 药物代谢排泄能力下降，剂量需调整 |

## 六、其他系统药物

### 6.1 呼吸系统药物

呼吸系统药物用于治疗呼吸系统疾病。

```
呼吸系统药物分类
        │
        ├─ 平喘药
        │   ├─ β2受体激动剂：沙丁胺醇（短效）、沙美特罗（长效）
        │   ├─ 茶碱类：氨茶碱
        │   ├─ 抗胆碱药：异丙托溴铵
        │   └─ 糖皮质激素：布地奈德、氟替卡松（吸入）
        │
        ├─ 镇咳药
        │   ├─ 中枢性：可待因、右美沙芬
        │   └─ 外周性：苯丙哌林
        │
        ├─ 祛痰药
        │   ├─ 黏液溶解剂：乙酰半胱氨酸、氨溴索
        │   └─ 刺激性祛痰药：愈创木酚甘油醚
        │
        └─ 抗组胺药
            ├─ 第一代（嗜睡）：氯苯那敏、苯海拉明
            └─ 第二代（不嗜睡）：氯雷他定、西替利嗪
```

### 6.2 内分泌系统药物

```
内分泌系统药物
        │
        ├─ 激素类药物
        │   ├─ 糖皮质激素：泼尼松、地塞米松（抗炎/免疫抑制）
        │   ├─ 甲状腺激素：左甲状腺素（替代治疗甲减）
        │   ├─ 胰岛素：短效/中效/长效（糖尿病治疗）
        │   ├─ 性激素：雌二醇、睾酮
        │   └─ 抗甲状腺药：甲巯咪唑、丙硫氧嘧啶（甲亢治疗）
        │
        ├─ 口服降糖药
        │   ├─ 双胍类：二甲双胍（一线，改善胰岛素抵抗）
        │   ├─ 磺脲类：格列本脲（促进胰岛素分泌）
        │   ├─ DPP-4 抑制剂：西格列汀
        │   ├─ SGLT-2 抑制剂：达格列净（促进尿糖排泄）
        │   └─ 噻唑烷二酮类：吡格列酮
        │
        └─ 骨质疏松用药
            ├─ 双膦酸盐：阿仑膦酸钠（抑制骨吸收）
            ├─ 钙剂 + 维生素 D
            └─ 选择性雌激素受体调节剂：雷洛昔芬
```

### 6.3 抗癌药物（化疗药物）

| 类别 | 机制 | 代表药物 | 主要不良反应 |
|------|------|----------|-------------|
| 烷化剂 | DNA 交联 | 环磷酰胺 | 骨髓抑制 |
| 抗代谢药 | 干扰核酸合成 | 5-氟尿嘧啶、甲氨蝶呤 | 骨髓抑制、口腔溃疡 |
| 抗肿瘤抗生素 | 嵌入 DNA | 阿霉素 | 心脏毒性、骨髓抑制 |
| 植物碱类 | 抑制微管 | 长春新碱、紫杉醇 | 神经毒性 |
| 铂类 | DNA 交联 | 顺铂、卡铂 | 肾毒性、恶心呕吐 |
| 靶向药 | 针对特定靶点 | 伊马替尼（BCR-ABL） | 相对较轻 |
| 免疫检查点抑制剂 | 解除免疫抑制 | PD-1/PD-L1 抑制剂 | 免疫相关不良反应 |

### 6.4 免疫调节药物

| 类别 | 代表药物 | 作用与用途 |
|------|----------|-----------|
| 免疫抑制剂 | 环孢素、他克莫司、霉酚酸酯 | 器官移植排斥预防 |
| 免疫增强剂 | 胸腺肽、干扰素 | 病毒感染、肿瘤辅助 |
| 非甾体抗炎药 (NSAIDs) | 阿司匹林、布洛芬 | 解热、镇痛、抗炎 |
| 改善病情抗风湿药 (DMARDs) | 甲氨蝶呤、柳氮磺吡啶 | 类风湿关节炎 |
| 生物制剂 | TNF-α 抑制剂（英夫利昔单抗） | 类风湿、强直 |


## 总结

药理学研究药物与机体的相互作用，为临床合理用药提供理论依据，是医学的重要基础学科。
