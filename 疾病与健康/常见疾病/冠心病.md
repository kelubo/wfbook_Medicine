# 冠心病

## 概述

冠心病 (Coronary Artery Disease, CAD) 是冠状动脉粥样硬化导致管腔狭窄或闭塞，引起心肌缺血、缺氧甚至坏死的心脏病，全称"冠状动脉粥样硬化性心脏病"。

> 冠心病是全球致死率最高的疾病之一。

---

## 一、病因与危险因素

### 1.1 冠状动脉粥样硬化

动脉粥样硬化是冠心病的根本病理基础——冠状动脉内膜脂质沉积、纤维组织增生、钙盐沉着，形成粥样斑块，导致管腔狭窄。

### 1.2 危险因素

```
冠心病危险因素
        │
        ├─ 不可控因素
        │   ├─ 年龄：男性 ≥ 45 岁，女性 ≥ 55 岁风险升高
        │   ├─ 性别：男性发病率高于女性（绝经后差距缩小）
        │   └─ 遗传：家族史
        │
        └─ 可控因素
            ├─ 高血压：最重要危险因素之一
            ├─ 血脂异常：LDL-C 升高是始动因素
            ├─ 糖尿病：相当于冠心病的"等危症"
            ├─ 吸烟：显著加速动脉粥样硬化
            ├─ 肥胖：尤其是腹型肥胖
            └─ 缺乏运动 + 不健康饮食
```

---

## 二、临床分型

```
冠心病分型
        │
        ├─ 慢性心肌缺血综合征
        │   ├─ 稳定型心绞痛：劳累时胸痛，休息/硝酸甘油缓解
        │   ├─ 缺血性心肌病：长期心肌缺血导致心力衰竭
        │   └─ 隐匿性冠心病：无症状但有心肌缺血证据
        │
        └─ 急性冠脉综合征 (ACS)
            ├─ 不稳定型心绞痛 (UA)：静息痛或加重型
            ├─ 非 ST 段抬高心肌梗死 (NSTEMI)：冠脉不完全闭塞
            └─ ST 段抬高心肌梗死 (STEMI)：冠脉完全闭塞（最危重）
```

---

## 三、临床表现

### 3.1 稳定型心绞痛

| 特征 | 描述 |
|------|------|
| 性质 | 压榨性、闷胀性、紧缩感 |
| 部位 | 胸骨后，可放射至左肩、左臂内侧、颈、下颌 |
| 诱因 | 劳力、情绪激动、饱餐、寒冷 |
| 持续时间 | 3~5 分钟，一般不超过 15 分钟 |
| 缓解方式 | 休息或舌下含服硝酸甘油 |

### 3.2 急性心肌梗死 (AMI)

```
心肌梗死临床表现
        │
        ├─ 胸痛：持续 ≥ 20 分钟，硝酸甘油不缓解（关键鉴别！）
        ├─ 全身症状：发热、白细胞升高
        ├─ 胃肠道：恶心、呕吐、上腹不适（下壁心梗常见）
        ├─ 心律失常：室性早搏、室速、室颤（24h 内最危险）
        ├─ 心力衰竭：呼吸困难、肺底啰音
        └─ 心源性休克：血压降低、四肢冰冷、意识模糊
```

> **注意**：约 20~33% 的心梗患者无典型胸痛——尤其是老年、女性和糖尿病患者，可表现为气促、乏力、上腹不适。

## 四、辅助检查

| 检查 | 意义 |
|------|------|
| 心电图 (ECG) | 基础检查——ST-T 改变、病理性 Q 波 |
| 心肌标志物 | **肌钙蛋白 (cTnI/cTnT)**：诊断 AMI 的"金标准"；CK-MB：辅助 |
| 运动负荷试验 | 诱发心肌缺血 |
| 冠脉 CT 血管成像 (CTA) | 无创评估冠脉狭窄 |
| 冠脉造影 | 诊断"金标准"，可同时介入治疗 |
| 心脏超声 | 评估心功能、室壁运动异常 |

| 心肌标志物 | 升高时间 | 峰值 | 恢复正常 |
|:---|:---:|:---:|:---:|
| 肌钙蛋白 cTnI | 3~6 h | 12~24 h | 5~14 天 |
| CK-MB | 4~6 h | 16~24 h | 2~3 天 |
| 肌红蛋白 | 1~2 h | 6~9 h | 24 h |

---

## 五、治疗

### 5.1 急性冠脉综合征 (ACS) 处理

    STEMI：时间就是心肌！
    ├─ 12h 内 → 急诊 PCI（经皮冠脉介入术）→ 开通血管
    ├─ 无 PCI 条件 → 溶栓治疗（30 分钟内）
    ├─ 抗血小板：阿司匹林 + P2Y12 抑制剂（氯吡格雷/替格瑞洛）
    ├─ 抗凝：肝素/低分子肝素
    └─ > 12h 无持续症状 → 择期介入

### 5.2 慢性稳定型心绞痛的长期治疗

| 类别 | 代表药 | 目的 |
|------|--------|------|
| 抗血小板 | 阿司匹林 | 预防血栓 |
| 他汀类 | 阿托伐他汀 | 降 LDL-C、稳定斑块 (LDL-C < 1.8 mmol/L) |
| β 受体阻滞剂 | 美托洛尔 | 减慢心率、降低心肌耗氧 |
| ACEI/ARB | 培哚普利 | 保护心脏、改善预后 |
| 硝酸酯类 | 单硝酸异山梨酯 | 扩张冠脉、缓解症状 |

### 5.3 血运重建

| 方法 | 适用 |
|:---|------|
| **PCI（支架植入）** | 单支或局限病变 |
| **CABG（冠脉搭桥）** | 多支弥漫病变、左主干病变 |

## 六、预防

### 一级预防与二级预防

| 预防级别 | 对象 | 措施 |
|:---|------|------|
| 一级预防 | 无病但有危险因素者 | 控血压、降脂、戒烟、运动 |
| 二级预防 | 已确诊冠心病者 | 抗血小板 + 他汀 + β-blocker + 危险因素控制 |

> 二级预防的 ABCD：**A**ntiplatelet（阿司匹林）、**B**eta-blocker & **B**lood pressure（β阻滞剂+控压）、**C**holesterol & **C**igarette（降脂+戒烟）、**D**iet & **D**iabetes（饮食+糖尿病）。
