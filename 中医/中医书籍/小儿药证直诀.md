# 小儿药证直诀

[TOC]

## 简介

《小儿药证直诀》是北宋**钱乙**（字仲阳，约 1032—1113）的儿科专著，由其门人阎孝忠收集整理，成书约在 1119 年。全书 3 卷，是中医历史上第一部体系完备的**儿科学专著**。

> 钱乙被尊为"儿科之祖"——"幼科鼻祖"。六味地黄丸即出自此书。

## 核心学术贡献

### 小儿生理病理特点

钱乙提出"小儿五脏六腑，成而未全，全而未壮"：

| 特点 | 表现 |
|------|------|
| 脏腑娇嫩 | 易受外邪侵袭 |
| 形气未充 | 发病容易、传变迅速 |
| 生机蓬勃 | 恢复能力强 |
| 纯阳之体 | 不宜过用温补 |

### 五脏辨证体系

首创儿科五脏辨证：

| 五脏 | 所主 | 辨别要点 |
|------|------|---------|
| 心热 | 惊 | 叫哭、发热、抽搐 |
| 肝热 | 风 | 直视、抽搐、项强 |
| 脾虚 | 困 | 倦怠、腹胀、泄泻 |
| 肺虚 | 喘 | 咳嗽、气促 |
| 肾虚 | 怯 | 先天不足、五迟五软 |

### 六味地黄丸的创制

钱乙将《金匮》肾气丸减去附子、桂枝二味，创制了**六味地黄丸**——原本是为小儿肾虚（纯阳之体不宜温补）而设。该方后世被移用于成人肾阴虚证，成为最著名的中成药之一。

## 代表方剂

| 方剂 | 主治 |
|------|------|
| **六味地黄丸** | 小儿肾阴虚（囟门不合、发育延迟） |
| 泻白散 | 肺热咳嗽 |
| 导赤散 | 心热口疮 |
| 泻黄散 | 脾热口疮 |
| 白术散 | 小儿脾虚泄泻 |

## 贡献

1. 第一部理论系统、理法方药完备的儿科学专著
2. 建立了小儿五脏辨证体系
3. 对诊察法——"（小儿）脉微难见，当以察色、听声、观形为先"的指导思想
4. 创制了许多至今仍在使用的名方
