# 藏红花

[TOC]

## 概述

藏红花（西红花）为鸢尾科植物番红花 *Crocus sativus* L. 的干燥柱头。原产地中海沿岸（伊朗为全球最大产区），经西藏传入中国内地，故名"藏红花"。

> 藏红花是世界上**最昂贵的香料和药材**之一：每朵花仅有三根红色柱头，约 15 万朵花才能采集到 1 公斤成品，全靠人工手采。

## 与红花的区别

藏红花和红花是两种完全不同的药物：

| | 藏红花（西红花） | 红花 |
|---|---|---|
| 来源 | 鸢尾科番红花的柱头 | 菊科红花的管状花 |
| 用量 | 0.5 ~ 1 g（泡服） | 3 ~ 9 g（煎服） |
| 价格 | 极贵（数万/公斤起） | 较便宜 |
| 药力 | 活血力**更强**、兼凉血解毒 | 活血通经为主 |
| 外观 | 红色丝状（油润有光泽） | 橙红色管状花序 |

> 市场上常见用红花冒充藏红花。简易鉴别：取少量浸入热水中，真品呈喇叭状散开、水染金黄色且不立即变红；伪品迅速掉色。

## 性味归经

- **性味**：甘、平（或微寒）
- **归经**：心、肝

## 功效

| 功效 | 应用 |
|------|------|
| **活血化瘀** | 血瘀所致的经闭、痛经、产后瘀阻 |
| **凉血解毒** | 温病热入营血（发斑发疹）、血热瘀滞 |
| **解郁安神** | 忧郁痞闷、惊悸恍惚（与红花的重要区别） |

## 使用注意

| 注意 | 说明 |
|------|------|
| 用量 | 煎服 1 ~ 3 g，或泡服每次 5 ~ 10 根（因昂贵多用泡服） |
| 孕妇 | **禁用**（活血力强可致流产） |
| 出血倾向 | 有出血性疾病者慎用 |

## 现代研究

| 成分 | 作用 |
|------|------|
| 西红花苷 (Crocin) | 抗氧化、抗抑郁、保护神经 |
| 西红花醛 (Safranal) | 改善情绪、抗焦虑 |
| 西红花酸 (Crocetin) | 降血脂、保护心血管 |

主要药理：① 抗抑郁（临床试验证明对轻中度抑郁有效）；② 改善视网膜功能（AMD 黄斑变性辅助）；③ 保护心肌；④ 降血脂。

## 品质鉴别

| 指标 | 优质特征 |
|------|---------|
| 产地 | 伊朗产 > 克什米尔 > 中国引种 |
| 外观 | 深红色、有光泽、柱头完整（不是碎屑） |
| 气香 | 特有浓郁甜香 |
| 入水 | 泡水后水染金黄色、柱头呈喇叭状 |
