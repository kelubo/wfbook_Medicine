# 灸法与推拿

## 第一部分：灸法

### 一、概述

灸法是以艾绒或其他药材燃烧产生的温热刺激作用于体表腧穴，通过经络传导以防治疾病的方法。

> 《灵枢·官针》："针所不为，灸之所宜"——凡针刺不宜者，灸法可补其不足。

### 二、灸法的作用

```
灸法的作用
        │
        ├─ 温经散寒：温热驱散寒邪，疏通经络
        ├─ 扶阳固脱：大补阳气——急救虚脱、脱肛、崩漏
        ├─ 消瘀散结：活血化瘀——消散肿块
        ├─ 防病保健：常用保健灸（足三里等）增强免疫力
        └─ 引热外达：以热引热——治疗某些热证（如痈肿）
```

### 三、常用灸法分类

#### 3.1 艾炷灸

```
艾炷灸
        │
        ├─ 直接灸
        │   ├─ 瘢痕灸：灸至起泡化脓、愈后留瘢 → 治哮喘、慢性病
        │   └─ 无瘢痕灸：温热即止、不留瘢 → 虚寒证
        │
        └─ 间接灸（隔物灸）
            ├─ 隔姜灸：生姜片——散寒解表、止呕
            ├─ 隔蒜灸：大蒜片——清热解毒、杀虫
            ├─ 隔盐灸：食盐填脐——回阳救逆（神阙穴）
            └─ 隔附子饼灸：温补肾阳、消沉寒
```

#### 3.2 艾条灸

| 方法 | 操作 | 适用 |
|:---|------|------|
| 温和灸 | 距皮肤 2~3cm 固定不动 | 虚寒证——最常用（家庭保健） |
| 雀啄灸 | 艾条一上一下如雀啄食 | 急救、局部感应不强者 |
| 回旋灸 | 艾条在穴位上方旋转移动 | 面积较大的病变 |

#### 3.3 温针灸

针柄上插艾条或艾绒团后点燃——针法与灸法结合，适用于既需针刺又需艾灸者（如关节冷痛）。

#### 3.4 现代灸具

| 灸具 | 说明 |
|:---|------|
| 艾灸盒 | 木/铁制盒内燃艾条固定于体表——简便安全 |
| 无烟艾灸 | 碳化艾条——减少烟雾 |
| 温灸器 | 电子/红外温灸设备 |

### 四、艾灸治疗取穴举例

| 症 | 取穴 | 灸法 |
|:---|:---|:---|
| 胃寒腹痛 | 中脘、足三里 | 隔姜灸或温和灸 15~20 分钟 |
| 寒性痛经 | 关元、三阴交 | 隔姜灸或温和灸 |
| 风寒感冒 | 大椎、风池 | 温和灸至发汗 |
| 肾阳虚腰痛 | 命门、肾俞 | 隔附子饼灸 |
| 免疫力低下 | 足三里（保健灸） | 温和灸——每周 2~3 次 |
| 虚脱急救 | 神阙、关元 | 隔盐灸——大艾炷连续施灸 |

### 五、注意事项

| 注意 | 说明 |
|:---|------|
| 施灸顺序 | 先上后下、先背后腹、先头后四肢 |
| 烫伤预防 | 及时弹去艾灰；弱感觉者（糖尿病神经病变）需格外小心 |
| 禁忌部位 | 面部、大血管处、孕妇腰腹 |
| 阴虚火热者 | 目赤、发热——慎灸或禁灸 |
| 灸后调养 | 灸后勿立即洗冷水澡、饮冷饮 |

## 第二部分：推拿

### 一、概述

推拿（又称按摩）是用手或肢体其他部位在人体体表特定部位实施各种手法操作以防治疾病的方法。

> 推拿作为中医外治法已有数千年历史，《黄帝内经》中已有导引按跷的记载。

### 二、推拿的作用原理

```
推拿的作用
        │
        ├─ 疏通经络：手法刺激→行气活血→通则不痛
        ├─ 理筋整复：纠正筋骨错位→恢复功能
        ├─ 调理脏腑：体表-内脏反射→调节脏腑功能
        ├─ 促进循环：手法→局部血管舒张→改善微循环
        └─ 缓解痉挛：缓解肌肉紧张和疲劳
```

### 三、常用推拿手法

#### 3.1 基本手法分类

| 类别 | 手法 | 操作要领 |
|:---|:---|------|
| **摆动类** | 㨰法、揉法 | 以小臂或掌根/指腹带动皮下组织旋转 |
| **摩擦类** | 摩法、擦法、推法 | 皮肤表面摩擦——温热效应 |
| **挤压类** | 按法、点法、捏法、拿法 | 垂直或相对挤压 |
| **振动类** | 振法、抖法 | 高频振动 |
| **叩击类** | 拍法、击法、叩法 | 有节律的叩击 |
| **运动关节类** | 摇法、扳法、拔伸法 | 活动关节、松解粘连 |

#### 3.2 核心手法详解

| 手法 | 操作 | 适用部位 | 作用 |
|:---|------|------|------|
| **㨰法** | 小鱼际背侧及掌指关节吸定体表、腕关节屈伸旋转 | 颈肩、腰背、四肢 | 舒筋活络、缓解痉挛——最常用 |
| **揉法** | 掌根或指腹带动皮下组织旋转 | 全身各部位 | 活血散瘀、消肿止痛 |
| **推法** | 指/掌单向直线推移 | 头面、胸腹、腰背、四肢 | 疏通经络 |
| **按法** | 指/掌垂直按压逐渐加力 | 全身腧穴 | 通经止痛——"以指代针" |
| **拿法** | 拇指和其他四指相对拿揉 | 颈、肩、四肢 | 解表发汗、缓解紧张 |
| **抖法** | 双手握肢体末端连续小幅度抖动 | 上肢、下肢 | 放松肌肉、松解关节 |

### 四、常见病推拿治疗取穴

| 病症 | 取穴/部位 | 手法 |
|:---|:---|:---|
| 颈肩疲劳 | 风池、肩井、天宗 | 按揉 + 拿法 |
| 腰痛 | 肾俞、委中、承山 | 㨰法 + 按揉 |
| 头痛 | 太阳、风池、百会、印堂 | 揉、按 |
| 失眠 | 神门、三阴交、涌泉 | 轻揉按揉 |
| 小儿积食 | 捏脊（华佗夹脊） | 自下而上捏提 |
| 面瘫恢复 | 阳白、迎香、地仓、合谷 | 揉法 + 擦法 |

### 五、推拿禁忌证与慎用

| 禁忌 | 说明 |
|:---|------|
| 骨折、脱位未复位 | 禁——加重损伤 |
| 开放性损伤、出血 | 禁 |
| 皮肤感染、烧伤 | 禁 |
| 严重骨质疏松 | 禁重手法 |
| 肿瘤部位 | 禁直接推拿 |
| 孕妇腰骶腹 | 禁用 |
| 血栓性静脉炎 | 禁——防脱落 |
| 饱餐后 30 分钟内 | 慎——尤其腹部和腰背部 |
