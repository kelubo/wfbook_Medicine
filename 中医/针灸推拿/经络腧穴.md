# 经络腧穴

## 概述

经络是人体运行气血、联络脏腑、沟通内外、贯穿上下的通道。腧穴是经络之气输注于体表的特殊部位，是针灸施术的刺激点。

> 《灵枢·经脉》："经脉者，所以能决死生，处百病，调虚实，不可不通。"

---

## 一、经络系统

### 1.1 经络总览

```
经络系统
        │
        ├─ 十二正经（主体）
        │   ├─ 手三阴：手太阴肺经、手厥阴心包经、手少阴心经
        │   ├─ 手三阳：手阳明大肠经、手少阳三焦经、手太阳小肠经
        │   ├─ 足三阴：足太阴脾经、足厥阴肝经、足少阴肾经
        │   └─ 足三阳：足阳明胃经、足少阳胆经、足太阳膀胱经
        │
        ├─ 奇经八脉
        │   ├─ 任脉：阴脉之海，行于腹面正中
        │   ├─ 督脉：阳脉之海，行于背面正中
        │   ├─ 冲脉：血海
        │   ├─ 带脉：约束诸经
        │   ├─ 阴跷脉 / 阳跷脉：司目之开合
        │   └─ 阴维脉 / 阳维脉：维系阴阳
        │
        ├─ 十二经别：经脉深入体腔的分支
        ├─ 十五络脉：经脉的外行分支
        └─ 十二经筋 / 十二皮部：经络的体表附属
```

### 1.2 十二经脉走行规律

| 规律 | 说明 |
|------|------|
| 阴经行于内侧，阳经行于外侧 | 举手而立，掌心向面 |
| 手三阴从胸走手 | 手太阴→肺 |
| 手三阳从手走头 | 手阳明→大肠 |
| 足三阳从头走足 | 足阳明→胃 |
| 足三阴从足走腹 | 足太阴→脾 |

### 1.3 十二经脉的阴阳表里相合

| 阴经（里） | 阳经（表） | 循行部位 |
|:---|:---|:---|
| 手太阴肺经 | 手阳明大肠经 | 上肢内侧前缘 / 外侧前缘 |
| 手厥阴心包经 | 手少阳三焦经 | 上肢内侧中线 / 外侧中线 |
| 手少阴心经 | 手太阳小肠经 | 上肢内侧后缘 / 外侧后缘 |
| 足太阴脾经 | 足阳明胃经 | 下肢内侧前缘 / 外侧前缘 |
| 足厥阴肝经 | 足少阳胆经 | 下肢内侧中线 / 外侧中线 |
| 足少阴肾经 | 足太阳膀胱经 | 下肢内侧后缘 / 外侧后缘 |

## 二、腧穴总论

### 2.1 腧穴的分类

```
腧穴分类
        │
        ├─ 十四经穴（361 个）：归属于十二正经和任督二脉的腧穴
        ├─ 经外奇穴：有固定名称和位置但不归经的腧穴（如太阳穴、印堂）
        └─ 阿是穴：无固定名称和位置，以压痛点或敏感点为穴
```

### 2.2 腧穴定位方法

| 方法 | 说明 | 示例 |
|------|------|------|
| 骨度分寸法 | 以骨节为标志折算等分 | 前发际→后发际 = 12 寸 |
| 解剖标志法 | 以体表解剖标志定位 | 眉头凹陷处 = 攒竹 |
| 手指同身寸法 | 以患者自身手指为尺 | 拇指同身寸、中指同身寸 |
| 简便取穴法 | 特定姿势直接定位 | 虎口交叉食指尖 = 列缺 |

### 2.3 常用同身寸

| 名称 | 折量 |
|:---|:---:|
| 拇指同身寸 | 拇指指间关节横幅 = 1 寸 |
| 中指同身寸 | 中指中节屈曲时两横纹间 = 1 寸 |
| 横指同身寸（一夫法） | 食中环小四指并拢 = 3 寸 |

## 三、常用腧穴

### 3.1 头面颈部

| 穴名 | 归经 | 定位 | 主治 |
|------|:---:|------|------|
| 百会 | 督脉 | 头顶正中，前发际直上 5 寸 | 头痛、眩晕、脱肛、失眠 |
| 太阳 | 经外奇穴 | 眉梢与外眼角之间向后约 1 寸凹陷 | 头痛、目赤、面瘫 |
| 迎香 | 大肠经 | 鼻翼外缘中点旁鼻唇沟中 | 鼻塞、面瘫 |
| 风池 | 胆经 | 项后枕骨下胸锁乳突肌上端凹陷 | 感冒、头痛、项强 |
| 印堂 | 经外奇穴 | 两眉中间 | 头痛、眩晕、鼻疾 |

### 3.2 上肢部

| 穴名 | 归经 | 定位 | 主治 |
|------|:---:|------|------|
| 合谷 | 大肠经 | 手背第 1、2 掌骨间 | 头痛、牙痛（"面口合谷收"） |
| 曲池 | 大肠经 | 屈肘纹头外侧端 | 发热、高血压、皮肤病 |
| 内关 | 心包经 | 腕横纹上 2 寸 | 心悸、胸闷、恶心呕吐 |
| 外关 | 三焦经 | 腕背横纹上 2 寸 | 偏头痛、上肢痹痛 |
| 列缺 | 肺经 | 桡骨茎突上方腕横纹上 1.5 寸 | 咳嗽、头痛（"头项寻列缺"） |
| 神门 | 心经 | 腕横纹尺侧端 | 失眠、心悸、健忘 |

### 3.3 躯干部

| 穴名 | 归经 | 定位 | 主治 |

## 四、特定穴

特定穴是具有特殊性能和治疗作用的腧穴。

| 类别 | 数量 | 特点 | 示例 |
|:---|:---:|------|------|
| 五输穴 | 60 | 井荥输经合——从指/趾端到肘/膝 | 肺经井→少商，荥→鱼际，输→太渊，经→经渠，合→尺泽 |
| 原穴 | 12 | 脏腑原气经过留止之处 | 太渊（肺）、合谷（大肠）、太冲（肝） |
| 络穴 | 15 | 联络表里两经之处 | 列缺（肺络大肠）、内关（心包络三焦） |
| 郄穴 | 16 | 经脉气血深聚之处——急症用 | 孔最（肺经郄穴，治咯血） |
| 背俞穴 | 12 | 脏腑之气输注于背部的腧穴 | 肺俞、心俞、肝俞、脾俞、肾俞 |
| 募穴 | 12 | 脏腑之气结聚于腹部的腧穴 | 中脘（胃之募）、关元（小肠募） |
| 八会穴 | 8 | 脏、腑、气、血、筋、脉、骨、髓之精气聚会 | 中脘（腑会）、膻中（气会） |
| 下合穴 | 6 | 六腑之气合于下肢的腧穴 | 足三里（胃）、上巨虚（大肠） |

## 五、穴位歌诀（四总穴歌）

> 肚腹三里留，腰背委中求。
> 头项寻列缺，面口合谷收。
> 心胸取内关，胁肋用阳陵。

| 症 | 取穴 | 归经 |
|:---|:---|:---|
| 腹部疾患 | 足三里 | 足阳明胃经 |
| 腰背疾患 | 委中 | 足太阳膀胱经 |
| 头项疾患 | 列缺 | 手太阴肺经 |
| 面部口腔 | 合谷 | 手阳明大肠经 |
| 心胸疾患 | 内关 | 手厥阴心包经 |
| 胁肋部疾患 | 阳陵泉 | 足少阳胆经 |
