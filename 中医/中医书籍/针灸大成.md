# 针灸大成

[TOC]

## 简介

《针灸大成》是明代**杨继洲**（约 1522—1620）集历代针灸成就编撰的综合性针灸学著作，成书于万历二十九年（1601 年）。全书 10 卷，是明代针灸学的集大成之作。

> 书前附有"铜人明堂之图"——标出了全身腧穴定位，是明清针灸师的标准参考图。

## 内容结构

| 卷次 | 内容 |
|:---:|------|
| 卷一 | 针道源流——集《内经》《难经》等 20 多种经典论针精华 |
| 卷二 | 针灸歌赋——如标幽赋、通玄指要赋等 |
| 卷三 | 五腧穴歌诀——井荥输经合 |
| 卷四 | 针具与手法——九针形制、补泻手法、针刺禁忌 |
| 卷五 | 井荥输经合之主治 |
| 卷六 ~ 七 | 十四经穴定位和主治（全书核心） **359 个经穴** |
| 卷八 | 临床治疗各论——分内外妇儿五官等 |
| 卷九 | 名医治法与名家灸法 |
| 卷十 | 小儿按摩经（附《保婴神术》） |

## 核心贡献

1. 集明代以前针灸学之大成——总结了完整的十四经腧穴体系
2. 详细记述了针刺补泻手法（提插、捻转、呼吸、开阖等）
3. 收录了大量针灸歌诀便于记忆
4. 附有小儿推拿内容
5. 至今为高等中医院校针灸推拿专业的核心教材之一

## 重要概念

### 五腧穴

每条正经（十二经脉）上有五个重要腧穴——井、荥、输、经、合——分别位于肘膝以下，对应于五行，各有特定的主治。

### 奇经八脉

除十二正经之外的人体八条重要经脉。在《针灸大成》中系统整理并配穴。
