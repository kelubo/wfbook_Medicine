# 四时养生

## 概述

四时养生是根据春、夏、秋、冬四季（及长夏）气候变化规律，调节生活起居、饮食精神和运动，以达到人与自然环境和谐统一的养生方法。其理论源于《黄帝内经》"四气调神"之说。

> 《素问·四气调神大论》："夫四时阴阳者，万物之根本也，所以圣人春夏养阳，秋冬养阴，以从其根。"

---

## 一、四季总纲

| 季节 | 五行 | 五脏 | 天时特点 | 养生总则 |
|:---|:---:|:---:|------|------|
| 春 | 木 | 肝 | 阳气生发、万物始生 | 养肝、助阳生发 |
| 夏 | 火 | 心 | 阳气最盛、万物繁茂 | 养心、清暑护阴 |
| 长夏 | 土 | 脾 | 湿气最盛 | 健脾、化湿 |
| 秋 | 金 | 肺 | 阳气收敛、燥气当令 | 养肺、润燥收敛 |
| 冬 | 水 | 肾 | 阳气闭藏、万物潜藏 | 养肾、藏精蓄锐 |

## 二、春季养生

### 2.1 起居

| 要点 | 说明 |
|:---|------|
| 夜卧早起 | 晚 10 点前睡，早 6 点左右起——顺应阳气升发 |
| 舒展形体 | 晨起缓步、多穿宽松衣服 |
| 防风避寒 | "春捂秋冻"——早春气温变化大，不急减衣 |
| 多亲近自然 | 踏青、郊游——疏导肝气 |

### 2.2 情志

- 调畅肝气：忌怒、忌压抑
- 保持心情舒畅——肝喜条达而恶抑郁

### 2.3 饮食

```
春季饮食要点
        │
        ├─ 省酸增甘：减少酸味、增加甘味以养脾气
        ├─ 宜辛温发散：葱、姜、蒜、韭菜
        ├─ 多吃绿色蔬菜：菠菜、荠菜、芹菜 → 养肝
        └─ 忌油腻、生冷
```

---

## 三、夏季养生

### 3.1 起居

| 要点 | 说明 |
|:---|------|
| 晚睡早起 | 顺应昼长夜短 |
| 适当午休 | 补充夜间不足 |
| 忌贪凉 | 空调不过低 (26~28°C)、不直吹、不露宿 |

### 3.2 情志

- 静心养神——"使志无怒"
- 心静自然凉——保持平和心态

### 3.3 饮食

```
夏季饮食要点
        │
        ├─ 清热解暑：绿豆汤、西瓜、苦瓜
        ├─ 益气养阴：西洋参、麦冬、百合
        ├─ 养护脾胃：避免过食生冷
        └─ 补充水分和电解质
```

> 夏季脾胃功能较弱，过度冷饮冷食是"夏伤脾胃、秋生疟痢"的根源之一。

## 四、长夏养生（农历六月前后）

长夏为脾所主，湿气最盛。

| 要点 | 说明 |
|:---|------|
| 健脾化湿 | 扁豆、薏苡仁、山药、茯苓——健脾祛湿 |
| 避免过劳 | 湿阻困脾→乏力困重 |
| 忌过食油腻 | 加重脾湿 |
| 运动微微出汗 | 不可大汗淋漓伤气 |

---

## 五、秋季养生

### 5.1 起居

| 要点 | 说明 |
|:---|------|
| 早卧早起 | 与鸡俱兴——顺应阳气收敛 |
| 适时添衣 | 初秋适"冻"以锻炼耐寒、深秋勿受寒 |
| 防燥保湿 | 室内加湿、减少出汗 |

### 5.2 情志

- 收敛神气——"使志安宁"
- 防悲忧——秋季与肺相应，在志为悲（悲秋）
- 登高望远——开阔心胸

### 5.3 饮食

```
秋季饮食要点
        │
        ├─ 润燥养肺：梨、银耳、百合、蜂蜜、杏仁
        ├─ 酸味收敛：山楂、葡萄、梅子
        ├─ 少辛增酸——减少葱姜等辛辣发散
        └─ 忌燥热食物
```

---

## 六、冬季养生

### 6.1 起居

| 要点 | 说明 |
|:---|------|
| **早卧晚起** | 必待日光——顺应阳气潜藏 |
| 保暖为先 | 头、背、足三处尤重保暖 |
| 室内通风 | 每日短时间开窗 |
| 节制房事 | 养精蓄锐 |

### 6.2 情志

- 藏神——"使志若伏若匿"
- 避免过度兴奋和惊恐
- 安静自守、韬光养晦

### 6.3 饮食

```
冬季饮食要点
        │
        ├─ 温补助阳：羊肉、核桃、韭菜、桂圆
        ├─ 滋补养阴：黑芝麻、枸杞、山药（阴中求阳）
        ├─ 根茎类蔬菜：萝卜、红薯、莲藕
        └─ 忌生冷
```

## 七、二十四节气养生要点

| 节气 | 要点 |
|:---|------|
| 立春 | 减衣循序渐进 |
| 惊蛰 | 早醒早起 |
| 夏至 | 一阴生——不宜过食寒凉 |
| 立秋 | 秋瓜坏肚——少食西瓜 |
| 白露 | 身不露——添衣防寒 |
| 冬至 | 一阳生——进补最佳时机（羊肉汤、药膳） |
| 大寒 | 藏精——减少户外活动 |
