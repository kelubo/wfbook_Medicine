## 一、为什么拆、拆成几本

原书 59 章混了「通用科普 / 具体技巧 / 男性专属 / 女性专属 / 进阶玩法」五个层面，
读者按需求买书时选不清，且男/女两本与「技巧」大面积重复。

**分层逻辑**：
- **受众维度**：通用 vs 男 vs 女 vs 进阶（决定"谁买"）
- **内容维度**：知（该懂什么）vs 行（怎么做）（决定"通用怎么分"）

五册 + 共享基座：

```
common.tex（共享基座：导言区/配色/术语/图风格/引用/解剖构造图）
   ├ A 通用·知  《性健康基础》
   ├ B 通用·行  《亲密实践与技巧》
   ├ C 男性     《男性性健康》
   ├ D 女性     《女性性健康》
   └ E 进阶     《BDSM 与 Kink》
```

## 二、边界决策（已拍板）

| 点 | 决定 | 理由 |
|---|---|---|
| 避孕专题 | **归 A**（通用·知） | 安全/医学属"知"，非性别专属 |
| 解剖构造图 | **归 common** | A/B/C/D 都要引用，集中一处维护 |
| 夫妻沟通/误解/体谅/房事养生/按摩 | **分散进 A / B**，不单立《亲密关系》 | 沟通→A；房事养生/按摩→B，避免第 6 本 |
| BDSM | **独立 E 册** | 兴趣进阶、小众，不吓退主流读者 |

## 六、目录结构（已落地）

```
性医学/
├─ 性学.tex            # 原始单文件（保留，作总源/对照）
├─ 性学.pdf            # 原单文件编译产物
├─ 系列规划.md         # 本文件
└─ 系列/               # 拆分产物（扁平结构）
   ├─ common.tex        # 共享基座（导言区/配色/TikZ/ctexset/C列型/字体）
   ├─ _split.py         # 切片脚本（性学.tex → 五册，可重复执行）
   ├─ A_性健康基础.tex/.pdf        # 167 页 / 32 章
   ├─ B_亲密实践与技巧.tex/.pdf    # 117 页 / 17 章
   ├─ C_男性性健康.tex/.pdf        # 38 页 / 6 章
   ├─ D_女性性健康.tex/.pdf        # 69 页 / 5 章
   └─ E_BDSM与Kink.tex/.pdf        # 8 页 / 1 章
```

每册独立可编译（`xelatex` 两遍出目录），`\input{common.tex}` 引用共享基座。
改配色/图风格/术语规范 → 只改 common.tex 一处，五册同步。
重新切片 → 改 `_split.py` 里 `BOOKS` 的 `starts` 行号后 `python _split.py`。
