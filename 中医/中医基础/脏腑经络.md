# 脏腑经络

## 概述

脏腑经络学说是中医理论的核心，用于解释人体生理功能和病理变化。

---

## 一、脏腑

### 1.1 五脏

五脏是心、肝、脾、肺、肾的总称，具有化生和贮藏精气的功能。

```
五脏功能
        │
        ├─ 心
        │   ├─ 主血脉：推动血液运行
        │   ├─ 主神志：主管精神活动
        │   └─ 开窍于舌
        │
        ├─ 肝
        │   ├─ 主疏泄：调节气血运行
        │   ├─ 主藏血：贮藏血液
        │   └─ 开窍于目
        │
        ├─ 脾
        │   ├─ 主运化：消化吸收
        │   ├─ 主升清：升提清气
        │   └─ 开窍于口
        │
        ├─ 肺
        │   ├─ 主气：呼吸功能
        │   ├─ 主肃降：通调水道
        │   └─ 开窍于鼻
        │
        └─ 肾
            ├─ 主藏精：贮藏精气
            ├─ 主水：调节水液代谢
            └─ 开窍于耳
```

### 1.2 六腑

六腑是胆、胃、小肠、大肠、膀胱、三焦的总称，具有传化水谷的功能。

| 六腑 | 功能 | 与五脏的关系 |
|------|------|--------------|
| 胆 | 贮藏胆汁 | 与肝相表里 |
| 胃 | 受纳腐熟水谷 | 与脾相表里 |
| 小肠 | 受盛化物，分清泌浊 | 与心相表里 |
| 大肠 | 传化糟粕 | 与肺相表里 |
| 膀胱 | 贮尿排尿 | 与肾相表里 |
| 三焦 | 通行元气，运行水液 | 与心包相表里 |

### 1.3 脏腑之间的关系

```
脏腑关系图
        │
        ├─ 心与肺：气与血的关系
        │   ├─ 气为血之帅
        │   └─ 血为气之母
        │
        ├─ 心与肝：血与神的关系
        │   ├─ 心主血，肝藏血
        │   └─ 心主神志，肝主疏泄
        │
        ├─ 心与脾：血的生成与运行
        │   ├─ 脾运化生血
        │   └─ 心推动血行
        │
        ├─ 肝与脾：疏泄与运化
        │   ├─ 肝疏泄助脾运化
        │   └─ 脾运化生血养肝
        │
        ├─ 肺与脾：气的生成
        │   ├─ 肺主气
        │   └─ 脾生气
        │
        └─ 肾与肝：精血同源
            ├─ 肾藏精
            └─ 肝藏血
```

## 二、经络

### 2.1 经络的概念

经络是人体运行气血、联络脏腑、沟通内外、贯穿上下的通道。

```
经络系统
        │
        ├─ 十二经脉
        │   ├─ 手三阴经：肺、心包、心
        │   ├─ 手三阳经：大肠、三焦、小肠
        │   ├─ 足三阴经：脾、肝、肾
        │   └─ 足三阳经：胃、胆、膀胱
        │
        ├─ 奇经八脉
        │   ├─ 督脉：总督一身之阳
        │   ├─ 任脉：总任一身之阴
        │   ├─ 冲脉：十二经之海
        │   └─ 带脉：约束诸经
        │
        ├─ 十二经别：补充十二经脉
        ├─ 十二经筋：联结肌肉骨骼
        └─ 十二皮部：经络的体表分布
```

### 2.2 十二经脉走向规律

```
十二经脉走向
        │
        ├─ 手三阴经：从胸走手
        │   ├─ 手太阴肺经
        │   ├─ 手厥阴心包经
        │   └─ 手少阴心经
        │
        ├─ 手三阳经：从手走头
        │   ├─ 手阳明大肠经
        │   ├─ 手少阳三焦经
        │   └─ 手太阳小肠经
        │
        ├─ 足三阳经：从头走足
        │   ├─ 足阳明胃经
        │   ├─ 足少阳胆经
        │   └─ 足太阳膀胱经
        │
        └─ 足三阴经：从足走腹
            ├─ 足太阴脾经
            ├─ 足厥阴肝经
            └─ 足少阴肾经
```

### 2.3 经络的功能

| 功能 | 描述 |
|------|------|
| 运行气血 | 输送营养物质 |
| 联络脏腑 | 沟通内外上下 |
| 感应传导 | 传递信息 |
| 调节平衡 | 维持机体稳态 |

## 三、脏腑经络与疾病

### 3.1 脏腑病变特点

| 脏腑 | 常见病变 | 病因 |
|------|----------|------|
| 心 | 心悸、失眠、胸闷 | 情志失调、劳累过度 |
| 肝 | 胁痛、头晕、易怒 | 情志不舒、饮食不节 |
| 脾 | 腹胀、便溏、乏力 | 饮食失调、思虑过度 |
| 肺 | 咳嗽、气喘、鼻塞 | 外感风寒、燥热伤肺 |
| 肾 | 腰膝酸软、耳鸣 | 先天不足、劳累过度 |

### 3.2 经络病变特点

```
经络病变
        │
        ├─ 经气不利：疼痛、麻木
        │
        ├─ 经络阻滞：肿胀、瘀斑
        │
        ├─ 经络空虚：肢体无力
        │
        └─ 经络异常：感觉异常
```

### 3.3 脏腑经络在诊断中的应用

| 诊断方法 | 应用 |
|----------|------|
| 望诊 | 观察面色、舌象 |
| 闻诊 | 听声音、闻气味 |
| 问诊 | 询问症状、病史 |
| 切诊 | 触摸脉象、按压穴位 |

---

## 总结

脏腑经络学说是中医理论的核心，通过脏腑的生理功能和经络的运行规律，解释人体生理病理变化，指导中医诊断和治疗。
