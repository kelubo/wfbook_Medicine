# 瘟疫论

[TOC]

## 简介

《瘟疫论》是明末清初的瘟疫学家**吴又可**（吴有性，字又可，1582—1652）所著，成书于崇祯十五年（1642 年）。全书 2 卷，是中国医学史上第一部系统研究急性传染病（瘟疫）的专著。

当时正值明末大疫（鼠疫大流行），吴又可亲临疫区，"格其所感之气，所入之门，所受之处，及其传变之体"，在深入观察的基础上提出了**戾气学说**——认为瘟疫非六淫（风、寒、暑、湿、燥、火）所致，而是"天地间别有一种异气（戾气）所感"。

> 这在显微镜看到细菌之前约 200 年就提出了近似"微生物感染"的天才假说，是世界传染病学史上的一块丰碑。

---

## 戾气学说

### 核心观点

| 观点 | 现代对应 |
|------|---------|
| 瘟疫由"戾气"（异气/杂气/疠气）所致 | 微生物（细菌、病毒）感染 |
| 戾气"无形可求、无象可见"但客观存在 | 肉眼不可见的病原体 |
| 不同戾气导致不同疫病 | 不同病原体 → 不同疾病 |
| 戾气从口鼻而入 | 呼吸道/消化道传入 |
| 戾气有"偏中性"（种属特异性） | 人畜共患病具有种属选择性 |
| "一病只有一气" | 特定病原体 → 特定疾病 |

### "邪伏膜原"理论

吴又可提出瘟疫的病变中心在**膜原**（又称募原）——位于半表半里之间、脏腑之外的一个部位。

- 邪气自口鼻侵入 → 伏于膜原 → 因诱因发作
- 初起憎寒壮热、嗣后但热不寒
- 此非表证亦非里证 → 须独辟蹊径——**达原开达膜原**

---

## 传变理论（九传）

吴又可提出戾气有九种传变（九传），实际可归纳为：

| 传变方向 | 特征 |
|----------|------|
| 向表传 | 出现表证——斑疹、自汗 |
| 向里传 | 出现里证——胸膈痞闷、腹胀 |
| 表里分传 | 既有表证又有里证 |

## 经典方剂

### 达原饮

- **组成**：槟榔二钱、厚朴一钱、草果仁五分、知母一钱、芍药一钱、黄芩一钱、甘草五分
- **功效**：开达膜原、辟秽化浊
- **主治**：瘟疫初起、邪伏膜原——憎寒壮热、头痛身痛、舌苔白如积粉

> 方中槟榔、厚朴、草果为"达原三味"——辛开直达膜原以去伏邪。

### 三消饮

- 达原饮 + 大黄、葛根、羌活、柴胡
- 用于瘟疫表里分传之证（表有头痛身痛、里有脘腹痞满便秘）

## 与《伤寒论》的决裂

| | 《伤寒论》 | 《瘟疫论》 |
|---|---|---|
| 病因 | 寒邪 | 戾气（异气） |
| 侵入途径 | 皮毛 | 口鼻 |
| 初起病位 | 太阳 | 膜原 |
| 治法 | 辛温发汗 | 达原开泄 |
| "六经" | 循经传 | 不拘于六经 |

> 吴又可直言："守古法不合今病"，力主摆脱伤寒经方的约束，为瘟疫专证创立专属治法。

## COVID-19 时代的回顾

2020 年新冠肺炎疫情爆发后，"邪伏膜原"、"达原饮"等《瘟疫论》概念再次被重新审视——中医界用达原饮合方的思路参与抗疫，取得了一定效果，印证了四百年前吴又可的学术洞见。

---

## 学术意义

1. 世界医学史上最早的传染病学专著之一（早于 Leeuwenhoek 发现细菌 30 多年）
2. 提出**非六淫**的致病概念——突破中医传统病因学范式
3. 建立独立的瘟疫辨证论治体系
4. 膜原理论为后世理解半表半里证增加了新的维度
5. 影响了清代戴天章《广瘟疫论》、余师愚《疫疹一得》、杨栗山《伤寒瘟疫条辨》等一批后续著作
