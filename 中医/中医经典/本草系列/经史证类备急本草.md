# 经史证类备急本草

[TOC]

## 简介

《经史证类备急本草》（简称《证类本草》）是北宋药学家**唐慎微**约于元丰五年（1082 年）编撰的中药学巨著。全书 31 卷（《重修政和经史证类备急本草》），载药 **1746 种**，是宋代本草学的集大成之作。

唐慎微原为蜀中名医，受地方官员资助，用十年时间广搜博采，将《嘉祐本草》和《本草图经》合二为一，系统收集了宋以前全部主要本草著作的内容和插图，并增补了经史子集中与药物有关的记载，成为李时珍《本草纲目》之前保存资料最丰富的本草文献。

> 李时珍推崇备至："使诸家本草及各药单方，垂之千古不致沦没者，皆其功也。"

---

## 内容结构

《证类本草》最突出的特点是**逐药汇集历代文献**，将同一味药物的历代记述汇编在一处：

```
【白字】《神农本草经》原文
【黑字】《名医别录》文
【大字】陶弘景注、新修本草注、开宝本草注等
【小字】唐慎微新增考辨
【药图】苏颂《本草图经》的插图
【附方】分布于药物之后（散见于书中，非集中附录）
```

每药还附有：
- 炮制方法
- 采收时月
- 道地产地
- 真伪鉴别
- 畏恶反忌（配伍禁忌）

## 版本流变

《证类本草》在宋代历经多次官方修订，形成多个版本：

| 版本 | 年代 | 说明 |
|------|------|------|
| 《经史证类备急本草》（原稿） | 约 1082 | 唐慎微原著 |
| 《大观本草》 | 大观二年（1108） | 艾晟校订、首度官刻 |
| 《政和本草》 | 政和六年（1116） | 曹孝忠校修 |
| 《重修政和经史证类备用本草》 | 淳祐九年（1249） | 张存惠增订版，图片最精，**通行版本** |

## 内容特色

### 一、保存了大量已佚文献

后世已亡佚的宋以前本草著作，大量依靠《证类本草》得以间接保存：

| 已佚著作 | 在《证类本草》中的保存情况 |
|----------|--------------------------|
| 《名医别录》 | 逐药以墨字保存 |
| 《本草经集注》 | 陶弘景注以墨字保存 |
| 《新修本草》 | 唐本注以墨字保存 |
| 《本草拾遗》 | 陈藏器说以墨字保存 |
| 《开宝本草》 | 开宝注以墨字保存 |
| 《本草图经》 | 逐药附药图、图经摘文 |
| 《雷公炮炙论》 | 炮制内容部分保存 |

### 二、引书极广

除本草文献之外，还引用了**经史子集**中与药物相关的内容 200 余种，使本草学超越了单纯的医学范围，具有博物学性质。

### 三、阅读便利

唐慎微为每味药汇编了完整的学术史链条，从《本经》→《别录》→陶弘景→唐本草→宋本草，前后贯穿，便于查证历代对同一药物的不同认识。

## 代表性药物举例

### 人参

- 《本经》：味甘微寒，补五脏，安精神
- 《别录》：疗肠胃中冷，心腹鼓痛
- 陶弘景：多出上党及辽东
- 《图经》：附人参植物形态图
- 唐慎微按：引《太平广记》《北梦琐言》等人参故事
- 附方：补中益气、生津止渴等

### 甘草

- 逐药采集历代论述
- 引《尔雅》《说文解字》考订名称
- 附地方品种鉴别

## 历史地位

1. **保存者角色**：宋代以前本章文献大量亡佚（包括珍贵的《新修本草》药图），唯赖此书得以间接保存
2. **资料总库**：李时珍《本草纲目》以《证类本草》为基本框架扩展而成
3. **学术严谨**：文献考据、引典注明出处的方法为后世楷模
4. **临床价值高**：附方丰富，至今其中不少简验方仍在临床使用
