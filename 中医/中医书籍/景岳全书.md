# 景岳全书

[TOC]

## 简介

《景岳全书》是明代著名医家**张介宾**（号景岳，1563—1640）的个人医学全集，由其门人整理编辑，成书于明崇祯十三年（1640 年）。全书共 64 卷，约 100 万字。

张景岳是明代温补学派的核心人物，以"阳常不足、阴常有余"的论点与朱丹溪"阳常有余、阴常不足"唱反调，倡温补法，被称为"医门之张子和"（这里的子和不是指攻邪派的张从正，而是指善于论辩者）。

## 核心学术观点

### 阳不足论

张景岳认为朱丹溪的"阴常不足"论过于强调养阴，导致时医滥用寒凉，进而伤伐阳气。提出了"天之大宝只此一丸红日，人之大宝只此一息真阳"的著名论断。

### 左归、右归

根据《难经》"左为肾、右为命门"之说，创立：

| | 左归（滋养真阴） | 右归（温补命门） |
|---|---|---|
| 丸剂 | 左归丸 | 右归丸 |
| 饮剂 | 左归饮 | 右归饮 |

左归丸滋肾阴，右归丸温肾阳——阴阳互根互用，补中有求。特别是左归丸去掉了六味地黄丸中泽泻、丹皮二味"泻"药，纯补无泻，适合纯虚证。

| 卷次 | 内容 |
|:---:|------|
| 卷一 ~ 三 | 传忠录——基础理论（含《类经》分类） |
| 卷四 ~ 六 | 脉神章——脉学 |
| 卷七 ~ 八 | 伤寒典——外感病 |
| 卷九 ~ 三十七 | 杂证谟——内伤病各论（本书核心） |
| 卷三十八 ~ 三十九 | 妇人规——妇科 |
| 卷四十 ~ 四十一 | 小儿则——儿科 |

| 卷四十七 ~ 四十八 | 外科 |

| 卷五十 ~ 六十 | 新方八阵 + 古方八阵 |
| 卷六十一 ~ 六十四 | 妇产及治法 |

## 八阵分类法

张景岳独创方剂八阵分法：

| 阵 | 治法 | 代表方 |
|:---:|------|------|
| 补阵 | 补虚 | 左归丸、右归丸 |
| 和阵 | 和解平衡 | 金水六君煎 |
| 攻阵 | 攻邪 | — |
| 散阵 | 发散 | 正柴胡饮 |
| 寒阵 | 清热 | — |
| 热阵 | 温里 | 理阴煎 |
| 固阵 | 收敛固涩 | — |
| 因阵 | 因证立方 | — |

## 代表方剂

- **左归丸/右归丸**、**左归饮/右归饮**（滋肾阴/温肾阳四对）
- **金水六君煎**（肺肾阴虚、咳嗽痰多——治"阴虚夹痰"的经典方）
- **正柴胡饮**（风寒感冒——轻于麻黄汤、重于桂枝汤的中间方）

## 张景岳的临床风格

> 用药如用兵，设方如布阵。

张景岳擅长温补，善用熟地（人称"张熟地"）。其最大特点是**重理论而不泥古方**——许多方剂是他自己根据经典理论独创，脱离了《局方》的旧有体系。
