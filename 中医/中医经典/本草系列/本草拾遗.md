# 本草拾遗

[TOC]

## 简介

《本草拾遗》是唐代著名药学家**陈藏器**（约687—757）所著，成书于唐开元二十七年（739 年）。全书 10 卷（序例 1 卷、拾遗 6 卷、解纷 3 卷）。

陈藏器鉴于《新修本草》虽有增补，仍"遗逸尚多"，遂广搜民间药物和外来药，拾遗补缺，对唐代以前遗漏的药物做了系统收集和整理。原书已佚，部分内容散见于《证类本草》和《本草纲目》的引用中。

> 李时珍对陈藏器评价极高："其所著述，博极群书，精核物类，订绳谬误，搜罗幽隐，自《本草》以来一人而已。"

## 核心贡献

### 一、宣、通、补、泄、轻、重、滑、涩、燥、湿——十剂分类法的雏形

陈藏器在序例中提出药物功效的十种类型，开后世"十剂"（徐之才归纳）之先河：

| 剂型 | 功能 | 药物举例 |
|:---:|------|------|
| **宣** | 宣散壅滞 | 生姜、橘皮 |
| **通** | 通利关节 | 通草、木通 |
| **补** | 补益虚损 | 人参、甘草 |
| **泄** | 泄闭开窍 | 大黄、葶苈 |
| **轻** | 轻解表邪 | 麻黄、薄荷 |
| **重** | 重镇安神 | 朱砂、磁石 |
| **滑** | 滑利下窍 | 滑石、冬葵子 |
| **涩** | 收敛固涩 | 龙骨、牡蛎 |
| **燥** | 燥湿利水 | 苍术、桑白皮 |
| **湿** | 滋润养液 | 麦冬、地黄 |

### 二、大量新增药物

陈藏器新增了大量为后世沿用的药物，如：

| 药物 | 现代认识 |
|------|---------|
| 延胡索 | 活血止痛（现代证明含延胡索乙素有镇痛作用） |
| 威灵仙 | 祛风湿、通经络（含原白头翁素有抗炎作用） |
| 骨碎补 | 补肾强骨、续伤止痛（促进骨折愈合） |
| 益智仁 | 暖肾固精缩尿、温脾开胃摄唾 |

### 三、纠正前代错误

在"解纷"部分中，陈藏器对《本经》《别录》《新修本草》等前代著作中的药物来源、品种考订错误进行系统纠正。

## 学术地位

1. 唐代官修《新修本草》之后最重要的私人增补
2. 开创药物功效分类（十剂）的新维度
3. 对《本草纲目》的影响——李时珍引陈氏之说近 400 条
4. 民间药和地方药的第一次系统收集
