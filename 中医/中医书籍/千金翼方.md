# 千金翼方

[TOC]

## 简介

《千金翼方》是唐代**孙思邈**为补充《千金要方》不足而作的姊妹篇，成书于孙氏晚年（约 682 年）。全书 30 卷。"翼"为辅助之意——补充《千金要方》未备之处。

> 两书合称《千金方》，与孙思邈的《银海精微》（眼科）共同构成"药王"的传世之作。

## 与《千金要方》的区别

《千金翼方》的侧重点不同：

| | 《千金要方》 | 《千金翼方》 |
|---|---|---|
| 侧重点 | 综合性临床 | 药物 + 伤寒 |
| 药物论述 | 较少 | **药物部分极详**——收录唐代引进的外来药 |
| 伤寒 | 有论述但非重点 | 加入了对《伤寒论》内容的整理 |

## 内容结构

| 卷次 | 内容 |
|:---:|------|
| 卷一 ~ 四 | **本草**——药物按自然属性分类，收录大量外来药和民间药 |
| 卷五 ~ 八 | 妇人、小儿 |
| 卷九 ~ 十 | **伤寒**——取自仲景《伤寒论》内容 |
| 卷十一 | 小儿惊痫 |
| 卷十二 ~ 十五 | 养性、辟谷、退居（养生/辟谷/隐居） |
| 卷十六 ~ 十七 | 中风 |
| 卷十八 ~ 二十 | 杂病 |
| 卷二十一 ~ 二十四 | 消渴诸淋疮痈等 |
| 卷二十五 | 色脉（诊断） |
| 卷二十六 ~ 二十八 | 针灸 |
| 卷二十九 ~ 三十 | 禁经（祝由、符咒——反映唐代医学中的民间宗教成素） |

## 增补药物

唐代丝绸之路上传入的外来药物在《千金翼方》中集中收录：

- 胡椒、补骨脂、荜茇、阿魏等
- 乳香、没药、安息香等香料药

## 养性延年

孙思邈本人活了 101 岁（一说 141 岁），其养生方法在《千金翼方》"养性"卷中有详细记载：

1. 调气——吐纳导引（类似气功）
2. 按摩——全身自我按摩
3. 服食——合理服用滋补药物
4. 房中——节欲保精
5. 居处——居住环境的选择

> 孙思邈的养生观核心：**顺其自然、适度节制**。"莫强食、莫强饮、莫强举重"，一切以中和为度。
