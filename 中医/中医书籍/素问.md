# 素问

[TOC]

## 简介

《素问》是《黄帝内经》的组成部分之一（另一部为《灵枢》），共 81 篇，主要阐述中医基础理论和治则。

"素问"名称含义：一说黄帝与岐伯等**平素答问**（日常问答），一说为探究**质素**（本质）的问难。

## 代表性篇目

| 篇目 | 核心内容 |
|------|---------|
| 上古天真论 | 养生总纲——"法于阴阳，和于术数"；肾气与生长衰老的关系 |
| 四气调神大论 | 四季养生——春生、夏长、秋收、冬藏；"治未病" |
| 生气通天论 | 天人相应——人体阳气与自然之气相通 |
| 阴阳应象大论 | 阴阳五行与人体生理病理的对应 |
| 灵兰秘典论 | 十二脏腑各自的功能定位（"心者君主之官"） |
| 六节藏象论 | 藏象理论 |
| 五脏生成论 | 五脏与体表组织的联系 |
| 异法方宜论 | 因地因人制宜——不同地域/体质应该用不同治法 |
| 脉要精微论 | 脉诊理论 |
| 热论 | 热病的六经辨证雏形（后世张仲景在此发挥为六经辨证） |
| 咳论 | "五脏六腑皆令人咳，非独肺也" |
| 痹论 | 风寒湿三气杂至合而为痹 |
| 痿论 | "治痿独取阳明" |
| 至真要大论 | 病机十九条——"诸风掉眩皆属于肝"等 |
