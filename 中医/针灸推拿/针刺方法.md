# 针刺方法

## 概述

针刺法是用金属制成的毫针刺激人体腧穴，通过经络的作用以防治疾病的方法。

> 《灵枢·九针十二原》："刺之要，气至而有效"——得气是针刺取效的关键。

---

## 一、针具

### 1.1 毫针的基本结构

```
毫针结构
        │
        ├─ 针尖：刺入皮肤的尖端
        ├─ 针体：针尖至针根部分
        ├─ 针根：针体与针柄的连接处
        └─ 针柄：用金属丝缠绕的手持部分
```

### 1.2 毫针规格

| 规格 | 用途 |
|:---|------|
| 粗针 (0.35~0.45mm) | 四肢肌肉丰厚处——用于泻法、强刺激 |
| 细针 (0.25~0.30mm) | 面部、肌肉薄弱处——常用临床 |
| 短针 (0.5~1.5 寸) | 头面、手指等浅薄部位 |
| 长针 (2~4 寸) | 臀部、大腿等肌肉丰厚处 |

> 临床最常用：0.30mm × 40mm（1.5 寸）

## 二、针刺前的准备

### 2.1 体位

| 体位 | 适用部位 | 常见取穴 |
|------|---------|---------|
| 仰卧位 | 头面、胸腹、四肢前部 | 中脘、足三里 |
| 侧卧位 | 身侧、下肢外侧 | 环跳、阳陵泉 |
| 俯卧位 | 项背、腰臀、下肢后部 | 大椎、肾俞、委中 |
| 仰靠坐位 | 头面、颈部 | 风池、百会 |
| 俯伏坐位 | 项背肩部 | 大椎、肺俞 |

### 2.2 消毒

- 针具：高压灭菌或一次性使用
- 腧穴部位：75% 酒精棉从中心向外擦拭
- 术者手指：75% 酒精消毒

## 三、进针方法

| 进针法 | 操作 | 适用 |
|--------|------|------|
| **指切进针** | 一手拇指甲切按皮肤，另手持针沿指甲刺入 | 短针——各部位通用 |
| **夹持进针** | 双手持消毒干棉球夹持针体进针 | 长针——肌肉丰厚处 |
| **提捏进针** | 拇食指提捏皮肤后刺入 | 皮肉浅薄处（如面部印堂） |
| **舒张进针** | 拇食指撑开皮肤后刺入 | 皮肤松弛处（如腹部） |

### 针刺角度

| 角度 | 针与皮肤 | 适用部位 |
|:---|:---|------|
| 直刺 | 90° | 四肢、腰腹肌肉丰厚处 |
| 斜刺 | 45° | 关节、胸肋、肌肉浅薄处 |
| 平刺（横刺） | 15° | 头皮、胸背部皮下 |

## 四、行针与得气

### 4.1 行针手法

行针是进针后为产生或加强针感而施行的手法。

| 手法 | 操作 | 作用 |
|:---|------|------|
| 提插法 | 针体上下进退 | 运针调气 |
| 捻转法 | 针柄左右旋转 | 催气导气 |
| 循法 | 沿经脉循按——辅助催气 | 气滞不行 |
| 弹法 | 弹针柄——增强针感 | 留针时催气 |
| 刮法 | 指甲刮针柄——扩大针感 | 针感未至 |

### 4.2 得气

**得气**是针刺后患者产生的酸、麻、重、胀等感觉，是针刺取效的标志。

| 得气的表现 | |
|:---|------|
| 患者感觉 | 酸、麻、胀、重、蚁走感 |
| 术者感觉 | 针下有沉紧感，如鱼吞钩 |
| 意义 | 气至效至；不得气则针刺效果差 |

> 影响得气的因素：取穴不准、深浅不当、体质虚弱。可留针候气、循经催气。

## 五、补泻手法

补泻是通过针刺手法的不同来调节机体虚实状态。

| 手法 | 补法 | 泻法 |
|:---|------|------|
| 提插补泻 | 重插轻提 | 重提轻插 |
| 捻转补泻 | 拇指向前顺时针捻转（慢，角度小） | 拇指向后逆时针捻转（快，角度大） |
| 疾徐补泻 | 慢进针→快出针 | 快进针→慢出针 |
| 迎随补泻 | 针尖顺经络方向 | 针尖逆经络方向 |
| 呼吸补泻 | 呼气进针→吸气出针 | 吸气进针→呼气出针 |
| 开阖补泻 | 出针速按针孔 | 出针摇大针孔不按 |

| 辨证 | 原则 | 示例 |
|:---|------|------|
| 虚证 | 用补法——激发正气 | 气虚乏力：补足三里 |
| 实证 | 用泻法——祛除邪气 | 发热、便秘：泻曲池、天枢 |
| 不虚不实 | 平补平泻 | 日常调养 |

## 六、留针与出针

| 环节 | 说明 |
|:---|------|
| **留针** | 一般 15~30 分钟——使针效持久 |
| **间歇行针** | 留针期间每 5~10 分钟行针 1 次 |
| **出针** | 左手持干棉球按压针孔旁，右手速拔 |
| **注意事项** | 出针后检查针数——防止遗漏 |

## 七、异常情况处理

| 异常 | 表现 | 处理 |
|:---|------|------|
| **晕针** | 头晕、心慌、面白、汗出 | 立即出针 → 平卧头低位 → 保暖→ 饮温开水→ 掐人中/内关 |
| **滞针** | 针体捻转不动 | 消除患者紧张 → 循按周围 → 再出针 |
| **弯针** | 针体弯曲在体内 | 顺弯曲方向缓慢拔出，不可强力抽 |
| **断针** | 针体折断在体内 | 保持体位不动 → 露出段用镊子夹出 → 深部手术取出 |
| **出血或血肿** | 出针后出血或青紫 | 干棉球按压 1~3 分钟；青紫则先冷敷→24h 后热敷 |

### 晕针的预防

- 饥饿、疲劳 → **不针**
- 初次针灸 → 卧位
- 手法由轻渐重
- 全程观察患者反应

## 八、针刺注意事项

| 禁忌/注意 | 说明 |
|:---|------|
| 极度饥饿、饱食、醉酒、大出血后 | 禁针 |
| 孕妇腹部、腰骶部 | 禁针 |
| 小儿囟门未合处 | 禁针 |
| 皮肤感染、溃疡、肿瘤处 | 禁针 |
| 有出血倾向者（血友病、抗凝治疗） | 慎用 |
| 胸背过深——防止气胸 | 斜刺、浅刺 |
| 眼区、项部——严格掌握角度和深度 | 谨慎操作 |
