# 太平圣惠方

[TOC]

## 简介

《太平圣惠方》是北宋初年的大型官修医方全书，由王怀隐等奉宋太宗赵光义之敕编纂，成书于淳化三年（992 年）。全书共 100 卷，分 1670 门，载方多达 **16834 首**，是宋代最早、最大型的一部官修综合医学著作。

> 书名取自太宗年号"太平兴国"，代表太平盛世帝王惠泽民众之意。

## 内容结构

| 卷次 | 内容 |
|:---:|------|
| 卷一 ~ 二 | 诊脉法（脉诀） |
| 卷三 ~ 七 | 中风、诸风 |
| 卷八 ~ 十八 | 伤寒（包括温病和时气） |
| 卷十九 ~ 三十一 | 诸疾（消渴、水肿、黄疸、虚劳等） |
| 卷三十二 ~ 三十九 | 眼、齿、咽喉、口舌、耳鼻 |
| 卷四十 ~ 五十九 | 头面、心腹、脚气、腰膝、诸痛 |
| 卷六十 ~ 六十四 | 积聚、痰饮、咳嗽、喘促 |
| 卷六十五 ~ 六十八 | 疮疡、痈疽 |
| 卷六十九 ~ 八十一 | 妇人（含经带胎产） |
| 卷八十二 ~ 九十三 | 小儿诸疾 |
| 卷九十四 ~ 九十五 | 神仙方、丹药 |
| 卷九十六 ~ 九十八 | **食治**（食疗——继承孙思邈传统） |
| 卷九十九 ~ 一百 | 针灸（含腧穴图） |

## 编撰特点

1. **先论后方**：每门前面有简要的病源证候论说，然后列出大量方药
2. **官修性质**：宋代馆阁组织编修，征用大量医官
3. **法象思想**：开篇引唐太宗"割股疗疾"图，强调仁政

## 学术贡献

1. 保存了大量唐、五代、宋初医方
2. 集中了宋代官方的妇科、儿科、针灸经验
3. 食疗卷继承并发展了唐代孙思邈《千金方》和孟诜《食疗本草》
4. 为后世的《圣济总录》提供了编撰基础和内容框架
