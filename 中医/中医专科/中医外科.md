# 中医外科

## 概述

中医外科是研究外科疾病辨证论治的学科，涵盖疮疡、皮肤病、肛肠疾病等。

---

## 一、疮疡疾病

### 1.1 疮疡概论

```
疮疡分类
        │
        ├─ 阳证疮疡：红肿热痛、进展快
        ├─ 阴证疮疡：皮色不变、疼痛不明显
        └─ 半阴半阳证：介于阳证和阴证之间
```

### 1.2 疖

```
疖辨证论治
        │
        ├─ 热毒蕴结
        │   ├─ 症状：红肿热痛、根脚较浅
        │   ├─ 治法：清热解毒
        │   └─ 方药：五味消毒饮
        │
        ├─ 暑热浸淫
        │   ├─ 症状：好发于夏秋、红肿热痛
        │   ├─ 治法：清暑化湿解毒
        │   └─ 方药：清暑汤
        │
        └─ 体虚毒恋
            ├─ 症状：反复发作、缠绵不愈
            ├─ 治法：扶正解毒
            └─ 方药：四妙汤
```

### 1.3 痈

```
痈辨证论治
        │
        ├─ 火毒凝结
        │   ├─ 症状：红肿热痛、范围较大
        │   ├─ 治法：清热解毒，行瘀活血
        │   └─ 方药：仙方活命饮
        │
        ├─ 热盛肉腐
        │   ├─ 症状：化脓破溃、脓液黄稠
        │   ├─ 治法：和营清热，透脓托毒
        │   └─ 方药：透脓散
        │
        └─ 气血两虚
            ├─ 症状：收口迟缓、脓水清稀
            ├─ 治法：益气养血，托毒生肌
            └─ 方药：托里消毒散
```

### 1.4 疽

```
疽辨证论治
        │
        ├─ 初期：皮色不变、肿胀疼痛
        │   ├─ 治法：温通活血，化痰散结
        │   └─ 方药：阳和汤
        │
        ├─ 中期：皮色转红、疼痛加剧
        │   ├─ 治法：清热解毒，和营托毒
        │   └─ 方药：仙方活命饮合透脓散
        │
        └─ 后期：气血两虚、收口困难
            ├─ 治法：益气养血，托毒生肌
            └─ 方药：托里消毒散
```

            ├─ 症状：创面愈合迟缓、肉芽不鲜
            ├─ 治法：益气养血，生肌收口
            └─ 方药：八珍汤

## 总结

中医外科通过辨证论治治疗各种外科疾病，强调局部与整体相结合，根据不同的病因和证型采用不同的治疗方法。
