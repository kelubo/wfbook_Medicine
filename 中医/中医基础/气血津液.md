# 气血津液

## 概述

气血津液是构成人体和维持人体生命活动的基本物质。

---

## 一、气

### 1.1 气的概念

气是构成人体和维持人体生命活动的最基本物质。

```
气的分类
        │
        ├─ 元气
        │   ├─ 来源：先天之精
        │   ├─ 功能：生命活动的原动力
        │   └─ 分布：全身
        │
        ├─ 宗气
        │   ├─ 来源：吸入的清气 + 水谷精气
        │   ├─ 功能：走息道、贯心脉
        │   └─ 分布：胸中
        │
        ├─ 营气
        │   ├─ 来源：水谷精气
        │   ├─ 功能：营养全身
        │   └─ 分布：血脉中
        │
        └─ 卫气
            ├─ 来源：水谷精气
            ├─ 功能：护卫肌表、调节体温
            └─ 分布：体表
```

### 1.2 气的功能

| 功能 | 描述 | 示例 |
|------|------|------|
| 推动作用 | 推动血液运行和津液代谢 | 心气推动血行 |
| 温煦作用 | 维持体温和脏腑功能 | 阳气温煦机体 |
| 防御作用 | 抵抗外邪入侵 | 卫气护卫肌表 |
| 固摄作用 | 固摄血液、津液 | 脾气固摄血液 |
| 气化作用 | 物质转化和能量代谢 | 食物转化为营养 |

### 1.3 气机失调

```
气机失调类型
        │
        ├─ 气虚
        │   ├─ 表现：气短、乏力、自汗
        │   └─ 治疗：补气
        │
        ├─ 气滞
        │   ├─ 表现：胀痛、胸闷、嗳气
        │   └─ 治疗：行气
        │
        ├─ 气逆
        │   ├─ 表现：咳嗽、呕吐、头痛
        │   └─ 治疗：降气
        │
        └─ 气陷
            ├─ 表现：头晕、内脏下垂
            └─ 治疗：升提
```

## 二、血

### 2.1 血的概念

血是循行于脉管中的红色液体，具有营养和滋润全身的功能。

```
血的生成
        │
        ├─ 水谷精微 → 营气 → 血
        │
        ├─ 肾精 → 肝血 → 血
        │
        └─ 心肺作用：气化生成
```

### 2.2 血的功能

| 功能 | 描述 |
|------|------|
| 营养作用 | 滋养脏腑、组织、器官 |
| 滋润作用 | 滋润皮肤、毛发、肌肉 |
| 神志作用 | 维持精神活动 |

### 2.3 血的运行

```
血液运行
        │
        ├─ 心：推动血行
        ├─ 肺：调节气机
        ├─ 肝：贮藏和调节血量
        ├─ 脾：统摄血液
        └─ 脉：运行通道
```

### 2.4 血病辨证

| 类型 | 表现 | 治疗原则 |
|------|------|----------|
| 血虚 | 面色苍白、头晕、心悸 | 补血 |
| 血瘀 | 刺痛、瘀斑、肿块 | 活血化瘀 |
| 血热 | 出血、发热、口干 | 清热凉血 |
| 血寒 | 畏寒、冷痛、紫绀 | 温经散寒 |

---

## 三、津液

### 3.1 津液的概念

津液是体内一切正常水液的总称，包括汗液、尿液、唾液、泪液等。

```
津液分类
        │
        ├─ 津：质地清稀，流动性大
        │   ├─ 分布：体表、肌肉、孔窍
        │   └─ 功能：滋润
        │
        └─ 液：质地稠厚，流动性小
            ├─ 分布：关节、脑髓、脏腑
            └─ 功能：濡养
```

### 3.2 津液的代谢

```
津液代谢过程
        │
        ├─ 脾：运化水液
        ├─ 肺：通调水道
        ├─ 肾：主水液
        └─ 三焦：运行通道
```

### 3.3 津液失调

| 类型 | 表现 | 治疗原则 |
|------|------|----------|
| 津液不足 | 口干、皮肤干燥、大便干结 | 滋阴润燥 |
| 水湿停滞 | 水肿、腹胀、痰多 | 利水渗湿 |
| 痰饮 | 咳嗽、痰多、胸闷 | 化痰祛湿 |

## 四、气血津液的关系

### 4.1 气与血的关系

```
气与血的关系
        │
        ├─ 气为血之帅
        │   ├─ 气能生血：气推动血液生成
        │   ├─ 气能行血：气推动血液运行
        │   └─ 气能摄血：气固摄血液
        │
        └─ 血为气之母
            ├─ 血能载气：血液承载气
            └─ 血能养气：血液滋养气
```

### 4.2 气与津液的关系

| 关系 | 描述 |
|------|------|
| 气能生津 | 气推动津液生成 |
| 气能行津 | 气推动津液运行 |
| 气能摄津 | 气固摄津液 |
| 津能载气 | 津液承载气 |

### 4.3 血与津液的关系

| 关系 | 描述 |
|------|------|
| 津血同源 | 津液和血液都来源于水谷精微 |
| 津能生血 | 津液渗入血脉成为血液 |
| 血能生津 | 血液渗出脉外成为津液 |

---

## 总结

气血津液是构成人体和维持人体生命活动的基本物质，它们之间相互依存、相互转化，共同维持人体的正常生理功能。
