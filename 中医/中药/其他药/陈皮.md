# 陈皮

[TOC]

## 概述

陈皮为芸香科植物橘 *Citrus reticulata* Blanco 及其栽培变种的干燥成熟果皮。主产于广东、福建、四川、浙江等地，以**广东新会**所产的"广陈皮"品质最优。

> 采收于成熟果实，剥取果皮经晒干或低温干燥而成。"陈"即愈陈愈良——传统认为存放 3 年以上才可入药（挥发油部分散失、药性趋和），但也不宜超过 10 年以免成分退化。

## 性味归经

- **性味**：辛、苦、温
- **归经**：脾、肺

## 功效

| 功效 | 应用 |
|------|------|
| **理气健脾** | 脾胃气滞——脘腹胀满、食少吐泻 |
| **燥湿化痰** | 痰湿壅肺——咳嗽痰多、胸闷气短 |

## 使用注意

| 注意 | 说明 |
|------|------|
| 用量 | 煎服 3 ~ 10 g |
| 禁忌 | 阴虚燥咳（干咳无痰）、内有实热者慎用 |
| 配伍 | 常与法半夏（二陈汤）、苍术（平胃散）等同用 |

## 现代研究

陈皮的主要活性成分：

| 成分 | 作用 |
|------|------|
| 橙皮苷 (Hesperidin) | 维生素P类作用—保护血管、抗氧化 |
| 挥发油（柠檬烯为主） | 刺激胃肠道蠕动、祛痰 |
| 川陈皮素 | 抗炎、抑制血小板聚集 |
| 辛弗林 | 类似麻黄碱的舒张支气管作用（含量很低） |

主要药理作用：① 促进消化液分泌、助消化；② 缓解胃肠平滑肌痉挛；③ 祛痰镇咳；④ 抗炎、抗氧化。

## 代表方剂

| 方剂 | 出处 | 陈皮的作用 |
|------|------|-----------|
| **二陈汤** | 《局方》 | 半夏+陈皮+茯苓+甘草——燥湿化痰之祖方（陈皮理气化痰） |
| 平胃散 | 《局方》 | 苍术+厚朴+陈皮+甘草——燥湿运脾 |
| **六君子汤** | 《局方》 | 四君子汤 + 陈皮 + 半夏——健脾化痰 |
| 保和丸 | 《丹溪心法》 | 消食导滞——陈皮下气消胀 |

> 二陈汤以半夏、陈皮二味为主，因"陈久者良"两者均要求陈久使用，故得名"二陈汤"。

## 品质鉴别

| 指标 | 优质特征 |
|------|---------|
| 产地 | 广东新会（核心产区：梅江、天马、东甲等） |
| 年份 | 3 ~ 5 年最佳 |
| 外表 | 外皮深褐色有光泽、内皮洁白 |
| 香气 | 浓郁柑香，无霉味 |
| 厚薄 | 皮厚者为佳（广陈皮油胞大而突出） |

## 青皮

**青皮**为橘未成熟果皮或幼果：

| | 陈皮 | 青皮 |
|---|---|---|
| 来源 | 成熟果皮 | 未成熟果皮/幼果 |
| 性味 | 辛温，较缓 | 苦辛温，破气力强 |
| 药力 | 行气调中（缓和） | 破气散结（猛烈） |
| 主治 | 脾肺气滞 | 肝气郁结、食积胀痛 |

## 橘核

橘的种子。苦平，归肝经。理气散结止痛，用于疝气疼痛、睾丸肿痛、乳房结块。煎服 3 ~ 9 g。
