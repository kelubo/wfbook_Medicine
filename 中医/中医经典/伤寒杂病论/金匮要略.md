# 金匮要略

[TOC]

## 简介

《金匮要略》全名《金匮要略方论》，东汉张仲景著，是《伤寒杂病论》的杂病部分。经西晋王叔和整理，北宋林亿等校定刊行。"金匮"喻文献珍贵如藏于金匮（金柜），"要略"即简要精要之意。

全书共 3 卷、25 篇，载方 262 首，以**脏腑经络辨证**为核心，系统论述内科杂病及部分外科、妇科病证，是中国历史上最早的杂病证治专著。

---

## 学术核心：脏腑经络辨证

不同于《伤寒论》的六经辨证，《金匮要略》以**脏腑经络**为纲，首创"千般疢难，不越三条"（三因论）：

| 病因 | 途径 |
|------|------|
| 内因 | 经络受邪，传入脏腑 |
| 外因 | 皮肤受邪，血脉壅塞 |
| 不内外因 | 房室、金刃、虫兽所伤 |

> 此为后世陈无择《三因极一病证方论》的理论渊源。

## 经典名方举要

### 瓜蒌薤白白酒汤（胸痹）

- **组成**：瓜蒌实一枚、薤白半升、白酒七升
- **功效**：通阳散结、豁痰下气
- **主治**：胸痹（冠心病心绞痛、胸膺闷痛、喘息咳唾）

### 大黄牡丹汤（肠痈）

- **组成**：大黄四两、牡丹一两、桃仁五十个、瓜子半升、芒硝三合
- **功效**：泻热破瘀、散结消肿
- **主治**：肠痈初起（急性阑尾炎未化脓期）

### 肾气丸（八味肾气丸）

- **组成**：干地黄八两、山药四两、山茱萸四两、泽泻三两、茯苓三两、牡丹皮三两、桂枝一两、附子一两
- **功效**：温补肾阳
- **主治**：肾阳不足（腰痛脚软、小便不利或反多）

### 酸枣仁汤（虚烦不寐）

- **组成**：酸枣仁二升、甘草一两、知母二两、茯苓二两、川芎二两
- **功效**：养血安神、清热除烦
- **主治**：虚烦不眠（神经衰弱性失眠）

### 甘麦大枣汤（脏躁）

- **组成**：甘草三两、小麦一升、大枣十枚
- **功效**：养心安神、和中缓急
- **主治**：妇人脏躁（癔症、更年期综合症属心阴不足者）

### 温经汤（妇科调经）

- **组成**：吴茱萸三两、当归二两、川芎二两、芍药二两、人参二两、桂枝二两、阿胶二两、牡丹皮二两、生姜二两、甘草二两、半夏半升、麦门冬一升
- **功效**：温经散寒、养血祛瘀
- **主治**：冲任虚寒、瘀血阻滞（月经不调、漏下不止、宫寒不孕）

## 《金匮》方剂特色

1. **同病异治**：同一水肿分为风水、皮水、正水、石水，处方各异
2. **异病同治**：同一肾气丸可治脚气、虚劳腰痛、痰饮、消渴、妇人转胞五种病
3. **治未病思想**：首篇即提出"见肝之病，知肝传脾，当先实脾"——预防传变
4. **剂型丰富**：汤剂、丸剂（薯蓣丸）、散剂（薏苡附子败酱散）、坐药（蛇床子散）、导法（蜜煎导）
5. **外治法**：历来被忽视，实则载有多种外治方

## 与《伤寒论》的关系

| | 《伤寒论》 | 《金匮要略》 |
|---|---|---|
| 核心辨证 | 六经辨证 | 脏腑经络辨证 |
| 主治 | 外感热病 | 内科杂病 |
| 病机侧重 | 邪正消长 | 脏腑功能失调 |
| 方剂数 | 113 方 | 262 方 |
| 共同核心方 | 两书重叠方约 42 首（如桂枝汤、承气汤、四逆汤等） | |

> 二书原为一体，合称《伤寒杂病论》，后世一分为二。临床应互相参看融会贯通。
