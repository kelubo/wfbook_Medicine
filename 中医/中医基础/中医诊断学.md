# 中医诊断学

## 概述

中医诊断学是研究诊断疾病的方法和理论的学科，包括望、闻、问、切四诊。

---

## 一、望诊

### 1.1 望神

望神是观察患者的精神状态。

```
神的分类
        │
        ├─ 得神
        │   ├─ 表现：精神饱满、目光明亮、面色红润
        │   └─ 意义：身体健康，病情较轻
        │
        ├─ 失神
        │   ├─ 表现：精神萎靡、目光呆滞、面色苍白
        │   └─ 意义：病情严重，预后较差
        │
        └─ 假神
            ├─ 表现：突然好转，如突然清醒、食欲增加
            └─ 意义：临终前的回光返照
```

### 1.2 望面色

望面色是观察患者的面部颜色和光泽。

```
面色与疾病
        │
        ├─ 白色
        │   ├─ 表现：面色苍白、淡白
        │   └─ 意义：气虚、血虚、阳虚
        │
        ├─ 黄色
        │   ├─ 表现：面色萎黄、黄胖、黄疸
        │   └─ 意义：脾虚、湿盛、肝胆疾病
        │
        ├─ 赤色
        │   ├─ 表现：面色潮红、通红
        │   └─ 意义：热证、阴虚
        │
        ├─ 青色
        │   ├─ 表现：面色青灰、青紫
        │   └─ 意义：寒证、血瘀、疼痛
        │
        └─ 黑色
            ├─ 表现：面色黧黑、晦暗
            └─ 意义：肾虚、血瘀、寒证
```

### 1.3 望形态

望形态是观察患者的形体和姿态。

```
形态与疾病
        │
        ├─ 形体肥胖
        │   ├─ 表现：体型肥胖
        │   └─ 意义：痰湿体质
        │
        ├─ 形体消瘦
        │   ├─ 表现：体型消瘦
        │   └─ 意义：阴虚、血虚
        │
        ├─ 姿态异常
        │   ├─ 半身不遂：中风后遗症
        │   ├─ 肢体震颤：肝风内动
        │   └─ 蜷缩成团：寒证、阳虚
        │
        └─ 动作异常
            ├─ 行走不稳：肝肾亏虚
            └─ 肢体麻木：气血不足
```

## 二、闻诊

### 2.1 听声音

听声音是听取患者的声音和语言。

```
声音与疾病
        │
        ├─ 语声
        │   ├─ 语声洪亮：实证、热证
        │   ├─ 语声低微：虚证、寒证
        │   ├─ 语声嘶哑：肺失清肃
        │   └─ 言语错乱：心神失常
        │
        ├─ 呼吸
        │   ├─ 呼吸急促：热证、实证
        │   ├─ 呼吸微弱：虚证、寒证
        │   ├─ 喘息：肺气不宣
        │   └─ 咳嗽：肺失清肃
        │
        ├─ 咳嗽
        │   ├─ 干咳：肺燥、阴虚
        │   ├─ 湿咳：痰湿、脾虚
        │   ├─ 痰黄黏稠：热证
        │   └─ 痰白稀薄：寒证
        │
        └─ 呕吐
            ├─ 呕吐物酸腐：食积
            ├─ 呕吐清水：胃寒
            └─ 呕吐苦水：肝胆湿热
```

### 2.2 嗅气味

嗅气味是闻患者身体和分泌物的气味。

```
气味与疾病
        │
        ├─ 口气
        │   ├─ 口臭：胃热、食积
        │   └─ 酸腐味：消化不良
        │
        ├─ 汗味
        │   ├─ 酸臭味：湿热
        │   └─ 腥膻味：寒湿
        │
        ├─ 痰涕味
        │   ├─ 痰黄黏稠有臭味：热证
        │   └─ 痰白稀薄无臭味：寒证
        │
        └─ 二便气味
            ├─ 大便酸腐：食积
            ├─ 大便腥臭：湿热
            └─ 小便黄赤有臭味：热证
```

## 三、问诊

### 3.1 问寒热

问寒热是询问患者的发热和怕冷情况。

```
寒热类型
        │
        ├─ 恶寒发热
        │   ├─ 表现：既怕冷又发热
        │   └─ 意义：外感表证
        │
        ├─ 但寒不热
        │   ├─ 表现：只怕冷不发热
        │   └─ 意义：寒证、阳虚
        │
        ├─ 但热不寒
        │   ├─ 壮热：高热不退，热证、实证
        │   ├─ 潮热：定时发热，阴虚、湿热
        │   └─ 低热：轻度发热，阴虚、气虚
        │
        └─ 寒热往来
            ├─ 表现：一会儿怕冷一会儿发热
            └─ 意义：少阳证、疟疾
```

### 3.2 问汗

问汗是询问患者的出汗情况。

```
出汗类型
        │
        ├─ 无汗
        │   ├─ 表现：不出汗
        │   └─ 意义：表寒证、阳虚
        │
        ├─ 自汗
        │   ├─ 表现：白天出汗，活动后加重
        │   └─ 意义：气虚、阳虚
        │
        ├─ 盗汗
        │   ├─ 表现：夜间出汗，醒来即止
        │   └─ 意义：阴虚
        │
        ├─ 战汗
        │   ├─ 表现：先恶寒战栗，后出汗
        │   └─ 意义：正邪交争
        │
        └─ 头汗
            ├─ 表现：头部出汗
            └─ 意义：上焦热盛、湿热
```

### 3.3 问疼痛

问疼痛是询问患者的疼痛部位和性质。

```
疼痛性质
        │
        ├─ 胀痛
        │   ├─ 表现：疼痛伴有胀满感
        │   └─ 意义：气滞
        │
        ├─ 刺痛
        │   ├─ 表现：疼痛如针刺
        │   └─ 意义：血瘀
        │
        ├─ 冷痛
        │   ├─ 表现：疼痛伴有冷感
        │   └─ 意义：寒证
        │
        ├─ 热痛
        │   ├─ 表现：疼痛伴有热感
        │   └─ 意义：热证
        │
        ├─ 隐痛
        │   ├─ 表现：疼痛不明显，时隐时现
        │   └─ 意义：虚证
        │
        └─ 绞痛
            ├─ 表现：剧烈疼痛如绞
            └─ 意义：实证、寒证
```

### 3.4 问饮食

问饮食是询问患者的食欲和饮食情况。

```
饮食与疾病
        │
        ├─ 食欲减退
        │   ├─ 表现：不想吃东西
        │   └─ 意义：脾虚、湿盛、食欲不振
        │
        ├─ 多食易饥
        │   ├─ 表现：吃得多但容易饿
        │   └─ 意义：胃火亢盛
        │
        ├─ 饥不欲食
        │   ├─ 表现：饥饿但不想吃
        │   └─ 意义：胃阴不足
        │
        ├─ 口味异常
        │   ├─ 口淡：脾虚、湿盛
        │   ├─ 口苦：肝胆湿热
        │   ├─ 口甜：脾胃湿热
        │   ├─ 口酸：胃热、食积
        │   └─ 口咸：肾虚
        │
        └─ 饮水情况
            ├─ 口渴多饮：热证、阴虚
            ├─ 口干不欲饮：湿证、阴虚
            └─ 饮水即吐：痰饮、水湿
```

## 四、切诊

### 4.1 脉诊

脉诊是通过触摸脉搏来诊断疾病。

```
常见脉象
        │
        ├─ 浮脉
        │   ├─ 特点：轻取即得
        │   └─ 意义：表证、虚证
        │
        ├─ 沉脉
        │   ├─ 特点：重按始得
        │   └─ 意义：里证、实证
        │
        ├─ 迟脉
        │   ├─ 特点：脉率缓慢（<60次/分钟）
        │   └─ 意义：寒证
        │
        ├─ 数脉
        │   ├─ 特点：脉率加快（>90次/分钟）
        │   └─ 意义：热证
        │
        ├─ 虚脉
        │   ├─ 特点：脉细弱无力
        │   └─ 意义：虚证
        │
        ├─ 实脉
        │   ├─ 特点：脉粗大有力
        │   └─ 意义：实证
        │
        ├─ 细脉
        │   ├─ 特点：脉细如线
        │   └─ 意义：血虚、阴虚
        │
        ├─ 弦脉
        │   ├─ 特点：脉来弦直
        │   └─ 意义：肝病、疼痛、痰饮
        │
        ├─ 滑脉
        │   ├─ 特点：脉来圆滑
        │   └─ 意义：痰湿、食积、妊娠
        │
        └─ 涩脉
            ├─ 特点：脉来涩滞
            └─ 意义：血瘀、血虚
```

### 4.2 按诊

按诊是通过按压身体来诊断疾病。

```
按诊方法
        │
        ├─ 按肌肤
        │   ├─ 肌肤热：热证
        │   ├─ 肌肤凉：寒证
        │   ├─ 肌肤湿润：有汗
        │   └─ 肌肤干燥：无汗、阴虚
        │
        ├─ 按腹部
        │   ├─ 腹部胀满：气滞、食积
        │   ├─ 腹部压痛：实证、瘀血
        │   ├─ 腹部肿块：积聚
        │   └─ 腹部柔软：虚证
        │
        ├─ 按四肢
        │   ├─ 四肢温热：阳气充足
        │   ├─ 四肢冰凉：阳虚、寒证
        │   ├─ 肢体浮肿：水肿
        │   └─ 肢体麻木：气血不足
        │
        └─ 按腧穴
            ├─ 穴位压痛：对应脏腑病变
            └─ 穴位结节：积聚、瘀血
```

## 五、辨证论治

### 5.1 八纲辨证

八纲辨证是中医辨证的基本方法。

```
八纲辨证
        │
        ├─ 表里
        │   ├─ 表证：病在体表，外感初期
        │   └─ 里证：病在脏腑，内伤或外感后期
        │
        ├─ 寒热
        │   ├─ 寒证：怕冷、喜热、舌苔白
        │   └─ 热证：发热、喜冷、舌苔黄
        │
        ├─ 虚实
        │   ├─ 虚证：正气不足，脉弱
        │   └─ 实证：邪气盛，脉实
        │
        └─ 阴阳
            ├─ 阴证：寒、虚、里的表现
            └─ 阳证：热、实、表的表现
```

### 5.2 脏腑辨证

脏腑辨证是根据脏腑的生理功能和病理表现来辨证。

```
脏腑辨证要点
        │
        ├─ 心
        │   ├─ 心气虚：心悸、气短、乏力
        │   ├─ 心血虚：心悸、失眠、面色苍白
        │   ├─ 心阴虚：心悸、心烦、盗汗
        │   └─ 心阳虚：心悸、畏寒、浮肿
        │
        ├─ 肝
        │   ├─ 肝气郁结：胸闷、易怒、胀痛
        │   ├─ 肝火上炎：头痛、面红、口苦
        │   ├─ 肝阳上亢：头晕、头痛、烦躁
        │   └─ 肝血虚：头晕、眼花、肢体麻木
        │
        ├─ 脾
        │   ├─ 脾气虚：食欲不振、腹胀、乏力
        │   ├─ 脾虚湿盛：腹胀、便溏、浮肿
        │   └─ 脾阳虚：畏寒、腹胀、便溏
        │
        ├─ 肺
        │   ├─ 肺气虚：咳嗽、气短、自汗
        │   ├─ 肺阴虚：干咳、痰少、盗汗
        │   ├─ 风寒束肺：咳嗽、恶寒、无汗
        │   └─ 风热犯肺：咳嗽、发热、咽痛
        │
        └─ 肾
            ├─ 肾阳虚：畏寒、腰膝冷痛、夜尿多
            ├─ 肾阴虚：腰膝酸痛、潮热、盗汗
            └─ 肾气不固：尿频、遗精、早泄
```

### 5.3 气血辨证

气血辨证是根据气血的病理变化来辨证。

```
气血辨证要点
        │
        ├─ 气虚
        │   ├─ 表现：气短、乏力、自汗、脉弱
        │   └─ 治疗：补气
        │
        ├─ 血虚
        │   ├─ 表现：面色苍白、头晕、心悸、脉细
        │   └─ 治疗：补血
        │
        ├─ 气滞
        │   ├─ 表现：胀痛、胸闷、嗳气、脉弦
        │   └─ 治疗：行气
        │
        ├─ 血瘀
        │   ├─ 表现：刺痛、瘀斑、肿块、脉涩
        │   └─ 治疗：活血化瘀
        │
        └─ 气血两虚
            ├─ 表现：气短乏力、面色苍白、头晕心悸
            └─ 治疗：益气养血
```

---

## 总结

中医诊断学通过望、闻、问、切四诊收集病情资料，运用八纲辨证、脏腑辨证、气血辨证等方法进行辨证，为治疗提供依据。
