# 医学影像学基础

## 概述

医学影像学是利用各种成像技术对人体进行诊断和治疗的学科，包括X光、CT、MRI、超声等。

---

## 一、影像学技术分类

### 1.1 放射影像学

```
放射影像学技术
        │
        ├─ X线摄影：最常用的影像学检查
        │   ├─ 原理：X射线穿透人体成像
        │   ├─ 应用：骨骼系统、胸部、腹部
        │   └─ 优点：快速、经济
        │
        ├─ CT（计算机断层扫描）
        │   ├─ 原理：X射线断层扫描+计算机重建
        │   ├─ 应用：全身各部位检查
        │   └─ 优点：分辨率高、断层成像
        │
        └─ 数字减影血管造影（DSA）
            ├─ 原理：血管造影+计算机减影
            ├─ 应用：血管疾病诊断和介入治疗
            └─ 优点：血管显示清晰
```

### 1.2 磁共振影像学

```
MRI（磁共振成像）
        │
        ├─ 原理：利用磁场和射频脉冲成像
        ├─ 特点：无辐射、软组织分辨率高
        ├─ 序列：T1加权、T2加权、弥散加权、增强扫描
        ├─ 应用：神经系统、软组织、关节
        └─ 禁忌：体内有金属植入物、心脏起搏器
```

### 1.3 超声影像学

```
超声检查
        │
        ├─ 原理：超声波反射成像
        │   ├─ B型超声：二维图像
        │   ├─ 彩色多普勒：血流显示
        │   ├─ 频谱多普勒：血流速度测量
        │   └─ 三维超声：三维图像
        │
        ├─ 特点：无辐射、实时成像、经济
        ├─ 应用：腹部、妇产科、心血管、小器官
        └─ 局限性：骨骼和气体干扰
```

### 1.4 核医学

```
核医学检查
        │
        ├─ 原理：放射性核素显像
        │   ├─ SPECT（单光子发射计算机断层）
        │   ├─ PET（正电子发射断层）
        │   └─ PET-CT：PET+CT融合
        │
        ├─ 特点：功能成像、分子成像
        ├─ 应用：肿瘤诊断、心脏功能检查、神经系统检查
        └─ 注意：放射性暴露
```

## 二、各系统影像学检查

### 2.1 骨骼系统

```
骨骼系统影像学检查
        │
        ├─ X线摄影：骨折、骨质疏松、骨肿瘤
        │   ├─ 骨折：显示骨折线和移位
        │   ├─ 骨质疏松：骨密度降低
        │   └─ 骨肿瘤：骨质破坏和软组织肿块
        │
        ├─ CT：复杂骨折、骨肿瘤、脊柱病变
        │
        ├─ MRI：骨髓病变、软组织肿瘤、关节病变
        │
        └─ 骨密度检查：骨质疏松诊断
```

### 2.2 呼吸系统

```
呼吸系统影像学检查
        │
        ├─ 胸部X线：肺炎、肺结核、肺癌、胸腔积液
        │   ├─ 肺炎：肺部阴影
        │   ├─ 肺结核：结核病灶
        │   ├─ 肺癌：肺部肿块
        │   └─ 胸腔积液：胸腔液体
        │
        ├─ 胸部CT：肺部小结节、肺癌分期、纵隔病变
        │
        ├─ MRI：纵隔肿瘤、肺血管疾病
        │
        └─ 核医学：肺栓塞诊断、肺癌转移评估
```

### 2.3 心血管系统

```
心血管系统影像学检查
        │
        ├─ 心脏X线：心脏大小和形态
        ├─ 超声心动图：心脏结构和功能
        │   ├─ 心脏瓣膜：瓣膜形态和功能
        │   ├─ 心功能：EF值测量
        │   └─ 心包疾病：心包积液
        ├─ 冠状动脉CT：冠状动脉钙化和狭窄
        ├─ 冠状动脉造影：金标准，冠心病诊断
        └─ MRI：心脏功能和心肌病变
```

### 2.4 消化系统

```
消化系统影像学检查
        │
        ├─ 腹部X线：肠梗阻、消化道穿孔
        │   ├─ 肠梗阻：肠管扩张和气液平
        │   └─ 消化道穿孔：膈下游离气体
        │
        ├─ 超声：肝胆胰脾肾检查
        │   ├─ 肝脏：肝肿瘤、脂肪肝
        │   ├─ 胆囊：胆结石、胆囊炎
        │   ├─ 胰腺：胰腺炎、胰腺癌
        │   └─ 脾脏：脾肿大、脾梗死
        │
        ├─ CT：腹部肿瘤、炎症、外伤
        │
        ├─ MRI：肝脏病变、胰腺病变
        │
        ├─ 消化道造影：食管、胃、肠道检查
        │   ├─ 钡餐造影：食管和胃
        │   └─ 钡灌肠：结肠
        │
        └─ 内镜检查：胃镜、肠镜
```

### 2.5 泌尿系统

```
泌尿系统影像学检查
        │
        ├─ 超声：肾脏、输尿管、膀胱
        │   ├─ 肾脏：肾结石、肾肿瘤、肾积水
        │   ├─ 输尿管：输尿管结石
        │   └─ 膀胱：膀胱结石、膀胱癌
        │
        ├─ CT：泌尿系统肿瘤、结石、外伤
        │
        ├─ IVP（静脉肾盂造影）：肾脏功能和尿路
        │
        └─ MRI：肾脏病变、尿路疾病
```

### 2.6 神经系统

```
神经系统影像学检查
        │
        ├─ 头颅CT：脑出血、脑梗死、脑肿瘤、颅脑外伤
        │   ├─ 脑出血：高密度出血灶
        │   ├─ 脑梗死：低密度梗死灶
        │   ├─ 脑肿瘤：占位性病变
        │   └─ 颅脑外伤：颅骨骨折、颅内血肿
        │
        ├─ 头颅MRI：脑梗死、脑肿瘤、多发性硬化
        │   ├─ DWI：急性脑梗死
        │   ├─ FLAIR：脑水肿和病变
        │   └─ 增强扫描：肿瘤和炎症
        │
        ├─ 脑血管造影：脑血管疾病诊断
        │
        └─ 脊髓MRI：脊髓病变、椎间盘突出
```

## 三、影像学报告解读

### 3.1 报告结构

```
影像学报告结构
        │
        ├─ 检查信息：患者信息、检查部位、检查方法
        ├─ 影像学表现：描述检查所见
        ├─ 诊断意见：给出诊断结论
        └─ 建议：进一步检查或治疗建议
```

### 3.2 报告解读要点

```
报告解读要点
        │
        ├─ 病变位置：病变所在部位
        ├─ 病变大小：病变尺寸
        ├─ 病变形态：病变形状和边缘
        ├─ 病变密度/信号：病变密度或信号特征
        ├─ 病变强化：增强扫描后的强化特征
        └─ 周围结构：病变与周围组织的关系
```

## 四、影像学检查原则

```
影像学检查原则
        │
        ├─ 合理选择：根据病情选择合适的检查方法
        ├─ 安全第一：减少辐射暴露
        ├─ 联合应用：多种检查方法互补
        ├─ 动态观察：定期复查监测病变变化
        └─ 规范报告：准确描述和诊断
```

## 五、影像学新技术

```
影像学新技术
        │
        ├─ AI辅助诊断：人工智能辅助影像诊断
        ├─ 三维重建：三维可视化
        ├─ 功能成像：弥散加权、灌注成像
        ├─ 分子成像：PET分子探针
        └─ 介入影像学：影像引导下治疗
```

## 总结

医学影像学是临床医学的重要学科，通过各种成像技术为疾病诊断提供重要依据。掌握不同影像学技术的特点和应用，对于准确诊断疾病至关重要。
