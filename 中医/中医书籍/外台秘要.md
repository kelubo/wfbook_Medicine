# 外台秘要

[TOC]

## 简介

《外台秘要》是唐代**王焘**（约 670—755）穷二十余年之功编撰而成的医学总集，成书于唐天宝十一年（752 年）。全书 40 卷，分 1104 门（今本有所合并），载方约 6000 余首。

"外台"指其当时任"外台"官职（唐代地方官的一种），"秘要"则采自当时内府珍藏的方书。

## 特点

### 一、详尽标明引用来源

王焘每引一方必定注明出处——引用了 69 家、约 2800 多种文献，许多已佚著作依靠《外台秘要》得以间接保存。

| 已佚著作 | 在《外台》中的保存 |
|----------|-------------------|
| 《近效方》 | 大量引用 |
| 《必效方》 | 大量引用 |
| 《古今录验方》 | 大量引用 |
| 范汪《东阳方》 | 部分保存 |
| 僧深《师方》 | 部分保存 |

### 二、分科系统详尽

以疾病分门、每门先论后方，为后代临床著作提供了编撰范式。

### 三、全面

涵盖内、外、妇、儿、骨、五官、皮肤各科，包括急救、中毒、虫兽伤等极实用的内容。

## 学术贡献

1. **保存文献**——大量后世已亡佚的唐以前医方赖此书保存
2. 重视急性传染病（天行/疫疠）的治疗
3. 创伤外科——对骨折、金创、箭伤等处理论述详实
4. 最早记载了消渴患者尿甜（糖尿病）
5. 系统介绍了眼科的多种手术（白内障针拨术等）
