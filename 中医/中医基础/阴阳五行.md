# 阴阳五行

## 概述

阴阳五行学说是中医理论的基础，用于解释人体生理病理和指导临床治疗。

---

## 一、阴阳学说

### 1.1 阴阳的概念

阴阳是对自然界相互关联的事物或现象对立双方属性的概括。

```
阴阳属性分类
        │
        ├─ 阴：静止、寒冷、内向、下降、阴暗
        │   ├─ 季节：冬季、秋季
        │   ├─ 时间：夜晚
        │   ├─ 方位：北方、西方
        │   └─ 人体：五脏、血、津液
        │
        └─ 阳：运动、温热、外向、上升、明亮
            ├─ 季节：春季、夏季
            ├─ 时间：白天
            ├─ 方位：南方、东方
            └─ 人体：六腑、气
```

### 1.2 阴阳的特性

| 特性 | 描述 | 示例 |
|------|------|------|
| 对立制约 | 阴阳双方相互对立、相互制约 | 寒与热相互制约 |
| 互根互用 | 阴阳双方相互依存、相互为用 | 气与血相互依存 |
| 消长平衡 | 阴阳双方在一定范围内消长变化 | 四季更替 |
| 相互转化 | 阴阳在一定条件下相互转化 | 寒极生热、热极生寒 |

### 1.3 阴阳与人体

```
人体阴阳分布
        │
        ├─ 上部为阳，下部为阴
        ├─ 体表为阳，体内为阴
        ├─ 背部为阳，腹部为阴
        ├─ 六腑为阳，五脏为阴
        ├─ 气为阳，血和津液为阴
        └─ 功能为阳，物质为阴
```

### 1.4 阴阳失调

| 类型 | 表现 | 治疗原则 |
|------|------|----------|
| 阴偏盛 | 畏寒、四肢不温、腹痛 | 寒者热之 |
| 阳偏盛 | 发热、口干、烦躁 | 热者寒之 |
| 阴偏衰 | 阴虚火旺、盗汗、头晕 | 滋阴降火 |
| 阳偏衰 | 阳虚怕冷、自汗、乏力 | 温阳散寒 |

## 二、五行学说

### 2.1 五行的概念

五行是木、火、土、金、水五种物质及其运动变化。

```
五行特性
        │
        ├─ 木：生长、升发、条达
        │   ├─ 季节：春季
        │   ├─ 方位：东方
        │   └─ 脏腑：肝
        │
        ├─ 火：温热、向上、明亮
        │   ├─ 季节：夏季
        │   ├─ 方位：南方
        │   └─ 脏腑：心
        │
        ├─ 土：生化、承载、受纳
        │   ├─ 季节：长夏
        │   ├─ 方位：中央
        │   └─ 脏腑：脾
        │
        ├─ 金：清洁、收敛、沉降
        │   ├─ 季节：秋季
        │   ├─ 方位：西方
        │   └─ 脏腑：肺
        │
        └─ 水：寒凉、滋润、向下
            ├─ 季节：冬季
            ├─ 方位：北方
            └─ 脏腑：肾
```

### 2.2 五行相生

五行相生是指木、火、土、金、水之间的相互滋生、促进关系。

```
五行相生关系
木 ──→ 火 ──→ 土 ──→ 金 ──→ 水 ──→ 木
│       │       │       │       │
│       │       │       │       └── 水生木
│       │       │       └────────── 金生水
│       │       └────────────────── 土生金
│       └────────────────────────── 火生土
└────────────────────────────────── 木生火
```

### 2.3 五行相克

五行相克是指木、火、土、金、水之间的相互制约、克制关系。

```
五行相克关系
木 ──→ 土 ──→ 水 ──→ 火 ──→ 金 ──→ 木
│       │       │       │       │
│       │       │       │       └── 金克木
│       │       │       └────────── 火克金
│       │       └────────────────── 水克火
│       └────────────────────────── 土克水
└────────────────────────────────── 木克土
```

### 2.4 五行与脏腑

```
五行与脏腑对应关系
        │
        ├─ 木 → 肝、胆
        │   ├─ 肝主疏泄
        │   └─ 肝主藏血
        │
        ├─ 火 → 心、小肠
        │   ├─ 心主血脉
        │   └─ 心主神志
        │
        ├─ 土 → 脾、胃
        │   ├─ 脾主运化
        │   └─ 脾主升清
        │
        ├─ 金 → 肺、大肠
        │   ├─ 肺主气
        │   └─ 肺主肃降
        │
        └─ 水 → 肾、膀胱
            ├─ 肾主藏精
            └─ 肾主水
```

### 2.5 五行学说的应用

| 应用领域 | 具体应用 |
|----------|----------|
| 诊断 | 面色、脉象的五行归类 |
| 治疗 | 根据五行生克确定治法 |
| 预防 | 根据季节调整饮食起居 |

## 三、五行生克在治疗中的应用

### 3.1 根据相生规律确定治法

| 治法 | 适用证 | 示例 |
|------|--------|------|
| 滋水涵木 | 肾阴不足，肝阳上亢 | 六味地黄丸 |
| 益火补土 | 肾阳虚，脾阳虚 | 右归丸 |
| 培土生金 | 脾气虚，肺气虚 | 参苓白术散 |
| 金水相生 | 肺阴虚，肾阴虚 | 百合固金汤 |

### 3.2 根据相克规律确定治法

| 治法 | 适用证 | 示例 |
|------|--------|------|
| 抑木扶土 | 肝气郁结，脾胃虚弱 | 逍遥散 |
| 培土制水 | 脾虚湿盛，水肿 | 实脾饮 |
| 佐金平木 | 肝火犯肺 | 泻白散 |
| 泻南补北 | 心肾不交 | 黄连阿胶汤 |

---

## 总结

阴阳五行学说是中医理论的重要组成部分，通过阴阳的对立统一和五行的生克关系，解释人体生理病理变化，指导中医诊断和治疗。
