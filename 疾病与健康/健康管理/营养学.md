# 营养学

## 概述

营养学是研究食物与健康关系的学科，包括营养素的摄入、吸收、代谢和利用。

---

## 一、营养素分类

### 1.1 宏量营养素

```
宏量营养素
        │
        ├─ 碳水化合物：提供能量
        │   ├─ 简单碳水化合物：葡萄糖、果糖、蔗糖
        │   ├─ 复杂碳水化合物：淀粉、膳食纤维
        │   └─ 推荐摄入量：占总热量的50%-65%
        │
        ├─ 蛋白质：构建和修复组织
        │   ├─ 必需氨基酸：人体无法合成，必须从食物中获取
        │   ├─ 非必需氨基酸：人体可以合成
        │   └─ 推荐摄入量：占总热量的10%-15%
        │
        └─ 脂肪：提供能量和必需脂肪酸
            ├─ 饱和脂肪：动物脂肪，增加胆固醇
            ├─ 不饱和脂肪：植物脂肪，降低胆固醇
            ├─ 必需脂肪酸：亚油酸、亚麻酸
            └─ 推荐摄入量：占总热量的20%-30%
```

### 1.2 微量营养素

```
微量营养素
        │
        ├─ 维生素：调节生理功能
        │   ├─ 脂溶性维生素：维生素A、D、E、K
        │   └─ 水溶性维生素：维生素B族、维生素C
        │
        └─ 矿物质：维持生理功能
            ├─ 常量矿物质：钙、磷、钾、钠、氯
            └─ 微量矿物质：铁、锌、铜、碘、硒
```

### 1.3 膳食纤维

```
膳食纤维分类
        │
        ├─ 可溶性膳食纤维：溶于水，延缓消化
        │   ├─ 食物来源：燕麦、豆类、水果
        │   └─ 作用：降低胆固醇、调节血糖
        │
        └─ 不可溶性膳食纤维：不溶于水，促进肠道蠕动
            ├─ 食物来源：蔬菜、全谷物、坚果
            └─ 作用：预防便秘、促进排便
```

## 二、能量代谢

### 2.1 能量单位

```
能量单位
        │
        ├─ 千卡（kcal）：1千卡=1000卡路里
        ├─ 千焦（kJ）：1千卡=4.184千焦
        └─ 换算：1 kcal = 4.184 kJ
```

### 2.2 基础代谢率

```
基础代谢率（BMR）
        │
        ├─ 定义：人体在清醒而又极端安静的状态下，不受肌肉活动、环境温度、食物及精神紧张等影响时的能量代谢率
        ├─ 计算：男性BMR=10×体重(kg)+6.25×身高(cm)-5×年龄-161
        │   女性BMR=10×体重(kg)+6.25×身高(cm)-5×年龄+5
        └─ 影响因素：年龄、性别、身高、体重、肌肉量
```

### 2.3 每日总能量消耗

```
每日总能量消耗（TDEE）
        │
        ├─ TDEE = BMR × 活动系数
        ├─ 活动系数
        │   ├─ 久坐不动：1.2
        │   ├─ 轻度活动：1.375
        │   ├─ 中度活动：1.55
        │   ├─ 高度活动：1.725
        │   └─ 非常活跃：1.9
        └─ 应用：减肥或增肌时调整热量摄入
```

## 三、健康饮食原则

### 3.1 均衡饮食

```
均衡饮食原则
        │
        ├─ 食物多样化：摄入多种食物
        ├─ 主食粗细搭配：全谷物和精制谷物搭配
        ├─ 蛋白质来源多样：动物蛋白和植物蛋白搭配
        ├─ 多吃蔬菜和水果：每天摄入500克以上蔬菜，200-350克水果
        ├─ 适量摄入脂肪：选择健康脂肪
        └─ 少油少盐少糖：减少油、盐、糖摄入
```

### 3.2 饮食金字塔

```
饮食金字塔结构
        │
        ├─ 底层：全谷物、杂豆、薯类（主食）
        ├─ 第二层：蔬菜和水果
        ├─ 第三层：畜禽肉、鱼虾、蛋类（蛋白质）
        ├─ 第四层：奶类、豆类和坚果（蛋白质和钙）
        └─ 顶层：油、盐、糖（适量摄入）
```

### 3.3 特殊人群饮食

```
特殊人群饮食
        │
        ├─ 老年人：易消化、营养丰富、适量膳食纤维
        ├─ 孕妇：增加蛋白质、叶酸、铁、钙摄入
        ├─ 儿童：均衡营养、适量热量、避免挑食
        ├─ 糖尿病患者：控制碳水化合物摄入、规律饮食
        ├─ 高血压患者：低盐饮食、多吃蔬菜水果
        └─ 高血脂患者：低脂饮食、多吃膳食纤维
```

## 四、营养与疾病

### 4.1 营养缺乏症

```
营养缺乏症
        │
        ├─ 维生素缺乏症
        │   ├─ 维生素A缺乏：夜盲症、干眼症
        │   ├─ 维生素D缺乏：佝偻病、骨质疏松
        │   ├─ 维生素C缺乏：坏血病
        │   └─ 维生素B1缺乏：脚气病
        │
        ├─ 矿物质缺乏症
        │   ├─ 缺铁：缺铁性贫血
        │   ├─ 缺锌：生长发育迟缓
        │   ├─ 缺碘：甲状腺肿、智力低下
        │   └─ 缺钙：骨质疏松、佝偻病
        │
        └─ 蛋白质缺乏：营养不良、免疫力下降
```

### 4.2 营养与慢性疾病

```
营养与慢性疾病
        │
        ├─ 肥胖：热量摄入过多
        ├─ 糖尿病：饮食不当、缺乏运动
        ├─ 高血压：高盐饮食
        ├─ 高血脂：高脂肪、高胆固醇饮食
        └─ 心血管疾病：不健康的饮食习惯
```

## 五、饮食建议

### 5.1 每日饮食建议

```
每日饮食建议
        │
        ├─ 主食：250-400克，全谷物占一半以上
        ├─ 蔬菜：500克以上，深色蔬菜占一半以上
        ├─ 水果：200-350克，新鲜水果
        ├─ 畜禽肉：40-75克，瘦肉
        ├─ 鱼虾：40-75克，深海鱼每周2次
        ├─ 蛋类：40-50克，每天1个鸡蛋
        ├─ 奶类：300毫升，低脂或脱脂奶
        ├─ 豆类：25-50克，豆腐、豆浆
        ├─ 油：25-30克，植物油
        └─ 盐：不超过5克
```

### 5.2 饮食误区

```
常见饮食误区
        │
        ├─ 不吃主食：影响能量供应
        ├─ 只吃蔬菜：缺乏蛋白质和脂肪
        ├─ 过度节食：导致营养不良
        ├─ 吃宵夜：增加肠胃负担
        ├─ 喝含糖饮料：增加热量摄入
        └─ 盲目补充营养素：过量可能有害
```

---

## 总结

营养学是维持健康的重要学科，通过均衡饮食和合理营养摄入，可以预防营养缺乏症和慢性疾病，促进身体健康。
