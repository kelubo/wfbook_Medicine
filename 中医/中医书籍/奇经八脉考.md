# 奇经八脉考

[TOC]

## 简介

《奇经八脉考》是明代**李时珍**的脉学专著之一，成书约在 1572 年前后。全书 1 卷，专门研究奇经八脉（不同于十二正经的另一组经脉系统），是对《内经》《难经》的奇经理论的系统整理和阐发。

## 奇经八脉

| 经脉 | 简称 | 功能 |
|------|:---:|------|
| **督脉** | 督 | 总督诸阳、行于背——"阳脉之海" |
| **任脉** | 任 | 总调诸阴、行于腹——"阴脉之海" |
| **冲脉** | 冲 | 通行十二经脉——"十二经之海""血海" |
| **带脉** | 带 | 束腰如带、约束诸经 |
| 阴跷脉 | 阴跷 | 主一身左右之阴、司眼睑开阖 |
| 阳跷脉 | 阳跷 | 主一身左右之阳、司眼睑开阖 |
| 阴维脉 | 阴维 | 维系诸阴经 |
| 阳维脉 | 阳维 | 维系诸阳经 |

## 特点

- 奇经不像十二正经有表里属络关系——是独立调节系统
- 八脉本身不参与气血循环（根据传统理论），而是存储和调节十二经脉的盈余气血
- 冲任二脉与妇科关系极为密切——"冲为血海，任主胞胎"

## 李时珍的贡献

1. 系统整理了奇经八脉的循行路线和功能
2. 阐发了奇经与十二正经的功能互补关系
3. 为后世针灸学家提供了八脉交会穴理论基础
4. 是学习和理解奇经八脉最重要的文献之一
