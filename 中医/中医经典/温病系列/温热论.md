# 温热论

[TOC]

## 简介

《温热论》（又称《外感温热篇》《叶香岩外感温热篇》）是清代著名温病学家**叶天士**（叶桂，字天士，号香岩，1667—1746）的代表著作。由门人顾景文记录整理，首刊于 1746 年。

全文仅约 6000 字，但言简意赅，首次系统阐释了温病的病因（温邪上受）、传变规律（卫气营血）、诊断方法（辨舌验齿）和治则（卫气营血辨证治疗），开创了温病学派的理论基础。

> 章虚谷评价："其说至精，其法至妙，足以补仲景之未备。"

## 四大核心贡献

### 一、首创卫气营血辨证

叶天士将温病的发生发展过程划分为四个层次：

| 层次 | 病位 | 主证 | 治则 |
|------|------|------|------|
| **卫** | 肺卫皮毛 | 发热微恶风寒、脉浮数 | 辛凉解表 |
| **气** | 肺→胃→肠 | 壮热、口渴、汗出、便结 | 清气泄热 |
| **营** | 心营 | 身热夜甚、心烦不寐、舌绛 | 清营透热 |
| **血** | 血分 | 动血—出血、发斑、躁扰 | 凉血散血 |

### 二、辨舌验齿诊断法

《温热论》对**验舌**论述极细：

| 舌象 | 辨证意义 |
|------|---------|
| 白苔（薄白而干） | 卫分表邪未解，或津液已伤 |
| 黄苔（老黄/焦躁） | 气分热盛（在胃/肠） |
| 绛舌 | 热入营分 |
| 紫舌（紫而干晦） | 热入血分、瘀热互结 |

**验齿**：观察牙龈润燥、齿垢色泽，判断津液盈亏和病情深浅。如齿燥如石，胃热极盛；齿如枯骨，肾阴枯竭。

### 三、斑疹辨治

| 类别 | 特征 | 病机 |
|------|------|------|
| **斑** | 点大成片、平铺皮面、压之不退色 | 热入血分、迫血妄行 |
| **疹** | 小如粟粒、高出皮肤、抚之碍手 | 热郁肺卫、内窜营分 |

### 四、妇人温病论治

特别提出妇人经期、产后感受温邪的特殊处理——重视血分，以调阴阳为先。认为"产后当如崩漏"不过是一偏之见，产后仍当以病情为主，不必拘泥于补虚。

## 核心论述

### "温邪上受"

"温邪上受，首先犯肺，逆传心包。"

- **温邪**：非普通寒邪，而是具有温热性质的致病邪气
- **上受**：从口鼻而入（有别于"寒邪从皮毛而入"）
- **首先犯肺**：肺主皮毛开窍于鼻，首当其冲
- **逆传心包**：不按卫→气→营→血的顺传规律，病邪直接由卫分传入营分/心包（病情急剧加重）

### 与伤寒的区别

| 类别 | 伤寒 | 温病 |
|------|------|------|
| 感邪途径 | 皮毛而入 | 口鼻而入 |
| 初起部位 | 太阳（膀胱经） | 肺 |
| 初起症状 | 恶寒重、发热轻 | 发热重、微恶风寒 |
| 舌象初始 | 苔薄白 | 苔薄白而干或舌边尖红 |
| 治法 | 辛温解表 | 辛凉解表 |

## 脉诊特色

叶天士对温病脉象有精辟论述：

| 脉象 | 辨证 |
|------|------|
| 浮数 | 邪在卫分 |
| 洪大 | 气分热盛 |
| 数大 | 入营前兆 |
| 细数 | 营分/血分，阴伤 |

## 学术评价

1. **理论突破**：将《内经》的卫气营血防御分布说发展为温病辨证纲领
2. **诊断精微**：辨舌验齿法至今为临床所用
3. **立法恰当**："在卫汗之，到气清气，入营透热转气，入血凉血散血"——成为温病治疗的十六字方针
4. **影响深远**：吴鞠通著《温病条辨》、王孟英著《温热经纬》均基于此
