# 性医学基础

## 概述

性医学是研究人类性生理、性功能、性心理及其相关疾病的诊断、治疗和预防的交叉学科。涵盖泌尿外科、妇科、内分泌科、精神心理科等多个领域。

> 性医学不仅仅是"治病"，更关注生活质量和身心健康。

## 一、两性生殖解剖

### 1.1 男性生殖系统

```
男性生殖系统
        │
        ├─ 外生殖器
        │   ├─ 阴茎：排尿和性交器官
        │   │   ├─ 阴茎海绵体（2 条）：勃起组织
        │   │   └─ 尿道海绵体（1 条）：包绕尿道
        │   └─ 阴囊：容纳和保护睾丸
        │
        ├─ 内生殖器
        │   ├─ 睾丸：产生精子 + 分泌雄激素（睾酮）
        │   ├─ 附睾：精子储存和成熟
        │   ├─ 输精管：输送精子
        │   ├─ 射精管：将精液排入尿道
        │   ├─ 精囊：分泌精囊液（占精液 60%）
        │   ├─ 前列腺：分泌前列腺液（占精液 30%）
        │   └─ 尿道球腺：分泌润滑液
        │
        └─ 精液组成
            ├─ 精子：由睾丸产生，占精液体积 < 5%
            ├─ 精囊液：碱性，含果糖（供能）
            └─ 前列腺液：含酶和锌离子
```

### 1.2 女性生殖系统

```
女性生殖系统
        │
        ├─ 外生殖器（外阴）
        │   ├─ 大阴唇
        │   ├─ 小阴唇
        │   ├─ 阴蒂：富含神经末梢，唯一以快感为目的的器官
        │   ├─ 阴道前庭
        │   └─ 前庭大腺：分泌润滑液
        │
        └─ 内生殖器
            ├─ 阴道：性交器官、分娩产道
            ├─ 子宫：孕育胎儿
            ├─ 输卵管：受精场所
            └─ 卵巢：排卵 + 分泌雌激素/孕激素
```

### 1.3 性腺轴

```
下丘脑-垂体-性腺轴
        │
        ├─ 下丘脑 → GnRH（促性腺激素释放激素）
        │   └─ 脉冲式分泌，调控垂体
        │
        ├─ 垂体前叶
        │   ├─ FSH（卵泡刺激素）：促进精子/卵泡生成
        │   └─ LH（黄体生成素）：促进睾酮/雌激素分泌
        │
        └─ 性腺
            ├─ 睾丸：睾酮 → 生精 + 维持第二性征
            └─ 卵巢：雌二醇 + 孕酮 → 月经周期
```

## 二、性激素及其功能

### 2.1 雄激素

| 激素 | 来源 | 功能 |
|------|------|------|
| 睾酮 (Testosterone) | 睾丸间质细胞（95%）+ 肾上腺 | 精子发生、维持性欲、肌肉量、骨密度 |
| 双氢睾酮 (DHT) | 睾酮经 5α-还原酶转化 | 前列腺发育、男性脱发（雄秃） |

### 2.2 雌激素与孕激素

| 激素 | 来源 | 功能 |
|------|------|------|
| 雌二醇 (E2) | 卵巢颗粒细胞 | 子宫内膜增生、第二性征、骨骼健康 |
| 孕酮 (P4) | 黄体、胎盘 | 维持妊娠、子宫内膜分泌期改变 |

### 2.3 激素随年龄变化

```
睾酮变化（男性）
        │
        ├─ 青春期（~12 岁）：开始升高
        ├─ 20~30 岁：峰值
        └─ 40 岁后逐年下降 ~1%/年 → 迟发性性腺功能减退 (LOH)

雌激素变化（女性）
        │
        ├─ 青春期：开始升高
        ├─ 育龄期：周期性波动
        ├─ 围绝经期（45~55 岁）：雌激素急剧下降
        └─ 绝经后：低水平维持
```

## 三、性反应周期

Masters & Johnson (1966) 提出的四期模型：

```
性反应周期
        │
        ├─ 兴奋期
        │   ├─ 男性：阴茎勃起（副交感神经 → 海绵体充血）
        │   └─ 女性：阴道润滑、阴蒂充血、乳房增大
        │
        ├─ 平台期
        │   ├─ 男性：龟头充血、睾丸上提
        │   └─ 女性：阴道外 1/3 充血（高潮平台）、阴蒂回缩
        │
        ├─ 高潮期
        │   ├─ 男性：射精（交感神经控制）
        │   │   ├─ 泄精期：附睾/输精管/精囊/前列腺收缩 → 精液入尿道
        │   │   └─ 射精期：尿道括约肌节律性收缩
        │   └─ 女性：盆底肌节律性收缩（0.8 秒间隔）
        │
        └─ 消退期
            ├─ 男性：阴茎疲软 → 不应期（随年龄延长）
            └─ 女性：消退缓慢，可再次高潮（无不应期）
```

## 四、男性性功能障碍

### 4.1 勃起功能障碍 (ED)

| 项目 | 内容 |
|------|------|
| 定义 | 持续 ≥ 3 个月不能获得或维持足以完成性交的勃起 |
| 分类 | 心理性 / 器质性 / 混合性 |
| 危险因素 | 年龄、糖尿病、高血压、心血管病、吸烟、肥胖 |

```
ED 的病因
        │
        ├─ 心理性（10-20%）
        │   ├─ 表现焦虑
        │   ├─ 抑郁、焦虑
        │   └─ 夫妻关系问题
        │
        ├─ 器质性（80-90%）
        │   ├─ 血管性（最常见）：动脉供血不足、静脉漏
        │   ├─ 神经性：脊髓损伤、糖尿病神经病变、盆腔手术后
        │   ├─ 内分泌性：低睾酮、高泌乳素血症、甲减
        │   └─ 药物性：降压药（利尿剂、β 阻滞剂）、抗抑郁药 (SSRIs)
        │
        └─ 混合性：器质性疾病 + 心理负担
```

**治疗阶梯**：

| 阶梯 | 治疗 | 说明 |
|:---:|------|------|
| 1 | 生活方式调整 | 戒烟、运动、减重、控制三高 |
| 2 | 口服 PDE5 抑制剂 | 西地那非（万艾可）/ 他达拉非 / 伐地那非 |
| 3 | 负压吸引装置 | 物理方法 |
| 4 | 海绵体注射 | 前列地尔 |
| 5 | 假体植入 | 手术最后手段 |

> PDE5 抑制剂禁忌：**正在服用硝酸酯类药物**（严重低血压风险）。

### 4.2 早泄 (PE)

| 项目 | 内容 |
|------|------|
| 定义 | 总是在插入后 < 1 分钟内射精，无法控制 |
| 分类 | 终身性（原发性）/ 获得性（继发性） |
| 治疗 | SSRIs（达泊西汀，按需服用）、局部麻醉喷雾、行为疗法 |

### 4.3 迟发性性腺功能减退 (LOH)

| 项目 | 内容 |
|------|------|
| 本质 | 年龄相关的睾酮下降 + 临床症状 |
| 症状 | 性欲减退、ED、乏力、情绪低落、肌肉减少 |
| 诊断 | 晨间总睾酮 < 300 ng/dL（需重复测定） |
| 治疗 | 睾酮替代治疗——需排除前列腺癌后慎重使用 |

## 五、女性性功能障碍

| 类型 | 定义 | 常见原因 |
|------|------|----------|
| 性欲障碍 | 持续性性兴趣/性幻想缺乏 | 心理因素、关系问题、激素变化、药物 |
| 性唤起障碍 | 不能维持润滑/兴奋 | 绝经后雌激素缺乏、血管因素 |
| 性高潮障碍 | 高潮延迟/缺失 | 心理因素、药物 (SSRIs)、缺乏有效刺激 |
| 性交疼痛 | 性交时反复疼痛 | 阴道干涩、子宫内膜异位症、盆底痉挛 |

> 性交疼痛需排查器质性病因（子宫内膜异位症、盆腔炎性疾病、间质性膀胱炎）。

## 六、不孕不育

### 6.1 定义

| 术语 | 定义 |
|------|------|
| 不孕 (infertility) | 规律无保护性生活 ≥ 12 个月未孕 |
| 不育 | 能怀孕但反复流产/死产 |

### 6.2 病因构成

```
不孕原因分布
        │
        ├─ 女性因素：~40%
        ├─ 男性因素：~40%
        ├─ 双方因素：~10%
        └─ 不明原因：~10%
```

### 6.3 基本检查

| 性别 | 检查项目 |
|------|---------|
| 男性 | 精液常规（数量、活力、形态） |
| 女性 | 排卵监测、输卵管通畅性、盆腔超声 |

## 七、性传播疾病 (STDs)

### 7.1 常见 STDs

| 疾病 | 病原体 | 特征 | 治疗 |
|------|--------|------|------|
| 淋病 | 淋病奈瑟菌 | 尿道/宫颈脓性分泌物 | 头孢曲松 |
| 衣原体感染 | 沙眼衣原体 | 常无症状，黏液脓性分泌物 | 阿奇霉素 / 多西环素 |
| 梅毒 | 梅毒螺旋体 | 一期硬下疳 → 二期皮疹 → 三期多系统 | 青霉素 |
| 尖锐湿疣 | HPV 6、11 型 | 菜花样赘生物 | 冷冻/激光/咪喹莫特 |
| 生殖器疱疹 | HSV-1、2 | 簇状水疱、反复发作 | 阿昔洛韦 |
| 艾滋 (HIV) | 人类免疫缺陷病毒 | CD4+ T 细胞耗竭 | 抗逆转录病毒治疗 (ART) |

### 7.2 预防

```
STD 预防策略
        │
        ├─ 安全套使用：有效屏障
        ├─ HPV 疫苗：预防宫颈癌和尖锐湿疣
        ├─ 定期筛查：有高危行为者
        ├─ 伴侣同治：避免乒乓球效应
        └─ 暴露前预防 (PrEP)：HIV 高风险人群
```

## 八、避孕与计划生育

| 方法 | 避孕有效率 | 特点 |
|------|:---:|------|
| 安全套（男用） | ~98%（正确使用） | 唯一同时预防 STD 的方法 |
| 短效口服避孕药 | > 99%（完美使用） | 调节月经周期 |
| 宫内节育器 (IUD) | > 99% | 长效可逆 |
| 皮下埋植 | > 99% | 有效期 3~5 年 |
| 紧急避孕药 | ~85% | 72 小时内服用 |
| 体外射精、安全期 | 低效 | **不推荐**作为常规避孕手段 |

## 九、性心理与性教育

```
健康性心理要素
        │
        ├─ 性认同：对自己性别和性取向的接纳
        ├─ 性知识：正确的生理和避孕知识
        ├─ 性沟通：伴侣间开放的性需求表达
        └─ 性价值观：尊重、自愿、安全、负责任
```

### 常见心理问题

| 问题 | 表现 | 处理 |
|------|------|------|
| 性表现焦虑 | 过度关注"表现"导致功能障碍 | 认知行为疗法 + 伴侣配合 |
| 性欲不一致 | 伴侣间性需求差异 | 沟通、协商频率、寻求专业帮助 |
| 性创伤后应激 | 性侵/虐待后对性的恐惧 | 心理治疗、伴侣理解支持 |

---

## 总结

性医学是多学科交叉领域，涉及生理、心理、社会三方面。健康和谐的性生活是整体健康的重要组成。遇到性相关问题应放下羞耻感，积极寻求专业帮助——大多数性功能障碍是可以有效治疗的。
