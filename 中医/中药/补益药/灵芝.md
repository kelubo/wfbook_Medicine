# 灵芝

[TOC]

## 概述

灵芝为多孔菌科真菌赤芝 *Ganoderma lucidum* (Leyss. ex Fr.) Karst. 或紫芝 *G. sinense* Zhao, Xu et Zhang 的干燥子实体。全年采收，除去杂质，阴干或晒干。野生灵芝现已稀少，市售多为人工栽培品。

> 《神农本草经》将灵芝列为上品，分青、赤、黄、白、黑、紫六芝，以赤芝和紫芝收录于《中国药典》。

## 性味归经

- **性味**：甘、平
- **归经**：心、肺、肝、肾

## 功效

| 功效 | 应用 |
|------|------|
| **补气安神** | 心气虚或心脾两虚所致的心悸、失眠、健忘、神疲乏力 |
| **止咳平喘** | 肺气虚所致的咳嗽、气喘 |
| **补益五脏** | 虚劳短气、食欲不振 |

## 使用注意

| 注意 | 说明 |
|------|------|
| 用量 | 煎服 6 ~ 12 g |
| 实证不宜 | 外感初起、实热证不可用（补则留邪） |

## 现代研究

灵芝的主要活性成分：

| 成分 | 作用 |
|------|------|
| 灵芝多糖 | 免疫调节（增强巨噬细胞、NK 细胞活性）、抗肿瘤辅助 |
| 灵芝三萜 (Ganoderic acids) | 保护肝脏、抗炎、抗过敏 |
| 灵芝腺苷 | 抑制血小板聚集、改善循环 |

主要药理作用：① 增强免疫功能；② 镇静安神（改善睡眠）；③ 保肝、降低转氨酶；④ 抗氧化、抗衰老；⑤ 辅助抗肿瘤（通过免疫调节而非直接杀灭）；⑥ 降血糖、降血脂。

> 注意：灵芝的"抗癌"功效是作为**辅助免疫调节剂**，并非替代性抗癌药。市场上有些夸大宣传需理性看待。

## 产品形式

| 形式 | 特点 |
|------|------|
| 子实体切片 | 煎汤服用（传统方式） |
| 灵芝孢子粉 | 孢子破壁后更利于吸收（含孢子油） |
| 灵芝提取物 | 标准化多糖/三萜含量 |
