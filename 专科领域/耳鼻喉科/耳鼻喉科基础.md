# 耳鼻喉科基础

## 概述

耳鼻喉科是研究耳、鼻、咽喉疾病的诊断、治疗和预防的学科。

---

## 一、耳部疾病

### 1.1 耳的结构

```
耳的结构
        │
        ├─ 外耳：耳廓、外耳道
        ├─ 中耳：鼓膜、听小骨、鼓室
        └─ 内耳：耳蜗、前庭、半规管
```

### 1.2 外耳道炎

```
外耳道炎特点
        │
        ├─ 病因：细菌或真菌感染
        │   ├─ 细菌性外耳道炎：金黄色葡萄球菌感染
        │   └─ 真菌性外耳道炎：曲霉菌感染
        │
        ├─ 症状：耳痛、耳痒、耳分泌物、听力下降
        ├─ 体征：外耳道红肿、分泌物增多
        └─ 治疗：清洁外耳道、抗感染药物
```

### 1.3 中耳炎

```
中耳炎分类
        │
        ├─ 急性中耳炎：细菌感染，鼓膜充血
        │   ├─ 症状：耳痛、发热、听力下降
        │   ├─ 体征：鼓膜充血、膨隆
        │   └─ 治疗：抗生素、止痛药
        │
        ├─ 慢性中耳炎：反复发作的中耳炎
        │   ├─ 症状：长期耳流脓、听力下降
        │   ├─ 体征：鼓膜穿孔、中耳肉芽
        │   └─ 治疗：药物治疗、手术治疗
        │
        └─ 分泌性中耳炎：中耳积液
            ├─ 症状：耳闷、听力下降
            ├─ 体征：鼓膜内陷、积液
            └─ 治疗：药物治疗、鼓膜穿刺、鼓膜置管
```

### 1.4 听力损失

```
听力损失分类
        │
        ├─ 传导性听力损失：外耳或中耳疾病
        │   ├─ 病因：外耳道堵塞、鼓膜穿孔、中耳炎
        │   └─ 特点：气导听力下降，骨导正常
        │
        ├─ 感音神经性听力损失：内耳或听神经疾病
        │   ├─ 病因：老年性耳聋、噪声性耳聋、药物性耳聋
        │   └─ 特点：气导和骨导听力均下降
        │
        └─ 混合性听力损失：传导性和感音神经性混合
```

### 1.5 耳鸣

```
耳鸣分类
        │
        ├─ 主观性耳鸣：只有患者能听到
        │   ├─ 病因：听力损失、噪声暴露、心理因素
        │   └─ 治疗：病因治疗、声音疗法、心理治疗
        │
        └─ 客观性耳鸣：医生也能听到
            ├─ 病因：血管异常、肌肉痉挛
            └─ 治疗：病因治疗
```

## 二、鼻部疾病

### 2.1 鼻的结构

```
鼻的结构
        │
        ├─ 外鼻：鼻梁、鼻翼、鼻尖
        ├─ 鼻腔：鼻中隔、鼻甲、鼻窦开口
        └─ 鼻窦：上颌窦、筛窦、额窦、蝶窦
```

### 2.2 鼻炎

```
鼻炎分类
        │
        ├─ 过敏性鼻炎：过敏反应
        │   ├─ 症状：打喷嚏、流清涕、鼻塞、鼻痒
        │   ├─ 体征：鼻黏膜苍白水肿
        │   └─ 治疗：抗过敏药物、鼻用糖皮质激素、避免过敏原
        │
        ├─ 非过敏性鼻炎：非过敏原因引起
        │   ├─ 血管运动性鼻炎：温度变化或刺激引起
        │   ├─ 感染性鼻炎：病毒或细菌感染
        │   └─ 药物性鼻炎：滥用减充血剂引起
        │
        └─ 萎缩性鼻炎：鼻黏膜萎缩
            ├─ 症状：鼻塞、嗅觉减退、鼻腔干燥
            └─ 治疗：鼻腔冲洗、润滑鼻腔
```

### 2.3 鼻窦炎

```
鼻窦炎分类
        │
        ├─ 急性鼻窦炎：急性感染
        │   ├─ 症状：鼻塞、流脓涕、头痛、面部疼痛
        │   ├─ 体征：鼻黏膜充血、脓性分泌物
        │   └─ 治疗：抗生素、鼻用糖皮质激素、鼻腔冲洗
        │
        └─ 慢性鼻窦炎：反复发作超过3个月
            ├─ 症状：长期鼻塞、流脓涕、嗅觉减退
            ├─ 体征：鼻黏膜慢性充血、息肉样变
            └─ 治疗：药物治疗、手术治疗
```

### 2.4 鼻息肉

```
鼻息肉特点
        │
        ├─ 病因：慢性炎症或过敏反应
        ├─ 症状：鼻塞、嗅觉减退、头痛
        ├─ 体征：鼻腔内灰白色息肉
        ├─ 并发症：鼻窦炎、中耳炎
        └─ 治疗：鼻用糖皮质激素、手术切除
```

## 三、咽喉疾病

### 3.1 咽喉结构

```
咽喉结构
        │
        ├─ 咽部：鼻咽、口咽、喉咽
        ├─ 喉部：声带、喉室、会厌
        └─ 扁桃体：腭扁桃体、咽扁桃体
```

### 3.2 咽炎

```
咽炎分类
        │
        ├─ 急性咽炎：急性感染
        │   ├─ 症状：咽痛、咽干、发热
        │   ├─ 体征：咽黏膜充血、扁桃体肿大
        │   └─ 治疗：抗生素、清热解毒药物
        │
        └─ 慢性咽炎：长期炎症
            ├─ 症状：咽干、咽痒、异物感
            ├─ 体征：咽黏膜慢性充血、淋巴滤泡增生
            └─ 治疗：含漱液、含片、避免刺激物
```

### 3.3 扁桃体炎

```
扁桃体炎分类
        │
        ├─ 急性扁桃体炎：急性感染
        │   ├─ 症状：剧烈咽痛、发热、吞咽困难
        │   ├─ 体征：扁桃体红肿、脓性分泌物
        │   └─ 治疗：抗生素、清热解毒药物
        │
        └─ 慢性扁桃体炎：反复发作的扁桃体炎
            ├─ 症状：反复咽痛、扁桃体肥大
            ├─ 并发症：扁桃体周围脓肿、风湿热
            └─ 治疗：药物治疗、扁桃体切除术
```

### 3.4 喉炎

```
喉炎分类
        │
        ├─ 急性喉炎：急性感染
        │   ├─ 症状：声音嘶哑、咽痛、咳嗽
        │   ├─ 体征：声带充血水肿
        │   └─ 治疗：声带休息、抗生素、糖皮质激素
        │
        └─ 慢性喉炎：长期用声过度或刺激
            ├─ 症状：长期声音嘶哑、喉部不适
            ├─ 体征：声带慢性充血、结节或息肉
            └─ 治疗：声带休息、药物治疗、手术治疗
```

### 3.5 声带息肉

```
声带息肉特点
        │
        ├─ 病因：长期用声过度或刺激
        ├─ 症状：声音嘶哑、发音疲劳
        ├─ 体征：声带边缘息肉样隆起
        └─ 治疗：声带休息、手术切除
```

## 四、耳鼻喉科检查

```
耳鼻喉科检查方法
        │
        ├─ 耳部检查：耳内镜、听力测试、前庭功能检查
        ├─ 鼻部检查：前鼻镜、鼻内镜、鼻窦CT
        ├─ 咽喉检查：喉镜、间接喉镜、纤维喉镜
        └─ 影像学检查：CT、MRI
```

---

## 五、耳鼻喉科手术

```
常见耳鼻喉科手术
        │
        ├─ 耳部手术：鼓膜修补术、人工耳蜗植入术
        ├─ 鼻部手术：鼻中隔矫正术、鼻窦手术、鼻息肉切除术
        ├─ 咽喉手术：扁桃体切除术、腺样体切除术、声带息肉切除术
        └─ 头颈手术：甲状腺手术、腮腺手术
```

---

## 总结

耳鼻喉科涵盖耳、鼻、咽喉多种疾病，通过准确诊断和合理治疗，可以有效缓解症状和恢复功能。良好的生活习惯和定期检查对于预防耳鼻喉疾病非常重要。
