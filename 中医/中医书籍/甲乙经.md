# 甲乙经

[TOC]

## 简介

《甲乙经》全名《针灸甲乙经》或《黄帝三部针灸甲乙经》，是西晋**皇甫谧**（字士安，215—282）编著的现存最早的针灸学专著，成书约在公元 256—282 年。全书 12 卷、128 篇。

皇甫谧将《素问》《灵枢》《明堂孔穴针灸治要》三部著作"使事类相从，删其浮辞，除其重复"，择其精华编为此书。

> 此书奠定了针灸学体系的基础，被称为"针灸之祖"，唐代被列为太医署的教材。

## 内容结构

| 卷次 | 内容 |
|:---:|------|
| 卷一 | 脏腑气血津液理论 |
| 卷二 | 经络——十二经脉的起止、循行、病候 |
| 卷三 | **腧穴**——头面躯干四肢 349 个穴位定位和主治（核心） |
| 卷四 | 诊法——望闻问切 |
| 卷五 | 针道——针具、手法、禁忌 |
| 卷六 | 病机——十二经是动所生病的阐释 |
| 卷七 ~ 十二 | 临床——各科疾病的针灸治疗 |

## 核心贡献

1. **腧穴系统化**——349 穴（正中单穴 49、双侧双穴 300），统一了穴位定位、归属经脉和主治
2. **线条状经脉**——将《灵枢》中散在的经脉描述整合为连续的"线状"循行路线
3. **穴-经-病**三位一体的模式——哪个穴、归哪条经、治什么病
4. 提出了针灸的禁忌和注意事项（禁针、禁灸穴、误刺后果等）

## 版本流传

唐代原书 13 卷，宋代校订后改为 12 卷。明清重要版本有吴勉学刻本等，日本亦有古抄本传世。

## 地位

与《灵枢》《针灸大成》并称针灸学三大基础经典。
