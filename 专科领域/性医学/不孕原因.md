# 不孕原因

## 男性因素

1.精液质量低下  
2.精子输出通道梗阻  
3.精子不能正常排入女性生殖道内  
4.附属性腺异常  
5.精索静脉曲张，内分泌异常，免疫遗传因素

### 详细分类

| 类别 | 具体原因 | 检查方法 |
|------|----------|----------|
| 精子生成障碍 | 无精症、少弱畸精症 | 精液常规分析 |
| 精索静脉曲张 | 睾丸温度升高 → 生精障碍 | 阴囊超声 |
| 内分泌异常 | 低促性腺激素性性腺功能减退、高泌乳素血症 | 性激素六项 |
| 输出通道梗阻 | 输精管缺如/梗阻、附睾梗阻 | 精浆生化、输精管造影 |
| 射精障碍 | 逆行射精、不射精 | 射精后尿液检查 |
| 免疫因素 | 抗精子抗体 | 血清/精浆抗体检测 |
| 遗传因素 | Y 染色体微缺失 (AZF)、克氏综合征 (47,XXY) | 染色体核型、Y 微缺失检测 |
| 感染因素 | 前列腺炎、附睾炎 | 精液培养 |

## 女性因素

1.生殖系统器官先天性发育异常  
2.内分泌功能障碍，导致女性排卵障碍  
3.生殖系统感染  
4.免疫功能异常

### 详细分类

| 类别 | 具体原因 | 检查方法 |
|------|----------|----------|
| 排卵障碍 | 多囊卵巢综合征 (PCOS)、卵巢早衰、高泌乳素血症、甲减 | 基础体温 + 性激素六项 + 超声监测卵泡 |
| 输卵管因素 | 输卵管阻塞/粘连（盆腔炎、子宫内膜异位症后遗症） | 子宫输卵管造影 (HSG) |
| 子宫因素 | 子宫肌瘤、宫腔粘连、子宫纵隔 | 宫腔镜 |
| 宫颈因素 | 宫颈黏液异常、抗精子抗体 | 性交后试验 |
| 子宫内膜异位症 | 异位内膜导致盆腔粘连、炎症环境 | 腹腔镜 |
| 免疫因素 | 抗磷脂抗体、抗精子抗体 | 血清学检查 |
| 不明原因 | 各项检查均正常 | 排除性诊断 |

## 双方共同因素

| 因素 | 说明 |
|------|------|
| 性生活频率不当 | 排卵期同房时机掌握不当 |
| 年龄 | 女性 > 35 岁、男性 > 40 岁生育力明显下降 |
| 生活方式 | 吸烟、酗酒、肥胖、环境毒素暴露 |
| 精神心理 | 焦虑、紧张 → 影响排卵和性功能 |

## 辅助生殖技术 (ART)

| 技术 | 适用情况 |
|------|---------|
| 诱导排卵 + 指导同房 | 排卵障碍 |
| 人工授精 (IUI) | 轻度男性因素、宫颈因素 |
| 体外受精-胚胎移植 (IVF-ET) | 输卵管阻塞、中重度男性因素、子宫内膜异位症 |
| 卵胞浆内单精子注射 (ICSI) | 严重男性因素（重度少弱畸精症） |
| 胚胎植入前遗传学检测 (PGT) | 遗传病携带者、反复流产、高龄
