# 茵芋

[TOC]

## 概述

茵芋为芸香科植物茵芋 *Skimmia reevesiana* Fort. 的干燥全株或根。主产于长江以南各省（云南、贵州、四川、湖北、广东、广西等）。

> 茵芋有毒，临床使用需严格遵循炮制和配伍规范。目前《中国药典》未单独收载。

## 性味归经

- **性味**：辛、苦、温、有毒
- **归经**：肝、肾

## 功效

| 功效 | 应用 |
|------|------|
| **祛风除湿** | 风湿痹痛、关节不利 |
| **理气止痛** | 脘腹冷痛 |

## 使用注意

| 注意 | 说明 |
|------|------|
| 有毒 | 需炮制后用（多以酒浸或醋制减毒） |
| 用量 | 1 ~ 3 g 煎服（外用适量） |
| 禁忌 | 体虚、孕妇忌用 |

## 与茵陈的区别

| | 茵芋 | 茵陈 |
|---|---|---|
| 科属 | 芸香科 | 菊科 |
| 性味 | 辛、苦、温、有毒 | 苦辛、微寒 |
| 功效 | 祛风除湿 | 清利湿热、退黄疸 |
| 常用性 | 罕见、临床已极少使用 | 极常用（黄疸第一要药） |

> 茵芋在现代中医药临床中已非常罕见，几乎完全被更为安全的祛风湿药（如独活、秦艽、威灵仙）替代。研究信息不足，其毒性机制不明确，不推荐自行使用。
