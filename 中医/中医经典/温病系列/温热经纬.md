# 温热经纬

[TOC]

## 简介

《温热经纬》是清代温病学家**王孟英**（王士雄，字孟英，号潜斋，1808—1868）编著，成书于咸丰二年（1852 年）。全书 5 卷，系统汇编了《内经》《伤寒论》中与温热病相关的条文，以及叶天士、薛生白、陈平伯、余师愚等温病名家的论述，并加以按语阐发，是温病学集大成的著作。

- "经纬"二字取义：以《内经》《伤寒论》为"经"，以后世温病学家著作为"纬"，经纬交织成温热病的完整体系。

## 核心学术观点

### 一、新感与伏气

王孟英继承并发展了"新感温病"与"伏气温病"的区分：

| | 新感温病 | 伏气温病 |
|---|---|---|
| 发病 | 感而即发 | 邪伏于内、逾时而发 |
| 初起 | 邪在表/在上焦 | 病发于里、以里证为主 |
| 传变 | 由表入里 | 自里出表或内陷 |
| 治法 | 辛凉解表 | 清里透热 |

### 二、暑邪论

王孟英精于暑病的辨证，以为：
- 暑为纯阳之邪，伤人最速
- 暑必兼湿（但也有不兼湿者）
- 治暑当以清暑涤热为先，不可过用温燥

> 其治暑之名方**清暑益气汤**（王氏自制与东垣不同）：西洋参、石斛、麦冬、黄连、竹叶、荷梗、知母、甘草、粳米、西瓜翠衣——清暑热而益气阴。

### 三、养阴保津

王孟英继承了温病学派"存津液为第一要义"的思想，治疗中处处顾护阴液：

| 津伤程度 | 表现 | 用药 |
|----------|------|------|
| 轻度 | 口干 | 芦根、天花粉（轻清甘寒） |
| 中度 | 舌干齿燥 | 麦冬、沙参、石斛 |
| 重度 | 舌光绛无苔 | 生地、玄参、阿胶（咸寒救阴） |

## 代表性方剂（卷五方论）

王孟英在方论中对 113 首方逐一评注，指出适应指征和注意事项。代表性方剂包括：

| 方剂 | 出处 | 功效 |
|------|------|------|
| 白虎汤类 | 《伤寒论》 | 清气分大热 |
| 清营汤 | 《温病条辨》 | 清营透热 |
| 犀角地黄汤 | 《千金要方》 | 凉血散血 |
| 清暑益气汤 | 王氏自制 | 清暑益气养阴 |
| 甘露消毒丹 | 叶氏方 | 利湿化浊清热解毒 |
| 神犀丹 | 王氏方 | 清热解毒凉血开窍 |

## 学术地位

1. 集温病学之大成，网罗各派
2. 追本溯源至《内经》《伤寒论》，为温病理论提供经典依据
3. "以经典为经、以诸家为纬"的编写体例为后世所效仿
4. 对暑病、伏气的鉴别有独到见解
5. 与叶天士《温热论》、吴鞠通《温病条辨》并称温病学三大经典
