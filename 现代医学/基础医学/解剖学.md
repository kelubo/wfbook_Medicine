# 解剖学

## 概述

解剖学是研究人体形态结构的科学，是医学的基础学科。

---

## 一、人体基本结构

### 1.1 细胞

细胞是人体结构和功能的基本单位。

```
细胞结构
        │
        ├─ 细胞膜：细胞的边界
        │   ├─ 脂质双分子层
        │   ├─ 蛋白质
        │   └─ 糖类
        │
        ├─ 细胞质：细胞内的液体环境
        │   ├─ 细胞器
        │   │   ├─ 线粒体：能量工厂
        │   │   ├─ 核糖体：蛋白质合成
        │   │   ├─ 内质网：物质运输
        │   │   └─ 高尔基体：加工分泌
        │   └─ 细胞骨架：维持形态
        │
        └─ 细胞核：细胞的控制中心
            ├─ 核膜
            ├─ 核仁
            └─ 染色体
```

### 1.2 组织

组织是由形态相似、功能相关的细胞和细胞间质组成的结构。

| 组织类型 | 结构特点 | 功能 | 分布 |
|----------|----------|------|------|
| 上皮组织 | 细胞紧密排列 | 保护、分泌、吸收 | 体表、体内腔面 |
| 结缔组织 | 细胞分散，间质丰富 | 支持、连接、营养 | 全身各处 |
| 肌肉组织 | 细胞细长，能收缩 | 运动 | 骨骼、内脏、心脏 |
| 神经组织 | 细胞有突起 | 传导神经冲动 | 神经系统 |

### 1.3 器官

器官是由多种组织构成的具有特定功能的结构。

```
主要器官
        │
        ├─ 循环系统：心脏、血管
        ├─ 呼吸系统：肺、气管
        ├─ 消化系统：胃、肠、肝、胰
        ├─ 泌尿系统：肾、膀胱
        ├─ 生殖系统：睾丸、卵巢
        ├─ 神经系统：大脑、脊髓
        ├─ 内分泌系统：甲状腺、垂体
        └─ 运动系统：骨骼、肌肉
```

## 二、运动系统

### 2.1 骨骼系统

骨骼系统由骨和关节组成，具有支持、保护、运动等功能。

```
骨骼分类
        │
        ├─ 颅骨：保护大脑
        ├─ 脊柱：支撑身体
        ├─ 胸廓：保护心肺
        ├─ 四肢骨：运动功能
        └─ 骨盆：保护盆腔器官
```

### 2.2 肌肉系统

肌肉系统由骨骼肌、平滑肌和心肌组成。

| 肌肉类型 | 结构特点 | 功能 | 分布 |
|----------|----------|------|------|
| 骨骼肌 | 横纹明显，受意识控制 | 躯体运动 | 附着于骨骼 |
| 平滑肌 | 无横纹，不受意识控制 | 内脏运动 | 内脏器官 |
| 心肌 | 横纹，不受意识控制 | 心脏跳动 | 心脏 |

---

## 三、消化系统

### 3.1 消化道

消化道是食物消化和吸收的通道。

```
消化道结构
口腔 → 咽 → 食管 → 胃 → 小肠 → 大肠 → 肛门
       │       │       │       │       │
       │       │       │       │       └── 吸收水分
       │       │       │       └── 主要吸收部位
       │       │       └── 初步消化
       │       └── 输送食物
       └── 咀嚼食物
```

### 3.2 消化腺

消化腺分泌消化液，帮助消化食物。

| 消化腺 | 分泌物质 | 功能 |
|--------|----------|------|
| 唾液腺 | 唾液 | 消化淀粉 |
| 胃腺 | 胃液 | 消化蛋白质 |
| 肝脏 | 胆汁 | 乳化脂肪 |
| 胰腺 | 胰液 | 消化糖类、蛋白质、脂肪 |
| 肠腺 | 肠液 | 消化糖类、蛋白质、脂肪 |

## 四、呼吸系统

### 4.1 呼吸道

呼吸道是气体进出的通道。

```
呼吸道结构
鼻腔 → 咽 → 喉 → 气管 → 支气管 → 细支气管
       │       │       │           │
       │       │       │           └── 气体交换部位
       │       │       └── 气体通道
       │       └── 发声器官
       └── 过滤空气
```

### 4.2 肺

肺是气体交换的场所。

```
肺的结构
        │
        ├─ 肺泡：气体交换的基本单位
        ├─ 肺泡壁：薄，便于气体扩散
        ├─ 毛细血管：与肺泡进行气体交换
        └─ 胸膜：保护肺
```

## 五、循环系统

### 5.1 心血管系统

心血管系统由心脏和血管组成。

```
心血管系统
        │
        ├─ 心脏
        │   ├─ 左心房：接收肺静脉血
        │   ├─ 左心室：泵血到全身
        │   ├─ 右心房：接收全身静脉血
        │   └─ 右心室：泵血到肺
        │
        ├─ 动脉：将血液从心脏输送到全身
        ├─ 静脉：将血液从全身输送回心脏
        └─ 毛细血管：气体和物质交换
```

### 5.2 血液循环

```
血液循环
        │
        ├─ 体循环
        │   左心室 → 主动脉 → 全身 → 上下腔静脉 → 右心房
        │
        └─ 肺循环
            右心室 → 肺动脉 → 肺 → 肺静脉 → 左心房
```

## 六、泌尿系统

### 6.1 肾脏

肾脏是主要的排泄器官。

```
肾脏结构
        │
        ├─ 肾皮质：外层，含肾小体
        ├─ 肾髓质：内层，含肾小管
        ├─ 肾单位：肾脏的基本功能单位
        │   ├─ 肾小体：过滤血液
        │   └─ 肾小管：重吸收和分泌
        └─ 肾盂：收集尿液
```

### 6.2 尿液生成

```
尿液生成过程
        │
        ├─ 滤过：血液 → 原尿
        ├─ 重吸收：原尿 → 有用物质重吸收
        └─ 分泌：肾小管分泌废物
```

## 七、神经系统

### 7.1 中枢神经系统

中枢神经系统由大脑和脊髓组成。

```
中枢神经系统
        │
        ├─ 大脑
        │   ├─ 大脑皮层：高级功能
        │   ├─ 小脑：协调运动
        │   ├─ 脑干：生命中枢
        │   └─ 间脑：调节内分泌
        │
        └─ 脊髓：传导神经冲动
```

### 7.2 周围神经系统

周围神经系统由脑神经和脊神经组成。

| 神经类型 | 数量 | 功能 |
|----------|------|------|
| 脑神经 | 12对 | 支配头面部 |
| 脊神经 | 31对 | 支配躯干和四肢 |

## 八、生殖系统

### 8.1 男性生殖系统

男性生殖系统由内生殖器和外生殖器组成。

```
男性生殖系统
        │
        ├─ 内生殖器
        │   ├─ 睾丸：产生精子和分泌雄激素
        │   ├─ 附睾：储存和成熟精子
        │   ├─ 输精管：输送精子
        │   ├─ 射精管：将精液排入尿道
        │   ├─ 精囊：分泌精囊液
        │   └─ 前列腺：分泌前列腺液
        │
        └─ 外生殖器
            ├─ 阴茎：排尿和交配器官
            └─ 阴囊：容纳睾丸
```

### 8.2 女性生殖系统

女性生殖系统也分为内、外生殖器。

```
女性生殖系统
        │
        ├─ 内生殖器
        │   ├─ 卵巢：产生卵子和分泌雌激素
        │   ├─ 输卵管：输送卵子
        │   ├─ 子宫：孕育胎儿
        │   └─ 阴道：交配和分娩通道
        │
        └─ 外生殖器
            ├─ 大阴唇
            ├─ 小阴唇
            └─ 阴蒂
```

| 结构 | 功能 |
|------|------|
| 卵巢 | 排卵 + 分泌雌激素/孕激素 |
| 输卵管 | 捕获卵子、受精场所 |
| 子宫 | 胚胎着床、胎儿发育 |
| 阴道 | 性交器官、分娩产道 |

## 九、感觉器官

### 9.1 眼（视觉器官）

```
眼球结构
        │
        ├─ 眼球壁
        │   ├─ 纤维膜：角膜、巩膜
        │   ├─ 血管膜：虹膜、睫状体、脉络膜
        │   └─ 视网膜：感光细胞
        │
        └─ 内容物
            ├─ 房水：营养角膜和晶状体
            ├─ 晶状体：调节焦距
            └─ 玻璃体：维持眼球形状
```

### 9.2 耳（听觉与平衡器官）

```
耳的结构
        │
        ├─ 外耳：耳廓、外耳道 → 收集声波
        ├─ 中耳：鼓膜、听小骨（锤骨-砧骨-镫骨） → 传导振动
        └─ 内耳：耳蜗（听觉）、前庭和半规管（平衡觉）
```

### 9.3 其他感觉器官

| 器官 | 感觉类型 | 结构 |
|------|----------|------|
| 鼻 | 嗅觉 | 嗅上皮→嗅神经 |
| 舌 | 味觉 | 味蕾→酸/甜/苦/咸/鲜 |
| 皮肤 | 触觉、温度觉、痛觉 | 多种感受器 |

## 十、内分泌系统

内分泌系统由内分泌腺和散在的内分泌细胞组成。

```
内分泌系统
        │
        ├─ 下丘脑：分泌释放激素/抑制激素 → 调控垂体
        ├─ 垂体：分泌促激素 → 调控各靶腺
        ├─ 甲状腺：分泌甲状腺激素 → 调节代谢
        ├─ 甲状旁腺：分泌甲状旁腺激素 → 调节血钙
        ├─ 肾上腺：皮质（皮质激素）+ 髓质（肾上腺素）
        ├─ 胰岛：α细胞（胰高血糖素）+ β细胞（胰岛素）
        ├─ 性腺：睾丸（雄激素）+ 卵巢（雌激素/孕激素）
        └─ 松果体：分泌褪黑素 → 调节生物节律
```

| 腺体 | 激素 | 主要作用 |
|------|------|---------|
| 甲状腺 | T3/T4 | 促进代谢、生长发育 |
| 甲状旁腺 | PTH | 升高血钙 |
| 肾上腺皮质 | 皮质醇 | 应激反应、代谢调节 |
| 肾上腺髓质 | 肾上腺素 | 应急反应 |
| 胰岛β细胞 | 胰岛素 | 降低血糖 |
| 胰岛α细胞 | 胰高血糖素 | 升高血糖 |

## 十一、淋巴系统

淋巴系统是循环系统的辅助部分，参与免疫防御。

```
淋巴系统组成
        │
        ├─ 淋巴管道：毛细淋巴管→淋巴管→淋巴干→淋巴导管
        ├─ 淋巴器官
        │   ├─ 淋巴结：过滤淋巴液、免疫应答
        │   ├─ 脾：滤血、免疫、储血
        │   ├─ 胸腺：T淋巴细胞成熟
        │   └─ 扁桃体：防御入口
        └─ 淋巴组织：弥散分布于黏膜
```

## 十二、解剖方位术语

| 术语 | 含义 |
|------|------|
| 前（腹侧）/ 后（背侧） | 前方 / 后方 |
| 上（头侧）/ 下（尾侧） | 靠近头 / 靠近尾 |
| 内侧（medial）/ 外侧（lateral） | 近中线 / 远离中线 |
| 近端（proximal）/ 远端（distal） | 近躯干 / 远离躯干（四肢） |
| 浅（superficial）/ 深（deep） | 近体表 / 远离体表 |

### 解剖平面

| 平面 | 切分方向 |
|------|----------|
| 矢状面（sagittal） | 左右分 |
| 冠状面（coronal） | 前后分 |
| 横断面（transverse） | 上下分（水平切） |

## 总结

解剖学是医学的基础，通过学习人体的形态结构，可以更好地理解人体的生理功能和病理变化。
