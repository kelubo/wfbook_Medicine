# 霜桑叶

[TOC]

## 概述

桑叶为桑科植物桑 *Morus alba* L. 的干燥叶。初霜后采收，除去杂质，晒干，称为"霜桑叶"或"冬桑叶"。全国大部分地区均产，以南方蚕桑区（江苏、浙江、四川等）为主产区。

> 传统认为经霜后的桑叶药力更佳——霜降后采收的桑叶质润而兼收降之性，更宜于清肺润燥。

## 性味归经

- **性味**：甘、苦、寒
- **归经**：肺、肝

## 功效

| 功效 | 应用 |
|------|------|
| **疏散风热** | 风热感冒——发热、咽痛、咳嗽（桑菊饮） |
| **清肺润燥** | 肺热燥咳——干咳无痰或痰少而粘（桑杏汤） |
| **清肝明目** | 肝火上炎——目赤肿痛、头昏眩晕 |
| **平抑肝阳** | 肝阳上亢——头痛眩晕（配合菊花、钩藤） |

## 使用注意

| 注意 | 说明 |
|------|------|
| 用量 | 煎服 5 ~ 10 g |
| 外用 | 煎水洗眼——治疗急性结膜炎（目赤涩痛） |
| 禁忌 | 风寒感冒者不宜 |

## 现代研究

桑叶的主要活性成分：

| 成分 | 作用 |
|------|------|
| 1-脱氧野尻霉素 (DNJ) | **α-葡萄糖苷酶抑制剂**→延缓碳水化合物吸收、降餐后血糖 |
| 黄酮类（芦丁、槲皮素） | 抗氧化、抗炎、保护血管 |
| 桑叶多糖 | 降血糖、免疫调节 |
| γ-氨基丁酸 | 辅助降压、镇静 |

> 桑叶的天然生物碱 DNJ 与降糖药阿卡波糖（拜唐苹）作用机制近同。桑叶泡水/桑叶茶作为辅助降血糖有一定科学依据。

## 桑枝

桑的嫩枝。微苦、平，归肝经。祛风湿、利关节——用于风湿痹痛、肩臂酸痛。

## 桑白皮

桑的干燥根皮。甘、寒，归肺经。泻肺平喘、利水消肿——用于肺热喘咳、水肿。

## 桑椹

桑的果穗。甘酸、寒，归心肝肾经。滋阴补血、生津润燥——用于阴血亏虚所致的发白、失眠。

> 桑一身都是药：叶治肺、枝治关节、皮治水肿、果（桑椹）补肝肾。
