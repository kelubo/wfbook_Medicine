# 生理学

## 概述

生理学是研究人体正常生理功能的科学，包括各器官系统的功能及其调节机制。

---

## 一、细胞生理

### 1.1 细胞膜功能

细胞膜具有物质转运、信号传递等功能。

```
物质转运方式
        │
        ├─ 被动转运
        │   ├─ 单纯扩散：氧气、二氧化碳
        │   └─ 易化扩散：葡萄糖、离子
        │
        ├─ 主动转运
        │   ├─ 原发性主动转运：钠钾泵
        │   └─ 继发性主动转运：葡萄糖协同转运
        │
        └─ 膜泡运输
            ├─ 胞吞：大分子进入细胞
            └─ 胞吐：大分子排出细胞
```

### 1.2 细胞信号转导

细胞通过受体接收和传递信号。

| 受体类型 | 分布 | 作用机制 |
|----------|------|----------|
| 离子通道受体 | 细胞膜 | 离子通道开闭 |
| G蛋白耦联受体 | 细胞膜 | 激活G蛋白 |
| 酶耦联受体 | 细胞膜 | 激活酶活性 |
| 核受体 | 细胞核 | 调节基因表达 |

## 二、神经生理

### 2.1 神经纤维的兴奋传导

神经纤维通过动作电位传导兴奋。

```
动作电位产生过程
        │
        ├─ 静息电位：细胞膜内外电位差
        │   ├─ 钾离子外流
        │   └─ 钠离子内流受阻
        │
        ├─ 去极化：钠离子内流
        │   └─ 电位从负变正
        │
        ├─ 复极化：钾离子外流
        │   └─ 电位恢复静息状态
        │
        └─ 超极化：钾离子持续外流
            └─ 电位低于静息状态
```

### 2.2 突触传递

突触是神经元之间的连接结构。

```
突触传递过程
        │
        ├─ 突触前神经元兴奋
        ├─ 神经递质释放
        ├─ 神经递质与受体结合
        ├─ 突触后神经元兴奋或抑制
        └─ 神经递质失活
```

## 三、肌肉生理

### 3.1 骨骼肌收缩

骨骼肌通过肌丝滑动实现收缩。

```
肌丝滑动学说
        │
        ├─ 肌动蛋白丝和肌球蛋白丝相互滑动
        ├─ 肌球蛋白头部与肌动蛋白结合
        ├─ ATP水解提供能量
        ├─ 肌球蛋白头部摆动
        └─ 肌动蛋白丝向肌节中心滑动
```

### 3.2 肌肉收缩类型

| 收缩类型 | 特点 | 示例 |
|----------|------|------|
| 等长收缩 | 肌肉长度不变，张力增加 | 站立时肌肉收缩 |
| 等张收缩 | 肌肉张力不变，长度缩短 | 举重物时肌肉收缩 |
| 离心收缩 | 肌肉被拉长，张力增加 | 放下重物时肌肉收缩 |

## 四、血液生理

### 4.1 血液组成

血液由血浆和血细胞组成。

```
血液组成
        │
        ├─ 血浆（55%）
        │   ├─ 水（90%）
        │   ├─ 蛋白质：白蛋白、球蛋白、纤维蛋白原
        │   ├─ 电解质：钠、钾、氯
        │   └─ 营养物质：葡萄糖、氨基酸
        │
        └─ 血细胞（45%）
            ├─ 红细胞：运输氧气
            ├─ 白细胞：免疫功能
            └─ 血小板：凝血功能
```

### 4.2 血型系统

```
ABO血型系统
        │
        ├─ A型：红细胞表面有A抗原
        │   └─ 血清中有抗B抗体
        │
        ├─ B型：红细胞表面有B抗原
        │   └─ 血清中有抗A抗体
        │
        ├─ AB型：红细胞表面有A和B抗原
        │   └─ 血清中无抗体
        │
        └─ O型：红细胞表面无A和B抗原
            └─ 血清中有抗A和抗B抗体
```

## 五、循环生理

### 5.1 心脏生理

心脏是血液循环的动力器官。

```
心脏泵血过程
        │
        ├─ 心房收缩期
        │   ├─ 心房收缩
        │   └─ 血液进入心室
        │
        ├─ 心室收缩期
        │   ├─ 心室收缩
        │   ├─ 房室瓣关闭
        │   └─ 血液射入动脉
        │
        └─ 心室舒张期
            ├─ 心室舒张
            ├─ 动脉瓣关闭
            └─ 血液从心房进入心室
```

### 5.2 血压调节

血压通过神经和体液调节维持稳定。

| 调节方式 | 调节机制 |
|----------|----------|
| 神经调节 | 交感神经兴奋升高血压，副交感神经兴奋降低血压 |
| 体液调节 | 肾上腺素升高血压，肾素-血管紧张素系统升高血压 |
| 自身调节 | 血管自身调节血流量 |

## 六、呼吸生理

### 6.1 肺通气

肺通气是气体进出肺的过程。

```
呼吸运动
        │
        ├─ 吸气
        │   ├─ 膈肌收缩下降
        │   ├─ 肋间肌收缩
        │   ├─ 胸腔容积增大
        │   └─ 肺内压降低
        │
        └─ 呼气
            ├─ 膈肌舒张上升
            ├─ 肋间肌舒张
            ├─ 胸腔容积减小
            └─ 肺内压升高
```

### 6.2 气体交换

气体交换发生在肺泡和毛细血管之间。

| 气体 | 分压 | 扩散方向 |
|------|------|----------|
| 氧气 | 肺泡 > 血液 | 肺泡 → 血液 |
| 二氧化碳 | 血液 > 肺泡 | 血液 → 肺泡 |

## 七、消化生理

### 7.1 消化过程

食物通过消化酶分解为小分子物质。

```
消化过程
        │
        ├─ 口腔消化：唾液淀粉酶消化淀粉
        ├─ 胃消化：胃蛋白酶消化蛋白质
        ├─ 小肠消化：胰液和肠液消化糖类、蛋白质、脂肪
        └─ 大肠消化：细菌分解纤维素
```

### 7.2 吸收过程

营养物质通过小肠壁吸收进入血液。

| 营养物质 | 吸收方式 | 吸收部位 |
|----------|----------|----------|
| 葡萄糖 | 主动转运 | 小肠 |
| 氨基酸 | 主动转运 | 小肠 |
| 脂肪 | 被动扩散 | 小肠 |
| 水 | 被动扩散 | 小肠和大肠 |

## 八、排泄生理

### 8.1 肾功能

肾脏通过过滤、重吸收和分泌生成尿液。

```
尿液生成
        │
        ├─ 滤过：血液 → 原尿
        │   ├─ 肾小球过滤
        │   └─ 滤过膜选择性通透
        │
        ├─ 重吸收：原尿 → 有用物质重吸收
        │   ├─ 葡萄糖：全部重吸收
        │   ├─ 水：大部分重吸收
        │   └─ 电解质：按需重吸收
        │
        └─ 分泌：肾小管分泌废物
            ├─ 氢离子
            ├─ 钾离子
            └─ 药物代谢产物
```

### 8.2 尿量调节

尿量通过抗利尿激素调节。

```
抗利尿激素调节
        │
        ├─ 血浆渗透压升高 → 抗利尿激素分泌增加 → 尿量减少
        └─ 血浆渗透压降低 → 抗利尿激素分泌减少 → 尿量增加
```

## 九、感觉生理

### 9.1 视觉

视觉是光线通过眼的屈光系统汇聚到视网膜上形成物像的过程。

```
视觉通路
        │
        ├─ 角膜和晶状体：屈光 → 光线聚焦于视网膜
        ├─ 视网膜：感光细胞（视锥细胞 + 视杆细胞）
        │   ├─ 视锥细胞：明视觉、色觉（红/绿/蓝）
        │   └─ 视杆细胞：暗视觉（对光敏感，无色觉）
        ├─ 视神经：传递视觉信号
        └─ 视觉中枢（枕叶）：整合形成视觉
```

### 9.2 听觉

听觉是将声波振动转化为神经冲动的过程。

```
听觉机制
        │
        ├─ 外耳收集声波 → 鼓膜振动
        ├─ 中耳听小骨（锤→砧→镫）放大振动
        ├─ 内耳耳蜗：柯蒂氏器毛细胞将机械振动转为电信号
        └─ 听神经 → 听觉中枢（颞叶）
```

### 9.3 平衡觉

| 结构 | 感知 | 功能 |
|------|------|------|
| 半规管（3 个） | 角加速度（旋转） | 头部旋转感知 |
| 椭圆囊/球囊 | 直线加速度、重力 | 头部位置和直线运动 |

### 9.4 嗅觉与味觉

| 感觉 | 感受器 | 中枢 |
|------|--------|------|
| 嗅觉 | 嗅上皮→嗅细胞（鼻腔顶部） | 嗅球→边缘系统 |
| 味觉 | 味蕾→酸/甜/苦/咸/鲜 | 脑干→丘脑→岛叶 |

> 嗅觉信号直接进入边缘系统（海马体、杏仁核），因此气味能强烈唤起记忆和情绪。

## 十、内分泌生理

内分泌系统与神经系统共同维持机体稳态。

### 10.1 下丘脑-垂体-靶腺轴

```
下丘脑-垂体-靶腺轴
        │
        ├─ 下丘脑：释放/抑制激素
        │   └─ 门脉系统 → 垂体前叶
        │
        ├─ 垂体
        │   ├─ 前叶（腺垂体）：GH/TSH/ACTH/FSH/LH/PRL
        │   └─ 后叶（神经垂体）：ADH/催产素
        │
        └─ 靶腺
            ├─ 甲状腺（T3/T4）
            ├─ 肾上腺皮质（皮质醇）
            └─ 性腺（雌激素/雄激素）
```

### 10.2 主要激素及其生理功能

| 激素 | 来源 | 靶组织/作用 |
|------|------|-----------|
| 生长激素 (GH) | 垂体前叶 | 促进生长、蛋白质合成 |
| 甲状腺激素 (T3/T4) | 甲状腺 | 基础代谢率升高、促进神经系统发育 |
| 皮质醇 | 肾上腺皮质 | 应激激素；升高血糖；抗炎 |
| 胰岛素 | 胰岛β细胞 | 降低血糖，促进糖原/脂肪/蛋白质合成 |
| 胰高血糖素 | 胰岛α细胞 | 升高血糖，促进糖原分解 |
| 醛固酮 | 肾上腺皮质 | 保钠排钾，升高血压 |
| 抗利尿激素 (ADH) | 垂体后叶 | 促进肾集合管重吸收水 → 尿量减少 |
| 催产素 | 垂体后叶 | 子宫收缩、泌乳反射 |

### 10.3 血糖调节

```
血糖调节
        │
        ├─ 进食 → 血糖升高 → 胰岛素分泌 → 血糖降低
        ├─ 饥饿 → 血糖降低 → 胰高血糖素分泌 → 血糖升高
        └─ 应激 → 肾上腺素/皮质醇 → 血糖升高
```

## 十一、能量代谢与体温调节

### 11.1 基础代谢率 (BMR)

基础代谢率是人体在清醒、安静、空腹状态下的能量消耗速率。

| 影响因素 | 作用 |
|----------|------|
| 甲状腺激素 | 增加 BMR（甲亢 BMR↑，甲减 BMR↓） |
| 年龄 | 随年龄增长 BMR 下降 |
| 性别 | 男性一般高于女性 |
| 体温 | 体温每升高1°C，BMR 增加约 13% |

### 11.2 体温调节

```
体温调节中枢：下丘脑视前区 (PO/AH)

体温调节机制
        │
        ├─ 产热
        │   ├─ 代谢产热（基础代谢、肌肉活动）
        │   ├─ 寒战产热（骨骼肌不自主收缩）
        │   └─ 非寒战产热（棕色脂肪）
        │
        ├─ 散热
        │   ├─ 辐射：热量以红外线形式散发（主要方式）
        │   ├─ 传导：热量直接传递给接触物
        │   ├─ 对流：空气流动带走热量
        │   └─ 蒸发：汗液蒸发带走热量（高温环境下的主要方式）
        │
        └─ 体温范围
            ├─ 正常：36.0 ~ 37.2°C
            ├─ 发热：> 37.3°C
            └─ 低温：< 35.0°C
```

## 总结

生理学研究人体各器官系统的正常功能及其调节机制，是医学的基础学科，为疾病诊断和治疗提供理论依据。
