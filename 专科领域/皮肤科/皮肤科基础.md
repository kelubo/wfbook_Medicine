# 皮肤科基础

## 概述

皮肤科是研究皮肤疾病的诊断、治疗和预防的学科，包括皮肤病、性病和皮肤美容。

---

## 一、皮肤结构与功能

### 1.1 皮肤结构

```
皮肤结构
        │
        ├─ 表皮：最外层，角质层、透明层、颗粒层、棘层、基底层
        ├─ 真皮：中间层，胶原蛋白、弹性纤维
        ├─ 皮下组织：最内层，脂肪组织
        └─ 附属器官：毛发、皮脂腺、汗腺、指甲
```

### 1.2 皮肤功能

```
皮肤功能
        │
        ├─ 保护功能：保护身体免受外界伤害
        ├─ 感觉功能：触觉、痛觉、温度觉
        ├─ 调节体温：出汗、血管收缩和扩张
        ├─ 分泌功能：分泌汗液和皮脂
        ├─ 排泄功能：排泄代谢废物
        └─ 免疫功能：皮肤免疫系统
```

## 二、常见皮肤病

### 2.1 感染性皮肤病

```
感染性皮肤病
        │
        ├─ 细菌感染：脓疱疮、毛囊炎、蜂窝织炎
        │   ├─ 脓疱疮：金黄色葡萄球菌感染，水疱和脓疱
        │   ├─ 毛囊炎：毛囊细菌感染，红色丘疹
        │   └─ 蜂窝织炎：皮下组织感染，红肿热痛
        │
        ├─ 真菌感染：手足癣、体癣、股癣、甲癣
        │   ├─ 手足癣：皮肤癣菌感染，瘙痒和脱屑
        │   ├─ 体癣：圆形红斑，边界清晰
        │   ├─ 股癣：腹股沟区域真菌感染
        │   └─ 甲癣：指甲真菌感染，指甲增厚变色
        │
        └─ 病毒感染：带状疱疹、单纯疱疹、疣
            ├─ 带状疱疹：水痘-带状疱疹病毒，沿神经分布的水疱和疼痛
            ├─ 单纯疱疹：单纯疱疹病毒，口唇或生殖器疱疹
            └─ 疣：人乳头瘤病毒，皮肤赘生物
```

### 2.2 过敏性皮肤病

```
过敏性皮肤病
        │
        ├─ 湿疹：皮肤炎症，红斑、丘疹、水疱、瘙痒
        │   ├─ 急性湿疹：红斑、水疱、渗出
        │   ├─ 亚急性湿疹：红斑、丘疹、鳞屑
        │   └─ 慢性湿疹：皮肤增厚、苔藓样变
        │
        ├─ 接触性皮炎：皮肤接触过敏原后炎症
        │   ├─ 刺激性接触性皮炎：接触刺激物
        │   └─ 过敏性接触性皮炎：接触过敏原
        │
        ├─ 荨麻疹：风团和瘙痒，急性和慢性
        │   ├─ 急性荨麻疹：突然发作，24小时内消退
        │   └─ 慢性荨麻疹：反复发作超过6周
        │
        └─ 药疹：药物引起的皮肤反应
            ├─ 麻疹样药疹：类似麻疹的皮疹
            ├─ 猩红热样药疹：类似猩红热的皮疹
            └─ 剥脱性皮炎：严重的皮肤剥脱
```

### 2.3 炎症性皮肤病

```
炎症性皮肤病
        │
        ├─ 银屑病：红斑、鳞屑，银白色鳞屑
        │   ├─ 寻常型银屑病：最常见，红斑和银白色鳞屑
        │   ├─ 关节型银屑病：伴有关节炎
        │   ├─ 脓疱型银屑病：脓疱
        │   └─ 红皮病型银屑病：全身皮肤发红
        │
        ├─ 玫瑰痤疮：面部潮红、丘疹、脓疱
        │
        ├─ 扁平苔藓：紫红色扁平丘疹
        │
        └─ 红斑狼疮：自身免疫性疾病，面部蝶形红斑
```

### 2.4 皮肤肿瘤

```
皮肤肿瘤
        │
        ├─ 良性肿瘤：色素痣、血管瘤、脂肪瘤
        │   ├─ 色素痣：黑色素细胞良性增生
        │   ├─ 血管瘤：血管良性增生
        │   └─ 脂肪瘤：脂肪组织良性增生
        │
        └─ 恶性肿瘤：基底细胞癌、鳞状细胞癌、黑色素瘤
            ├─ 基底细胞癌：最常见，溃疡和结节
            ├─ 鳞状细胞癌：红色斑块和溃疡
            └─ 黑色素瘤：恶性程度高，色素不均的痣
```

## 三、皮肤病诊断

### 3.1 诊断方法

```
皮肤病诊断方法
        │
        ├─ 病史采集：发病时间、症状、诱因、既往病史
        ├─ 体格检查：皮疹形态、颜色、分布、大小
        ├─ 皮肤镜检查：放大观察皮肤病变
        ├─ 真菌镜检和培养：诊断真菌感染
        ├─ 皮肤活检：病理检查
        └─ 过敏原检测：斑贴试验、血液检测
```

### 3.2 皮疹描述

```
皮疹描述要素
        │
        ├─ 形态：斑疹、丘疹、水疱、脓疱、结节、溃疡
        ├─ 颜色：红色、粉红色、紫色、褐色、黑色
        ├─ 分布：对称分布、单侧分布、局限性、全身性
        ├─ 大小：直径、面积
        ├─ 数量：单个、多个
        └─ 伴随症状：瘙痒、疼痛、灼热感
```

## 四、皮肤病治疗

### 4.1 外用药物

```
外用药物分类
        │
        ├─ 糖皮质激素：抗炎、抗过敏
        │   ├─ 弱效：氢化可的松
        │   ├─ 中效：糠酸莫米松
        │   └─ 强效：卤米松
        │
        ├─ 抗真菌药物：克霉唑、咪康唑、特比萘芬
        ├─ 抗生素：莫匹罗星、红霉素
        ├─ 抗病毒药物：阿昔洛韦、喷昔洛韦
        ├─ 角质溶解剂：水杨酸、尿素
        └─ 保湿剂：凡士林、尿素软膏
```

### 4.2 口服药物

```
口服药物分类
        │
        ├─ 抗组胺药：氯雷他定、西替利嗪、依巴斯汀
        ├─ 糖皮质激素：泼尼松、地塞米松
        ├─ 免疫抑制剂：环孢素、甲氨蝶呤
        ├─ 抗生素：青霉素、头孢、四环素
        ├─ 抗病毒药物：阿昔洛韦、伐昔洛韦
        └─ 维A酸类：异维A酸、阿维A
```

### 4.3 物理治疗

```
物理治疗方法
        │
        ├─ 紫外线照射：治疗银屑病、白癜风
        ├─ 激光治疗：治疗血管性疾病、色素性疾病
        ├─ 冷冻治疗：治疗疣、良性肿瘤
        ├─ 光动力治疗：治疗痤疮、皮肤肿瘤
        └─ 电疗：治疗疣、皮肤肿瘤
```

## 五、皮肤护理

```
皮肤护理原则
        │
        ├─ 清洁：温和清洁，避免过度清洁
        ├─ 保湿：使用保湿剂保持皮肤滋润
        ├─ 防晒：避免紫外线照射
        ├─ 避免刺激：避免搔抓和摩擦
        ├─ 饮食调理：避免辛辣刺激食物
        └─ 规律作息：保证充足睡眠
```

---

## 总结

皮肤科涵盖多种皮肤疾病，通过准确诊断和合理治疗，可以有效控制和治愈大多数皮肤病。皮肤护理对于预防和辅助治疗皮肤病也非常重要。
