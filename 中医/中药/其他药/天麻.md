# 天麻

[TOC]

## 概述

天麻为兰科植物天麻 *Gastrodia elata* Bl. 的干燥块茎。主产于云南、四川、贵州、湖北、陕西等地。立冬后至次年清明前采挖，冬季采者名"冬麻"（质优），春季采者名"春麻"。

> 天麻是兰科植物，没有根和叶，不能进行光合作用，是一种与蜜环菌共生的异养植物。古人称其"有风不动，无风自摇"，故名"定风草"。

## 性味归经

- **性味**：甘、平
- **归经**：肝

## 功效

| 功效 | 应用 |
|------|------|
| **息风止痉** | 肝风内动——小儿急慢惊风、癫痫抽搐、破伤风 |
| **平抑肝阳** | 肝阳上亢——高血压所致头痛、眩晕 |
| **祛风通络** | 风湿痹痛、肢体麻木、中风后遗症半身不遂 |

## 使用注意

| 注意项 | 说明 |
|--------|------|
| 用量 | 煎服 3 ~ 9 g。研末冲服每次 1 ~ 1.5 g |
| 禁忌 | 气血虚弱者慎用（《本经》曰久服益气力，但以风证为主） |

## 现代研究

| 成分 | 作用 |
|------|------|
| 天麻素 (Gastrodin) | 镇静、抗惊厥、改善脑循环 |
| 天麻苷元 (对羟基苯甲醇) | 神经保护、改善学习记忆 |
| 天麻多糖 | 免疫调节、抗衰老 |

主要药理作用：① 镇静、抗惊厥；② 增加脑血流量、改善微循环；③ 降血压；④ 抗眩晕、改善前庭功能；⑤ 神经保护。

## 道地产区与品质鉴别

| 指标 | 优质特征 |
|------|---------|
| 产地 | 云南昭通、贵州毕节（乌天麻最优） |
| 外观 | 质地坚实沉重、有鹦哥嘴（顶端红棕色芽苞） |
| 断面 | 角质样、半透明——断面黄白不空心 |
| 气味 | 气特异（马尿味）、味甘 |
| 等级 | 冬麻 > 春麻（冬麻肥厚饱满、春麻空虚有皱） |

> 野生天麻价格昂贵，现多为蜜环菌伴栽的人工培养品。
