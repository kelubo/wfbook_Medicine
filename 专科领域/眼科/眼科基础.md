# 眼科基础

## 概述

眼科是研究眼部疾病的诊断、治疗和预防的学科，包括眼表疾病、眼底疾病、屈光不正等。

---

## 一、眼的结构

### 1.1 眼球结构

```
眼球结构
        │
        ├─ 眼球壁
        │   ├─ 外层：角膜、巩膜
        │   ├─ 中层：虹膜、睫状体、脉络膜
        │   └─ 内层：视网膜
        │
        ├─ 眼内容物
        │   ├─ 房水：维持眼压
        │   ├─ 晶状体：调节焦距
        │   └─ 玻璃体：支撑眼球
        │
        └─ 附属器官：眼睑、结膜、泪器、眼外肌
```

### 1.2 视觉系统

```
视觉系统
        │
        ├─ 光线进入：角膜→瞳孔→晶状体→玻璃体→视网膜
        ├─ 感光细胞：视锥细胞（彩色视觉）、视杆细胞（黑白视觉）
        ├─ 信号传递：视网膜→视神经→视交叉→视束→大脑视觉中枢
        └─ 视觉形成：大脑处理视觉信号
```

## 二、屈光不正

### 2.1 屈光不正类型

```
屈光不正类型
        │
        ├─ 近视：光线聚焦在视网膜前方
        │   ├─ 症状：看远处模糊，看近处清晰
        │   ├─ 分类：轻度近视、中度近视、高度近视
        │   └─ 矫正：凹透镜
        │
        ├─ 远视：光线聚焦在视网膜后方
        │   ├─ 症状：看近处模糊，看远处清晰
        │   ├─ 分类：轻度远视、中度远视、高度远视
        │   └─ 矫正：凸透镜
        │
        ├─ 散光：光线不能聚焦在同一点
        │   ├─ 症状：视物模糊、重影
        │   ├─ 分类：近视散光、远视散光、混合散光
        │   └─ 矫正：柱镜
        │
        └─ 老视：年龄相关的调节能力下降
            ├─ 症状：看近处困难
            ├─ 年龄：40岁以上
            └─ 矫正：凸透镜
```

### 2.2 屈光检查

```
屈光检查方法
        │
        ├─ 视力检查：标准视力表
        ├─ 验光：客观验光、主观验光
        ├─ 角膜曲率测量：角膜曲率计
        └─ 眼压测量：眼压计
```

### 2.3 矫正方式

```
矫正方式
        │
        ├─ 框架眼镜：最常见的矫正方式
        ├─ 隐形眼镜：直接贴在角膜上
        │   ├─ 软性隐形眼镜：舒适
        │   └─ 硬性隐形眼镜：透氧性好
        └─ 屈光手术：激光手术、ICL植入
            ├─ LASIK：准分子激光原位角膜磨镶术
            ├─ PRK：准分子激光角膜切削术
            ├─ SMILE：飞秒激光小切口透镜取出术
            └─ ICL：有晶体眼人工晶体植入术
```

## 三、眼表疾病

### 3.1 结膜炎

```
结膜炎分类
        │
        ├─ 细菌性结膜炎：细菌感染，脓性分泌物
        │   ├─ 症状：眼红、分泌物增多、异物感
        │   └─ 治疗：抗生素滴眼液
        │
        ├─ 病毒性结膜炎：病毒感染，水样分泌物
        │   ├─ 症状：眼红、水样分泌物、眼痛
        │   └─ 治疗：抗病毒滴眼液
        │
        ├─ 过敏性结膜炎：过敏反应
        │   ├─ 症状：眼痒、眼红、流泪
        │   └─ 治疗：抗过敏滴眼液
        │
        └─ 干眼症：泪液分泌不足或蒸发过快
            ├─ 症状：眼干、异物感、烧灼感
            └─ 治疗：人工泪液、抗炎滴眼液
```

### 3.2 角膜炎

```
角膜炎特点
        │
        ├─ 病因：细菌、病毒、真菌、外伤
        │   ├─ 细菌性角膜炎：脓性分泌物、角膜溃疡
        │   ├─ 病毒性角膜炎：树枝状角膜病变
        │   ├─ 真菌性角膜炎：角膜浸润、溃疡
        │   └─ 外伤相关性角膜炎：角膜划伤
        ├─ 症状：眼痛、畏光、流泪、视力下降
        └─ 治疗：抗感染、抗炎、角膜移植
```

## 四、白内障

```
白内障特点
        │
        ├─ 病因：晶状体混浊
        │   ├─ 年龄相关性白内障：最常见
        │   ├─ 先天性白内障：出生时存在
        │   ├─ 外伤性白内障：外伤引起
        │   └─ 并发性白内障：其他眼病引起
        │
        ├─ 症状：视力模糊、畏光、复视、颜色改变
        │
        ├─ 分期：初发期、膨胀期、成熟期、过熟期
        │
        └─ 治疗：手术治疗
            ├─ 超声乳化白内障吸除术
            └─ 人工晶体植入术
```

## 五、青光眼

```
青光眼分类
        │
        ├─ 原发性青光眼
        │   ├─ 原发性开角型青光眼：眼压升高，房角开放
        │   │   ├─ 症状：早期无症状，晚期视力下降
        │   │   └─ 治疗：药物、激光、手术
        │   │
        │   └─ 原发性闭角型青光眼：眼压急剧升高，房角关闭
        │       ├─ 症状：眼痛、头痛、恶心、呕吐
        │       └─ 治疗：药物降眼压，手术治疗
        │
        ├─ 继发性青光眼：其他疾病引起
        │
        └─ 先天性青光眼：出生时存在
```

### 青光眼检查

```
青光眼检查方法
        │
        ├─ 眼压测量：眼压计
        ├─ 房角检查：房角镜
        ├─ 视野检查：视野计
        ├─ 视神经检查：眼底检查、OCT
        └─ 视盘检查：评估视神经损伤
```

## 六、眼底疾病

### 6.1 糖尿病视网膜病变

```
糖尿病视网膜病变特点
        │
        ├─ 病因：糖尿病引起的视网膜微血管病变
        │   ├─ 非增殖期：微血管瘤、出血、渗出
        │   ├─ 增殖期：新生血管、玻璃体出血、视网膜脱离
        │   └─ 黄斑水肿：影响中心视力
        │
        ├─ 筛查：定期眼底检查
        ├─ 治疗：控制血糖、激光治疗、抗VEGF药物、手术
        └─ 预防：控制血糖、血压、血脂
```

### 6.2 年龄相关性黄斑变性

```
年龄相关性黄斑变性特点
        │
        ├─ 病因：黄斑区退行性变
        │   ├─ 干性黄斑变性：黄斑区萎缩
        │   └─ 湿性黄斑变性：脉络膜新生血管
        │
        ├─ 症状：中心视力下降、视物变形、暗点
        ├─ 检查：眼底检查、OCT、眼底荧光血管造影
        └─ 治疗：抗VEGF药物、激光治疗
```

### 6.3 视网膜脱离

```
视网膜脱离特点
        │
        ├─ 病因：视网膜神经上皮与色素上皮分离
        │   ├─ 孔源性视网膜脱离：视网膜裂孔
        │   ├─ 牵拉性视网膜脱离：玻璃体牵拉
        │   └─ 渗出性视网膜脱离：炎症或肿瘤
        │
        ├─ 症状：眼前黑影、闪光感、视力下降
        ├─ 检查：眼底检查、眼部超声
        └─ 治疗：手术治疗（巩膜扣带术、玻璃体切割术）
```

## 七、眼科检查

```
眼科检查方法
        │
        ├─ 视力检查：标准视力表
        ├─ 眼压测量：眼压计
        ├─ 眼底检查：眼底镜、眼底照相
        ├─ 视野检查：视野计
        ├─ OCT检查：光学相干断层扫描
        ├─ 角膜检查：角膜地形图、角膜内皮镜
        ├─ 房角检查：房角镜
        └─ 眼底荧光血管造影：评估视网膜血管
```

---

## 总结

眼科涵盖多种眼部疾病，通过准确诊断和合理治疗，可以有效保护和恢复视力。定期眼部检查对于早期发现和预防眼部疾病非常重要。
