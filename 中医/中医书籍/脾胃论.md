# 脾胃论

[TOC]

## 简介

《脾胃论》是金代著名医家**李杲**（李东垣，号东垣，1180—1251）的代表作，成书于 1249 年。全书 3 卷，系统阐述了"**内伤脾胃、百病由生**"的学术思想。

> 李东垣是金元四大家中"补土派"的开创者。因时值金元之际，连年战乱，百姓饥饱无定，脾胃内伤所致疾病非常多见，东垣因此创补中益气法。

## 金元四大家

| 医家 | 派别 | 核心观点 |
|------|:---:|------|
| 刘完素 | **寒凉派** | 六气皆从火化——善用寒凉 |

## 核心学术思想

### 一、脾胃为元气之本

> 真气又名元气，乃先身生之精气也。非胃气不能滋之。

元气（生命的根本能量）依靠脾胃运化水谷精微来滋养。脾胃一旦受损，元气失去营养来源，百病由此而生。

### 二、内伤与外感的鉴别

东垣在《内外伤辨惑论》（《脾胃论》的姊妹篇）中详辨内伤与外感：

| | 内伤（脾胃虚弱） | 外感（风寒袭表） |
|---|---|---|
| 发热 | 手心热、午后热甚 | 手背热、发热恶寒 |
| 脉 | 虚大或洪大而虚 | 浮紧/浮数 |
| 神志 | 倦怠懒言、昏沉 | 身重疼痛而精神尚可 |
| 口渴 | 口淡不欲饮或渴不欲多饮 | 口渴欲饮 |
| 恶寒 | 得衣被即减 | 虽复衣被不减 |

### 三、升降浮沉理论

脾胃为气机升降枢纽——脾升则健，胃降则安。若脾胃虚弱，清阳不升则头晕耳鸣、久泻脱肛；浊阴不降则腹胀痞满。

## 补中益气汤

东垣的招牌方：

| 药物 | 作用 |
|------|------|
| **黄芪**（君） | 大补脾肺之气 |
| 人参、白术、甘草 | 补气健脾（四君子去茯苓） |
| 陈皮 | 理气——使补而不滞 |
| 升麻、柴胡 | 升举清阳之气（"提气"） |
| 当归 | 养血和营 |

主治：① 脾胃气虚——少气懒言、四肢倦怠；② 气虚发热——身热自汗、渴喜热饮；③ 中气下陷——脱肛、子宫下垂、久泻久痢。

## 代表方剂

| 方剂 | 主治 |
|------|------|
| **补中益气汤** | 脾胃气虚、气虚发热、中气下陷 |
| 升阳益胃汤 | 脾胃虚弱兼夹湿邪 |
| 补脾胃泻阴火升阳汤 | 脾胃虚弱+湿热 |
| 清暑益气汤 | 暑湿耗伤脾胃之气阴 |

## 历史影响

1. 首创"内伤学说"——在外感六淫之外，为内科疾病提供了新视角
2. 确立了益气升阳法——黄芪+升麻+柴胡的配伍成为"提气"的经典模式
3. 开创了"脾胃论"——脾胃为后天之本的思想从此深入中医体系
4. 补中益气汤至今是最畅销的中成药之一
