# 医学入门

[TOC]

## 简介

《医学入门》是明代**李梴**（字健斋，约 16 世纪末）编纂的综合性中医入门教材，成书于万历三年（1575 年）。全书 9 卷，以**歌诀**+**注解**的形式编写，是针对初学者设计的中医启蒙读物。

## 内容结构

| 卷次 | 内容 |
|:---:|------|
| 卷一 | 医学略论（总纲）—阴阳、五行、脏腑、经络、病因、诊法 |
| 卷二 | 本草（药物分类歌诀） |
| 卷三 | 伤寒、温疫 |
| 卷四 ~ 五 | 内科杂病各论 |
| 卷六 | 妇人、小儿 |
| 卷七 | 口齿、咽喉、眼目 |
| 卷八 | 外科 |
| 卷九 | 针灸、运气 |

## 特点

1. **歌诀**：将核心知识编成韵文便于记诵——"医学入门，先读歌诀"
2. 内容精简涵盖面广——相当于一部小型的临床全书
3. 注重实用——药量和治法给出具体参考

## 影响

《医学入门》在明清时期流传甚广。直至近代仍为中医入门的首选读物之一。日本汉方医学界也有极高的评价，被视为理解中医临床思维的重要参考。
