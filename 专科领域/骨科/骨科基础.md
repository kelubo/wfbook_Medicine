# 骨科基础

## 概述

骨科是研究骨骼、关节、肌肉等运动系统疾病的诊断、治疗和预防的学科。

---

## 一、骨骼系统

### 1.1 骨骼结构

```
骨骼结构
        │
        ├─ 骨膜：覆盖在骨骼表面
        ├─ 骨质：骨密质和骨松质
        ├─ 骨髓：红骨髓和黄骨髓
        └─ 关节：连接骨骼的结构
```

### 1.2 骨骼功能

```
骨骼功能
        │
        ├─ 支持功能：支撑身体
        ├─ 保护功能：保护内脏器官
        ├─ 运动功能：与肌肉配合产生运动
        ├─ 造血功能：红骨髓造血
        └─ 储存功能：储存钙和磷
```

---

## 二、骨折

### 2.1 骨折分类

```
骨折分类
        │
        ├─ 按部位分：上肢骨折、下肢骨折、脊柱骨折
        │
        ├─ 按程度分：不完全骨折、完全骨折
        │   ├─ 不完全骨折：裂缝骨折、青枝骨折
        │   └─ 完全骨折：横形骨折、斜形骨折、螺旋形骨折
        │
        ├─ 按移位分：移位骨折、无移位骨折
        │
        └─ 按稳定性分：稳定骨折、不稳定骨折
```

### 2.2 骨折愈合

```
骨折愈合过程
        │
        ├─ 血肿形成期：骨折后出血形成血肿
        ├─ 纤维软骨痂形成期：血肿机化形成纤维软骨痂
        ├─ 骨痂形成期：软骨痂钙化形成骨痂
        └─ 骨骼重塑期：骨痂重塑成正常骨骼
```

### 2.3 骨折治疗

```
骨折治疗原则
        │
        ├─ 复位：恢复骨骼正常位置
        │   ├─ 手法复位：通过手法复位
        │   └─ 手术复位：通过手术复位
        │
        ├─ 固定：保持复位后的位置
        │   ├─ 外固定：石膏固定、夹板固定
        │   └─ 内固定：钢板、螺钉、髓内钉
        │
        └─ 康复：恢复关节功能和肌肉力量
```

## 三、关节疾病

### 3.1 骨关节炎

```
骨关节炎特点
        │
        ├─ 病因：关节软骨磨损和退行性变
        ├─ 症状：关节疼痛、僵硬、肿胀、活动受限
        ├─ 常见部位：膝关节、髋关节、手指关节
        └─ 治疗：药物治疗、物理治疗、手术治疗
```

### 3.2 类风湿关节炎

```
类风湿关节炎特点
        │
        ├─ 病因：自身免疫性疾病
        │   ├─ 对称性关节肿痛
        │   ├─ 晨僵持续至少1小时
        │   ├─ 类风湿因子阳性
        │   └─ 关节畸形
        ├─ 治疗：非甾体抗炎药、改善病情抗风湿药、生物制剂
        └─ 关节置换：严重关节损伤时
```

### 3.3 强直性脊柱炎

```
强直性脊柱炎特点
        │
        ├─ 病因：自身免疫性疾病
        ├─ 症状：下腰背痛、脊柱僵硬、骶髂关节炎
        ├─ 影像学：骶髂关节炎、脊柱竹节样改变
        └─ 治疗：非甾体抗炎药、物理治疗、生物制剂
```

---

## 四、关节置换手术

### 4.1 髋关节置换

```
髋关节置换手术
        │
        ├─ 适应证：严重髋关节骨关节炎、股骨头坏死
        ├─ 手术方式：全髋关节置换、半髋关节置换
        ├─ 假体类型：金属对聚乙烯、陶瓷对陶瓷
        └─ 术后康复：早期活动、康复训练
```

### 4.2 膝关节置换

```
膝关节置换手术
        │
        ├─ 适应证：严重膝关节骨关节炎
        ├─ 手术方式：全膝关节置换、单髁置换
        ├─ 假体类型：固定平台、活动平台
        └─ 术后康复：膝关节活动训练、肌肉力量训练
```

---

## 五、脊柱疾病

### 5.1 颈椎病

```
颈椎病类型
        │
        ├─ 颈型颈椎病：颈部疼痛和僵硬
        ├─ 神经根型颈椎病：上肢麻木和疼痛
        ├─ 脊髓型颈椎病：四肢无力和行走困难
        ├─ 椎动脉型颈椎病：头晕和眩晕
        └─ 交感神经型颈椎病：心慌、胸闷、出汗
```

### 5.2 腰椎间盘突出症

```
腰椎间盘突出症特点
        │
        ├─ 病因：椎间盘退变和突出
        ├─ 症状：腰痛、下肢放射痛、麻木、无力
        ├─ 体征：直腿抬高试验阳性
        ├─ 影像学：CT或MRI显示椎间盘突出
        └─ 治疗：保守治疗、手术治疗
```

### 5.3 脊柱骨折

```
脊柱骨折分类
        │
        ├─ 颈椎骨折：高位截瘫风险
        ├─ 胸椎骨折：可能影响呼吸
        ├─ 腰椎骨折：可能影响下肢功能
        └─ 治疗：保守治疗、手术治疗
```

## 六、运动损伤

### 6.1 肩袖损伤

```
肩袖损伤特点
        │
        ├─ 病因：肩关节反复活动导致肌腱损伤
        ├─ 症状：肩部疼痛、无力、活动受限
        ├─ 体征：疼痛弧试验阳性
        ├─ 影像学：MRI显示肩袖撕裂
        └─ 治疗：保守治疗、手术修复
```

### 6.2 半月板损伤

```
半月板损伤特点
        │
        ├─ 病因：膝关节扭转导致半月板撕裂
        ├─ 症状：膝关节疼痛、肿胀、交锁
        ├─ 体征：麦氏征阳性
        ├─ 影像学：MRI显示半月板损伤
        └─ 治疗：保守治疗、关节镜手术
```

### 6.3 交叉韧带损伤

```
交叉韧带损伤特点
        │
        ├─ 前交叉韧带损伤：膝关节前向不稳定
        │   ├─ 症状：膝关节肿胀、疼痛、不稳
        │   ├─ 体征：抽屉试验阳性
        │   └─ 治疗：关节镜下交叉韧带重建
        │
        └─ 后交叉韧带损伤：膝关节后向不稳定
            ├─ 症状：膝关节肿胀、疼痛、不稳
            ├─ 体征：后抽屉试验阳性
            └─ 治疗：保守治疗或手术重建
```

---

## 七、骨科检查

```
骨科检查方法
        │
        ├─ 体格检查：视诊、触诊、叩诊、动诊
        ├─ X线检查：骨折、骨关节炎、脱位
        ├─ CT检查：复杂骨折、脊柱病变
        ├─ MRI检查：软组织损伤、椎间盘病变
        ├─ 关节镜检查：关节内部检查和治疗
        └─ 骨密度检查：骨质疏松诊断
```

---

## 八、骨科康复

```
骨科康复原则
        │
        ├─ 早期康复：术后早期开始康复训练
        ├─ 循序渐进：逐渐增加训练强度
        ├─ 个体化：根据患者情况制定康复计划
        ├─ 综合康复：结合物理治疗和运动训练
        └─ 长期坚持：长期康复训练
```

---

## 总结

骨科涵盖骨骼、关节和肌肉系统的疾病，通过准确诊断和合理治疗，可以有效恢复患者的运动功能。康复训练对于骨科疾病的恢复非常重要。
