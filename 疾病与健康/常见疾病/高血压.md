# 高血压

## 概述

高血压 (Hypertension) 是以体循环动脉血压持续升高为主要表现的临床综合征。原发性高血压占 90% 以上，是心脑血管疾病最重要的危险因素。

> 中国成人高血压患病率约 27.9%，知晓率、治疗率、控制率偏低。

---

## 一、诊断标准与分级

### 1.1 诊室血压分级（成人）

| 分类 | 收缩压 (SBP) | 舒张压 (DBP) |
|:-----|:---:|:---:|
| 正常血压 | < 120 | < 80 |
| 正常高值 | 120 ~ 139 | 80 ~ 89 |
| 高血压 1 级（轻度） | 140 ~ 159 | 90 ~ 99 |
| 高血压 2 级（中度） | 160 ~ 179 | 100 ~ 109 |
| 高血压 3 级（重度） | ≥ 180 | ≥ 110 |
| 单纯收缩期高血压 | ≥ 140 | < 90 |

> 诊室血压需非同日在安静状态下测量 3 次以上均超标方可诊断。

### 1.2 诊断方式

```
血压测量方式
        │
        ├─ 诊室血压：≥ 140/90 mmHg → 诊断标准
        ├─ 动态血压监测 (ABPM)
        │   ├─ 24h 平均 ≥ 130/80 mmHg
        │   └─ 可排除白大衣高血压、发现隐匿性高血压
        └─ 家庭自测血压：≥ 135/85 mmHg
```

## 二、分型

### 2.1 原发性与继发性

```
高血压分型
        │
        ├─ 原发性高血压（占 90%+）
        │   ├─ 原因不明，多因素综合作用
        │   └─ 危险因素：遗传、高盐饮食、肥胖、饮酒、精神紧张
        │
        └─ 继发性高血压（占 5~10%）
            ├─ 肾实质性：急慢性肾小球肾炎
            ├─ 肾血管性：肾动脉狭窄
            ├─ 内分泌性：原发性醛固酮增多症、嗜铬细胞瘤、库欣综合征
            ├─ 药物性：口服避孕药、NSAIDs、甘草
            └─ 睡眠呼吸暂停综合征
```

## 三、病理生理机制

```
血压 = 心排出量 × 外周阻力

高血压发生机制
        │
        ├─ 交感神经活性升高：心率加快、血管收缩
        ├─ RAAS 激活（肾素-血管紧张素-醛固酮系统）
        │   └─ 血管紧张素Ⅱ → 强烈缩血管 + 醛固酮 → 水钠潴留
        ├─ 钠盐摄入过多 → 水钠潴留 → 容量负荷增加
        ├─ 血管内皮功能障碍 → 舒张因子(NO)减少
        └─ 胰岛素抵抗 → 代偿性高胰岛素 → 交感兴奋 + 水钠潴留
```

## 四、靶器官损害

长期高血压对各器官的损害：

```
靶器官损害
        │
        ├─ 心脏
        │   ├─ 左心室肥厚 → 舒张功能不全
        │   ├─ 冠心病、心肌梗死
        │   └─ 心力衰竭（高心病）
        │
        ├─ 脑
        │   ├─ 脑卒中（脑出血、脑梗死）
        │   ├─ 短暂性脑缺血发作 (TIA)
        │   └─ 高血压脑病
        │
        ├─ 肾脏
        │   ├─ 良性肾小动脉硬化 → 肾功能不全
        │   └─ 恶性高血压 → 急进性肾衰竭
        │
        ├─ 血管
        │   ├─ 动脉粥样硬化加速
        │   └─ 主动脉夹层（最危急）
        │
        └─ 眼
            └─ 高血压视网膜病变
```

## 五、治疗

### 5.1 降压目标

| 人群 | 降压目标 |
|:-----|:---:|
| 一般高血压患者 | < 140/90 mmHg |
| 耐受者（能进一步降低） | < 130/80 mmHg |
| 老年（65~79 岁） | < 140/90 mmHg |
| 高龄（≥80 岁） | < 150/90 mmHg |
| 合并糖尿病/肾病/冠心病 | < 130/80 mmHg |

### 5.2 非药物治疗（生活方式干预）

```
生活方式干预
        │
        ├─ 低盐饮食：每日食盐 < 5g（约一啤酒瓶盖）
        ├─ 控制体重：BMI < 24
        ├─ 规律运动：每周 ≥ 150 分钟中等强度
        ├─ 戒烟限酒
        ├─ 合理膳食：DASH 饮食（富钾、富钙、低脂）
        └─ 心理健康：减少精神压力
```

### 5.3 药物治疗

| 类别 | 代表药 | 机制 | 适用人群 |
|------|--------|------|---------|
| 钙通道阻滞剂 (CCB) | 氨氯地平、硝苯地平 | 阻断钙内流 → 血管舒张 | 老年、单纯收缩期、卒中 |
| ACEI | 依那普利、培哚普利 | 抑制 AngⅡ 生成 | 心衰、心梗后、肾病（干咳副作用） |
| ARB | 缬沙坦、氯沙坦 | 阻断 AngⅡ 受体 | 同 ACEI（无干咳） |
| 利尿剂 | 氢氯噻嗪、吲达帕胺 | 排钠利尿 → 减少血容量 | 老年、心力衰竭 |
| β 受体阻滞剂 | 美托洛尔、比索洛尔 | 减慢心率、减少心肌耗氧 | 冠心病、心衰、快速心律失常 |

### 5.4 联合用药原则

- 大多数患者需要 ≥ 2 种药物联合治疗
- 优先选择单片复方制剂 (SPC) 以提高依从性
- 常用组合：ACEI/ARB + CCB、ACEI/ARB + 利尿剂、CCB + β-blocker

## 六、高血压急症

| 类型 | 特征 | 处理 |
|------|------|------|
| 高血压急症 (Hypertensive Emergency) | BP≥180/120 + 靶器官进行性损害 | 静脉用药、监护下降压 |
| 高血压亚急症 (Urgency) | BP 显著升高但无急性靶器官损害 | 口服短效降压药观察24~48h |

---

## 七、预防

- 定期测量血压（18 岁以上每年至少 1 次）
- 限制钠盐摄入是最经济有效的预防措施
- 超重者减轻体重 10kg 可使收缩压降低 5~20 mmHg
