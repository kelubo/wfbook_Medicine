# 中医妇科

## 概述

中医妇科是研究妇科疾病辨证论治的学科，涵盖月经病、带下病、妊娠病、产后病等。

---

## 一、月经病

### 1.1 月经不调

```
月经不调辨证论治
        │
        ├─ 肝郁气滞
        │   ├─ 症状：月经先后无定期、乳房胀痛
        │   ├─ 治法：疏肝理气调经
        │   └─ 方药：逍遥散
        │
        ├─ 肾虚
        │   ├─ 症状：月经推迟、量少色淡
        │   ├─ 治法：补肾调经
        │   └─ 方药：归肾丸

        ├─ 血虚
        │   ├─ 症状：月经推迟、量少色淡
        │   ├─ 治法：补血调经

        └─ 血热
```

## 总结

中医妇科通过辨证论治治疗各种妇科疾病，强调调理气血、肝肾和冲任，根据不同的病因和证型采用不同的治疗方法。
