# 中医内科

## 概述

中医内科是研究内科疾病辨证论治的学科，涵盖呼吸、循环、消化、泌尿等系统疾病。

---

## 一、呼吸系统疾病

### 1.1 感冒

```
感冒辨证论治
        │
        ├─ 风寒感冒
        │   ├─ 症状：恶寒发热、无汗、鼻塞流清涕
        │   ├─ 治法：辛温解表
        │   └─ 方药：麻黄汤、桂枝汤

        ├─ 风热感冒

        │   └─ 方药：银翘散、桑菊饮
```

## 总结

中医内科通过辨证论治治疗各种内科疾病，强调整体观念和辨证论治，根据不同的病因和证型采用不同的治疗方法。
