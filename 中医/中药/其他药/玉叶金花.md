# 玉叶金花

[TOC]

## 概述

玉叶金花为茜草科植物玉叶金花 *Mussaenda pubescens* Ait. f. 的干燥全株。主产于广东、广西、福建、江西等地。

> 又名"白纸扇"、"凉茶藤"——因其顶生花序外围的一片小叶呈白色，远望如白纸扇或白玉叶托金花（黄色花冠）而得名。广东凉茶中常见使用。

## 性味归经

- **性味**：甘、淡、凉
- **归经**：肺、脾、膀胱

## 功效

| 功效 | 应用 |
|------|------|
| **清热利湿** | 感冒发热、暑湿吐泻、湿热黄疸 |
| **解毒消肿** | 咽喉肿痛、痈疮肿毒、蛇虫咬伤（外敷） |
| **利尿通淋** | 小便不利、泌尿道感染 |

## 使用注意

| 注意 | 说明 |
|------|------|
| 用量 | 煎服 15 ~ 30 g（鲜品加倍） |
| 外用 | 鲜品捣烂敷患处 |
| 禁忌 | 虚寒体质、脾胃虚寒者慎用（药性偏凉） |

## 现代研究

玉叶金花含三萜皂苷、环烯醚萜苷类化合物和黄酮类成分，具有：

| 作用 | 相关成分 |
|------|---------|
| 抗炎 | 齐墩果酸型三萜皂苷 |
| 解热 | 总提取物 |
| 抗菌 | 对金黄色葡萄球菌有抑制作用 |

> 在两广地区民间凉茶（如"王老吉""廿四味"等配方中）常见玉叶金花的使用。但现代系统中缺乏高质量的药理和临床研究，属于民间中草药范畴。
