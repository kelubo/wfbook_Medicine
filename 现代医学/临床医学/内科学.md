# 内科学

## 概述

内科学是临床医学的核心学科，研究人体内部器官的疾病诊断和治疗。

---

## 一、呼吸系统疾病

### 1.1 肺炎

```
肺炎分类
        │
        ├─ 按病因分：细菌性、病毒性、真菌性、支原体肺炎
        │
        ├─ 按解剖分：大叶性、小叶性、间质性肺炎
        │
        └─ 按获得方式分：社区获得性、医院获得性肺炎
```

### 1.2 慢性阻塞性肺疾病

```
COPD特点
        │
        ├─ 慢性支气管炎：咳嗽、咳痰持续3个月以上，连续2年
        ├─ 肺气肿：肺泡过度充气，桶状胸
        ├─ 症状：慢性咳嗽、咳痰、气短
        └─ 治疗：戒烟、支气管舒张剂、氧疗、康复治疗
```

### 1.3 哮喘

```
哮喘特点
        │
        ├─ 气道慢性炎症：气道高反应性
        ├─ 症状：喘息、咳嗽、胸闷、呼吸困难
        ├─ 发作特点：突发突止
        └─ 治疗：吸入糖皮质激素、支气管舒张剂、避免过敏原
```

## 二、心血管系统疾病

### 2.1 高血压

```
高血压分类
        │
        ├─ 原发性高血压：原因不明，占90%-95%
        ├─ 继发性高血压：由其他疾病引起
        │   ├─ 肾性高血压
        │   ├─ 内分泌性高血压
        │   └─ 血管性高血压
        └─ 治疗：非药物治疗+药物治疗
```

### 2.2 冠心病

```
冠心病类型
        │
        ├─ 无症状性心肌缺血
        ├─ 心绞痛：稳定型、不稳定型
        ├─ 心肌梗死：ST段抬高型、非ST段抬高型
        └─ 缺血性心肌病
```

### 2.3 心力衰竭

```
心力衰竭分类
        │
        ├─ 按部位分：左心衰竭、右心衰竭、全心衰竭
        ├─ 按功能分：收缩性、舒张性心力衰竭
        └─ 按程度分：NYHA分级Ⅰ-Ⅳ级
```

## 三、消化系统疾病

### 3.1 胃炎

```
胃炎分类
        │
        ├─ 急性胃炎：急性单纯性、急性糜烂出血性胃炎
        └─ 慢性胃炎：慢性浅表性、慢性萎缩性胃炎
```

### 3.2 消化性溃疡

```
消化性溃疡特点
        │
        ├─ 胃溃疡：餐后半小时至1小时疼痛，胃窦部
        ├─ 十二指肠溃疡：空腹或夜间疼痛，十二指肠球部
        └─ 并发症：出血、穿孔、幽门梗阻、癌变
```

### 3.3 肝硬化

```
肝硬化病因
        │
        ├─ 病毒性肝炎：乙肝、丙肝
        ├─ 酒精性肝病：长期大量饮酒
        ├─ 非酒精性脂肪肝：肥胖、高血脂
        ├─ 自身免疫性肝病
        └─ 药物性肝损伤
```

## 四、泌尿系统疾病

### 4.1 肾小球疾病

```
肾小球疾病类型
        │
        ├─ 急性肾小球肾炎：链球菌感染后
        ├─ 慢性肾小球肾炎：长期存在
        ├─ 肾病综合征：大量蛋白尿、低蛋白血症、水肿、高脂血症
        └─ IgA肾病：最常见的原发性肾小球疾病
```

### 4.2 尿路感染

```
尿路感染分类
        │
        ├─ 膀胱炎：尿频、尿急、尿痛
        ├─ 肾盂肾炎：发热、腰痛、尿频尿急尿痛
        └─ 无症状菌尿：无症状，尿常规异常
```

---

## 五、血液系统疾病

### 5.1 贫血

```
贫血分类
        │
        ├─ 缺铁性贫血：铁摄入不足或丢失过多
        ├─ 巨幼细胞性贫血：维生素B12或叶酸缺乏
        ├─ 再生障碍性贫血：骨髓造血功能衰竭
        ├─ 溶血性贫血：红细胞破坏过多
        └─ 地中海贫血：遗传性贫血
```

### 5.2 白血病

```
白血病分类
        │
        ├─ 急性白血病：急性淋巴细胞白血病、急性髓系白血病
        └─ 慢性白血病：慢性粒细胞白血病、慢性淋巴细胞白血病
```

## 六、内分泌系统疾病

### 6.1 糖尿病

```
糖尿病分类
        │
        ├─ 1型糖尿病：胰岛素绝对缺乏，青少年多见
        ├─ 2型糖尿病：胰岛素抵抗和分泌相对不足，中老年人多见
        └─ 妊娠期糖尿病：妊娠期间发生
```

### 6.2 甲状腺疾病

```
甲状腺疾病分类
        │
        ├─ 甲状腺功能亢进：甲亢，甲状腺激素过多
        │   ├─ 弥漫性毒性甲状腺肿（Graves病）
        │   ├─ 症状：心悸、手抖、体重减轻、突眼
        │   └─ 治疗：抗甲状腺药物、放射性碘、手术
        │
        └─ 甲状腺功能减退：甲减，甲状腺激素不足
            ├─ 症状：乏力、怕冷、体重增加、便秘
            └─ 治疗：甲状腺激素替代治疗
```

## 七、神经系统疾病

### 7.1 脑血管疾病

```
脑血管疾病分类
        │
        ├─ 缺血性脑血管疾病：脑梗死
        │   ├─ 脑血栓形成：动脉粥样硬化
        │   ├─ 脑栓塞：栓子堵塞血管
        │   └─ 短暂性脑缺血发作：短暂脑缺血
        │
        └─ 出血性脑血管疾病：脑出血、蛛网膜下腔出血
```

### 7.2 帕金森病

```
帕金森病特点
        │
        ├─ 病因：黑质多巴胺神经元变性
        ├─ 症状：静止性震颤、肌强直、运动迟缓、姿势异常
        └─ 治疗：左旋多巴、多巴胺受体激动剂
```

---

## 八、风湿免疫系统疾病

### 8.1 类风湿关节炎

```
类风湿关节炎特点
        │
        ├─ 病因：自身免疫性疾病
        ├─ 症状：对称性关节肿痛、晨僵
        ├─ 关节畸形：手指天鹅颈畸形
        └─ 治疗：非甾体抗炎药、改善病情抗风湿药、生物制剂
```

### 8.2 系统性红斑狼疮

```
系统性红斑狼疮特点
        │
        ├─ 病因：自身免疫性疾病
        ├─ 症状：面部蝶形红斑、发热、关节痛
        ├─ 累及器官：皮肤、关节、肾脏、心脏、肺
        └─ 治疗：糖皮质激素、免疫抑制剂
```

---

## 总结

内科学涵盖多个系统的疾病，是临床医学的核心学科。通过系统学习和临床实践，可以掌握各种疾病的诊断和治疗方法。
