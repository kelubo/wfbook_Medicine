# 难经

[TOC]

## 简介

《难经》原名《黄帝八十一难经》，托名秦越人（扁鹊）所著，实际成书约在东汉（公元 1 世纪前后）。全书以设问设答方式（八十一难），对《内经》中疑难和有争议之处加以阐发。

## 核心内容

| 篇段 | 问难 | 核心贡献 |
|------|------|---------|
| 一难 ~ 二十二难 | 脉学 | **独取寸口**（腕部桡动脉），奠定了切脉标准 |
| 二十三难 ~ 二十九难 | 经络 | 奇经八脉的系统论述 |
| 三十难 ~ 四十七难 | 脏腑 | 三焦、命门之论 |
| 四十八难 ~ 六十一难 | 疾病诊候 | 四诊（望闻问切）规范 |
| 六十二难 ~ 六十八难 | 特定腧穴 | 五腧穴（井荥输经合）的理论 |
| 六十九难 ~ 八十一难 | 针刺方法 | 补泻手法和四时刺法 |

## 代表性贡献

### 独取寸口

第一难明确提出了"**独取寸口**"的切脉方法——仅按腕部桡动脉的寸口脉，分为寸、关、尺三部对应脏腑：

| 三部 | 左手 | 右手 |
|:---:|------|------|
| 寸 | 心/小肠 | 肺/大肠 |
| 关 | 肝/胆 | 脾/胃 |
| 尺 | 肾/膀胱 | 命门/三焦 |

### 命门学说（三十六难、三十九难）

提出左肾为肾、右肾为**命门**——"诸神精之所舍，原气之所系"。为后世命门学说的源头。

### 三焦有名无形

二十五难提出"三焦有名无形"——三焦是一个功能概念而非具体解剖器官。

## 历史地位

1. 中医四大经典之一（与《内经》《伤寒杂病论》《本经》并列）
2. 系统化、条理化地解决了《内经》中的疑难不定问题
3. 奠定了脉学基础（独取寸口沿用至今）
4. 为奇经八脉、命门、三焦等概念提供了基本框架
