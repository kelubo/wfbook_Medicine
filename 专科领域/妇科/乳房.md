## 一、数值与趣闻

乳房的平均重量是500克左右（单侧），其中填充的脂肪量占了身体总脂肪量的4% ~ 5% 。

与阴茎相似，性唤起时乳房也会胀大，乳头会变得坚挺，长度会比平时增加0.5 ~ 1cm，而基底部直径会增加 0.25 ~ 0.5cm 。

在美国，2010年女性的平均罩杯是36C，而在15年前，是34B。在澳大利亚和新西兰，高达40%的女性购买的胸罩罩杯在D或以上。包括中国和日本在内的亚洲、非洲诸多国家，女性平均罩杯仅为A。英国女性以34E的平均罩杯，夺下了全球罩杯尺寸之冠。

早在公元前7世纪，就出现了类似胸罩的服饰，不过直到20世纪30年代，胸罩才开始大规模生产。

有5%的新生儿会在出生2个月内分泌乳汁，被称为新生儿乳，不论男女都可能发生。

## 二、黄金三角点和黄金法则

黄金三角点：正面，等边三角形（左乳头 + 右乳头 + 锁骨中间的凹陷）

侧面：乳头的位置正好位于上臂的1/2处（由手臂侧面测量获得）。

## 三、乳房解剖

```
乳房结构
        │
        ├─ 皮肤与乳头乳晕
        │   ├─ 乳头：含 15~20 个输乳管开口
        │   └─ 乳晕：含蒙哥马利腺（分泌润滑液）
        │
        ├─ 乳腺组织
        │   ├─ 乳腺叶（15~20 个）：呈放射状排列
        │   ├─ 乳腺小叶：基本分泌单位
        │   └─ 输乳管：从小叶汇合至乳头开口
        │
        ├─ 悬韧带 (Cooper 韧带)
        │   └─ 连接皮肤与深筋膜——萎缩致乳房下垂
        │
        └─ 脂肪组织
            └─ 决定乳房大小和形状
```

### 乳腺发育

| 时期 | 变化 |
|------|------|
| 出生 | 男女皆有新生儿乳（母体激素影响） |
| 青春期 | 雌激素 → 导管增生；孕激素 → 腺泡发育 |
| 孕期 | 腺泡大量增殖，准备泌乳 |
| 哺乳期 | 催乳素驱动 → 分泌乳汁 |
| 绝经后 | 腺体萎缩、脂肪替代 |

## 四、常见乳房疾病

### 4.1 乳腺增生

```
乳腺增生特点
        │
        ├─ 本质：乳腺导管和腺泡的良性增生
        ├─ 症状：经前乳房胀痛 ± 结节感，月经后缓解
        ├─ 病因：雌/孕激素比例失调
        ├─ 检查：乳腺超声——排除实性肿块
        ├─ 治疗：对症止痛、中药疏肝理气（逍遥散）
        └─ 预后：绝大多数为良性——但需定期随访
```

### 4.2 乳腺纤维腺瘤

| 项目 | 内容 |
|------|------|
| 人群 | 20~30 岁年轻女性最常见 |
| 特征 | 质韧、光滑、活动度好——"乳腺中的弹珠" |
| 治疗 | 观察随访 or 手术切除（> 2 cm 或快速增长） |

### 4.3 乳腺炎

```
乳腺炎
        │
        ├─ 急性化脓性乳腺炎
        │   ├─ 好发：哺乳期（尤其初产妇产后 3~4 周）
        │   ├─ 病因：乳汁淤积 + 细菌入侵（多为金葡菌）
        │   ├─ 症状：红肿热痛 + 发热
        │   └─ 治疗：排空乳汁 + 抗生素；脓肿 → 穿刺引流
        │
        └─ 浆细胞性乳腺炎（非哺乳期）
            ├─ 无菌性炎症——导管扩张
            └─ 易被误诊为乳腺癌
```

### 4.4 乳腺癌

| 项目 | 内容 |
|------|------|
| 流行病学 | 女性恶性肿瘤第一位 |
| 好发部位 | 外上象限（约 50%） |
| 危险因素 | 初潮早/绝经晚、未哺乳、BRCA1/2 突变、家族史 |
| 常见病理 | 浸润性导管癌（占 80%） |
| 典型体征 | 无痛性质硬固定肿块 + 皮肤橘皮样变 + 乳头内陷 |

**分子分型**：

| 亚型 | 标志物 | 预后 |
|:---|:---|:---:|
| Luminal A | ER+/PR+/HER2-/Ki-67 低 | 最好 |
| Luminal B | ER+/HER2±/Ki-67 高 | 中等 |
| HER2 过表达 | ER-/PR-/HER2+ | 较差（但靶向药改善显著） |
| 三阴性 | ER-/PR-/HER2- | 最差 |

**治疗模式**：

```
乳腺癌综合治疗
        │
        ├─ 手术：保乳术 + 前哨淋巴结活检（早期标准）
        ├─ 放疗：术后辅助
        ├─ 化疗：蒽环类 + 紫杉类
        ├─ 内分泌治疗：ER+ 者——他莫昔芬 / 芳香化酶抑制剂（5~10 年）
        ├─ 靶向治疗：HER2+ 者——曲妥珠单抗（赫赛汀）
        └─ 免疫治疗：三阴性乳腺癌（PD-L1 阳性）
```

## 五、乳腺筛查与自检

### 5.1 筛查策略

| 年龄段 | 方法 | 频率 |
|:---|:---|:---|
| 20~39 岁 | 乳腺超声 | 每 1~3 年 |
| 40~69 岁 | **钼靶 (X 线摄影)** + 超声 | 每 1~2 年 |
| BRCA 突变/高危 | MRI | 每年（自 25 岁起） |

### 5.2 乳房自检（每月一次）

```
自检时机：月经来潮后 7~10 天（绝经后固定日期）

自检步骤
        │
        ├─ 视诊
        │   ├─ 镜前观察：双侧是否对称、有无皮肤凹陷/橘皮样变
        │   ├─ 乳头有无内陷、溢液
        │   └─ 双臂上举 → 再叉腰 → 观察变化
        │
        └─ 触诊
            ├─ 仰卧位，肩下垫小枕
            ├─ 指腹（非指尖）以打圈方式由外向内
            ├─ 覆盖整个乳房 + 腋窝淋巴结
            └─ 轻挤乳头——观察有无溢液
```

### 5.3 危险信号（需立即就医）

| 信号 | 可能意义 |
|------|---------|
| 无痛性质硬肿块、固定不动 | 乳腺癌警示 |
| 皮肤凹陷、橘皮样改变 | 肿瘤牵拉 Cooper 韧带 |
| 乳头内陷（新出现） | 导管受侵 |
| 乳头血性溢液 | 导管内乳头状瘤/癌 |
| 腋窝淋巴结肿大 | 淋巴转移 |

## 六、中医对乳房的认识

| 经络 | 循行 | 病理 |
|------|------|------|
| 足阳明胃经 | 贯穿乳房正中 | 胃热 → 乳痈 |
| 足厥阴肝经 | 绕乳头 | 肝郁气滞 → 乳癖（乳腺增生） |
| 冲任二脉 | 调节乳房发育与泌乳 | 冲任失调 → 乳房胀痛、肿块 |

```
中医乳房病辨证
        │
        ├─ 肝郁气滞型：经前乳胀、烦躁、肿块随周期变化 → 逍遥散
        ├─ 痰瘀互结型：肿块质韧、固定不移 → 血府逐瘀汤 + 消瘰丸
        ├─ 冲任失调型：月经紊乱 + 乳腺增生 → 二仙汤
        └─ 正虚毒蕴型：乳腺癌晚期 → 扶正祛邪并举
```

## 总结

乳房健康关乎每一位女性。定期自检 + 影像学筛查是早期发现疾病的关键。中西医结合：西医精准诊断与综合治疗 + 中医辨证调理内分泌与情志。
