# 圣济总录

[TOC]

## 简介

《圣济总录》是宋代继《太平圣惠方》之后的又一部大型官修医学全书，由宋徽宗赵佶敕令编纂，成书于政和年间（1111—1118）。全书共 200 卷，分 66 门，载方约 20000 首，是中国古代收方最多的医书之一。

> 书名"圣济"取意"帝王以仁政惠济天下苍生"。宋徽宗本人喜好医学并对编撰有所指导。

## 内容结构

| 门类 | 卷次 | 重点 |
|------|:---:|------|
| 运气 | 卷一 ~ 二 | 五运六气（宋徽宗非常重视运气学说） |
| 诸风、诸痹 | 卷五 ~ 二十 | 神经系统及风湿类疾病 |
| 伤寒 | 卷二十一 ~ 三十三 | 外感病 |
| 中焦脏腑 | 卷三十四 ~ 五十四 | 脾胃肠道疾病 |
| 泄痢、诸虫 | 卷七十四 ~ 七十九 | 下利及寄生虫 |
| 虚劳 | 卷八十八 ~ 九十二 | 虚损类疾病 |
| 眼目口齿 | 卷一百〇二 ~ 一二四 | 五官科 |
| 妇科、小儿 | 卷一百五十 ~ 一七四 | 妇儿各科 |
| 疮肿金创 | 卷一百三十 ~ 一四三 | 外科 |
| 针灸门 | 卷一九一 ~ 一九四 | 单独设立针灸门 |

## 特点

1. **运气学说**冠首——彰显宋代运气理论在官方医学中的重要地位
2. 载方约 2 万首，多于《太平圣惠方》——其中许多是宋元时期新创方
3. 每种疾病均先论病因病机，再列方药
4. 重视外科——有单独金创、疮肿门

## 版本

《圣济总录》完成后即遭靖康之难（1127），书板被金人掠走。南宋时期反而不得见——国内主要靠金、元翻刻本流传。日本有《圣济总录》古抄本。

---

## 书名误认澄清

"圣济"并非指"圣人之济（助）"，而是取自宋徽宗御制序中的"使圣人之道广济天下"之意——即用医道（圣人之道）广济天下百姓。
