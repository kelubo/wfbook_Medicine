# 慢性阻塞性肺疾病与支气管哮喘

## 一、慢性阻塞性肺疾病 (COPD)

### 1.1 概述

慢性阻塞性肺疾病 (COPD) 是一种以持续性气流受限为特征的慢性气道疾病，气流受限不完全可逆、呈进行性发展。

> COPD 是全球第三大死因，中国 40 岁以上人群患病率约 13.7%。吸烟是最主要的病因。

### 1.2 病因与病理

```
COPD 病因
        │
        ├─ 吸烟：占 80%+，烟龄越长，风险越高
        ├─ 职业粉尘和化学物质
        ├─ 室内外空气污染（如生物燃料）
        ├─ 遗传因素：α1-抗胰蛋白酶缺乏（罕见）
        └─ 反复呼吸道感染
```

**病理改变**：
- 慢性支气管炎：气道黏液腺增生、炎症浸润 → 咳嗽咳痰
- 肺气肿：肺泡壁破坏 → 肺泡腔扩大 → 弹性回缩力下降 → 呼气困难

### 1.3 临床表现

| 症状 | 特点 |
|------|------|
| **慢性咳嗽** | 晨起明显，每年 ≥ 3 个月，连续 ≥ 2 年 |
| **咳痰** | 白色黏液或浆液性泡沫痰 |
| **呼吸困难** | 渐进性——初为劳力性，后静息也出现 |
| **喘息和胸闷** | 非特异性 |

**体征**：
- 桶状胸（肺过度充气）
- 呼吸音减弱
- 呼气相延长

### 1.4 诊断

| 标准 | 说明 |
|------|------|
| 危险因素 | 吸烟史、职业暴露等 |
| 症状 | 慢性咳嗽咳痰 + 呼吸困难 |
| **肺功能（金标准）** | 吸入支气管舒张剂后 **FEV₁/FVC < 0.70** |

### 1.5 病情评估

| GOLD 分级 | FEV₁ 占预计值% |
|:---:|:---:|
| GOLD 1（轻度） | ≥ 80% |
| GOLD 2（中度） | 50% ~ 79% |
| GOLD 3（重度） | 30% ~ 49% |
| GOLD 4（极重度） | < 30% |

### 1.6 治疗

```
COPD 稳定期治疗
        │
        ├─ 戒烟：唯一能延缓 FEV₁ 下降的干预
        ├─ 支气管舒张剂（基础用药）
        │   ├─ 短效：沙丁胺醇 (SABA)、异丙托溴铵 (SAMA)
        │   └─ 长效：LABA（沙美特罗）+ LAMA（噻托溴铵）
        ├─ 吸入糖皮质激素 (ICS)：反复急性加重者
        ├─ 三联疗法：ICS + LABA + LAMA
        ├─ 氧疗：静息 PaO₂ ≤ 55 mmHg 时需长期家庭氧疗（≥ 15h/天）
        ├─ 肺康复：运动训练、营养支持
        └─ 疫苗：流感疫苗、肺炎疫苗
```

| 急性加重标志 | 处理 |
|-------------|------|
| 呼吸困难加重 | 增加支气管舒张剂使用 |
| 痰量增加或变为脓性 | 抗生素（符合 Anthonisen 标准） |
| 严重者 | 口服/静脉糖皮质激素 → 无创通气 → 有创通气 |

## 二、支气管哮喘

### 2.1 概述

支气管哮喘是一种以慢性气道炎症和气道高反应性为特征的异质性疾病，表现为反复发作的喘息、气促、胸闷和咳嗽。

> 本质：慢性过敏性炎症 ≠ 感染性炎症（因此抗生素无效！）

### 2.2 病因与触发因素

```
哮喘触发因素
        │
        ├─ 过敏原：尘螨、花粉、宠物皮屑、霉菌
        ├─ 感染：病毒性上呼吸道感染（最常见诱因之一）
        ├─ 运动：运动诱发支气管收缩
        ├─ 药物：阿司匹林、β-blockers
        ├─ 环境：冷空气、烟雾、刺激性气味
        └─ 情绪：精神紧张、焦虑
```

### 2.3 病理生理

```
哮喘发病机制
        │
        ├─ 变应原进入气道
        ├─ Th2 细胞激活 → IL-4/IL-5/IL-13 释放
        ├─ IgE 生成增加 → 肥大细胞致敏
        ├─ 再次接触抗原 → 肥大细胞脱颗粒
        │   └─ 组胺、白三烯、前列腺素释放
        └─ 结果
            ├─ 支气管平滑肌痉挛（可逆）
            ├─ 黏膜水肿
            ├─ 黏液分泌增加
            └─ 气道重塑（长期不可逆）
```

### 2.4 临床表现

| 特征 | 描述 |
|------|------|
| 发作性 | 症状突发突止 |
| 可逆性 | 可自行缓解或用药缓解 |
| 季节性/时间性 | 夜间/凌晨多发 |
| 诱因相关 | 特定触发因素后发作 |

**哮鸣音的临床意义**：
- 双肺弥漫性哮鸣音——发作期典型体征
- **寂静胸**——极其危险！气道严重堵塞，气体无法进出

### 2.5 诊断

| 标准 | 内容 |
|------|------|
| 典型症状+体征 | 反复发作喘息、双肺哮鸣音 |
| **可变气流受限**（至少 1 项） | ① 支气管舒张试验阳性（FEV₁ 增加 >12% 且 >200mL）② PEF 昼夜变异率 >10% ③ 激发试验阳性 |
| 排除其他疾病 | COPD、心源性哮喘等 |

### 2.6 COPD 与哮喘的鉴别

| | COPD | 哮喘 |
|:---|------|------|
| 起病年龄 | > 40 岁 | 多为儿童/青少年 |
| 吸烟史 | 几乎都有 | 无关 |
| 气流受限 | 不完全可逆 | 完全可逆 |
| 症状 | 渐进性、持续 | 发作性、间歇 |
| 过敏史 | 多无 | 常有 |
| 炎症细胞 | 中性粒细胞为主 | 嗜酸性粒细胞为主 |

### 2.7 治疗

```
哮喘阶梯治疗（GINA 方案）
        │
        ├─ Step 1：按需低剂量 ICS-福莫特罗
        ├─ Step 2：低剂量 ICS 维持
        ├─ Step 3：低剂量 ICS-LABA
        ├─ Step 4：中剂量 ICS-LABA
        └─ Step 5：高剂量 ICS-LABA + LAMA + 生物制剂
            ↕ 每3个月评估一次，升/降阶梯
```

**急性发作处理**：
1. SABA（沙丁胺醇）吸入——每 20 分钟 1 次，共 3 次
2. 口服糖皮质激素（泼尼松片）
3. 氧疗（目标 SpO₂ 93~95%）
4. 严重者 → 急诊、无创通气
