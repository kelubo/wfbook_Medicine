# 糖尿病

## 概述

糖尿病 (Diabetes Mellitus) 是以慢性高血糖为特征的代谢性疾病，由胰岛素分泌缺陷和/或胰岛素作用障碍引起。

> 中国成人糖尿病患病率约 11.2%，是全球糖尿病患者最多的国家。

---

## 一、分型

### 1.1 主要类型

```
糖尿病的分型
        │
        ├─ 1 型糖尿病 (T1DM)
        │   ├─ 病因：自身免疫破坏胰岛 β 细胞
        │   ├─ 特点：胰岛素绝对缺乏
        │   ├─ 发病年龄：多为青少年
        │   └─ 治疗：必须终身注射胰岛素
        │
        ├─ 2 型糖尿病 (T2DM)
        │   ├─ 病因：胰岛素抵抗 + 胰岛素分泌相对不足
        │   ├─ 特点：起病隐匿，与肥胖、生活方式密切相关
        │   ├─ 发病年龄：多为中老年（但日趋年轻化）
        │   └─ 治疗：生活方式干预 + 口服降糖药 ± 胰岛素
        │
        ├─ 妊娠期糖尿病 (GDM)
        │   └─ 妊娠期首次发现的糖代谢异常
        │
        └─ 特殊类型糖尿病
            ├─ 遗传性 β 细胞功能缺陷
            └─ 继发性：胰腺炎、药物等
```

| 特征 | 1 型 | 2 型 |
|------|------|------|
| 占比 | ~5% | ~90% |
| 胰岛素 | 绝对缺乏 | 相对不足+抵抗 |
| 酮症倾向 | 易发生 | 较少 |
| 体型 | 多消瘦 | 多肥胖 |
| 自身抗体 | 阳性 | 阴性 |

---

## 二、诊断标准

| 指标 | 正常 | 糖尿病前期 | 糖尿病 |
|:-----|:---:|:--------:|:---:|
| 空腹血糖 (FPG) | < 6.1 | 6.1 ~ 7.0 | ≥ 7.0 mmol/L |
| 餐后 2h 血糖 (2hPG) | < 7.8 | 7.8 ~ 11.1 | ≥ 11.1 mmol/L |
| 糖化血红蛋白 (HbA1c) | < 5.7% | 5.7 ~ 6.5% | ≥ 6.5% |

> 满足上述任一标准并复查确认，即可诊断糖尿病。

---

## 三、临床表现

### 3.1 典型症状

```
典型"三多一少"
        │
        ├─ 多饮：血糖升高→渗透性利尿→脱水→口渴
        ├─ 多尿：高血糖超过肾糖阈→糖尿→渗透性利尿
        ├─ 多食：胰岛素不足→细胞不能利用葡萄糖→饥饿
        └─ 体重减轻：脂肪和蛋白质分解增加
```

### 3.2 2 型糖尿病的隐匿性

2 型糖尿病起病隐匿，很多患者长期无明显症状，常在体检或因并发症就诊时才被发现。

---

## 四、并发症

### 4.1 急性并发症

| 并发症 | 常见于 | 临床特征 |
|--------|:---:|------|
| 糖尿病酮症酸中毒 (DKA) | T1DM | 高血糖+酮体+代谢性酸中毒 |
| 高渗高血糖状态 (HHS) | T2DM | 极度高血糖 (≥33.3 mmol/L)、无酮症 |
| 低血糖 | 降糖治疗过量 | 血糖<3.9 mmol/L、出汗/心慌/昏迷 |

### 4.2 慢性并发症

```
慢性并发症（长期高血糖损伤血管和神经）
        │
        ├─ 微血管病变
        │   ├─ 糖尿病视网膜病变：致盲主要原因之一
        │   ├─ 糖尿病肾病：终末期肾病的主要原因
        │   └─ 糖尿病神经病变：对称性远端感觉异常
        │
        └─ 大血管病变
            ├─ 冠心病、心肌梗死
            ├─ 脑卒中
            └─ 下肢动脉病变 → 糖尿病足 → 截肢
```

| 并发症 | 筛查建议 |
|--------|---------|
| 视网膜病变 | 每年眼底检查 |
| 肾病 | 每年查尿微量白蛋白 |
| 神经病变 | 每年足部检查 |
| 心血管 | 定期 ECG、血脂 |

---

## 五、治疗

### 5.1 治疗目标

控制血糖，预防和延缓并发症，提高生活质量。

| 指标 | 目标值 |
|:-----|:---:|
| HbA1c | < 7.0%（个体化） |
| 空腹血糖 | 4.4 ~ 7.0 mmol/L |
| 餐后 2h 血糖 | < 10.0 mmol/L |

### 5.2 治疗"五驾马车"

```
糖尿病综合管理
        │
        ├─ 饮食治疗：控制总热量、合理分配三大营养素
        ├─ 运动治疗：每周 ≥ 150 分钟中等强度有氧运动
        ├─ 药物治疗：口服降糖药 ± 胰岛素
        ├─ 血糖监测：自我血糖监测 + 定期 HbA1c
        └─ 健康教育：提高自我管理能力
```

### 5.3 药物治疗

| 类别 | 代表药 | 机制 |
|------|--------|------|
| 双胍类 | 二甲双胍 | 改善胰岛素抵抗（一线首选） |
| 磺脲类 | 格列美脲 | 促进胰岛素分泌 |
| DPP-4 抑制剂 | 西格列汀 | 抑制 GLP-1 降解 |
| SGLT-2 抑制剂 | 达格列净 | 促进尿糖排泄（有心肾保护） |
| GLP-1 受体激动剂 | 利拉鲁肽 | 促进胰岛素分泌+抑制食欲（减重） |
| 胰岛素 | 基础/餐时 | 补充外源性胰岛素 |

---

## 六、预防

```
糖尿病三级预防
        │
        ├─ 一级预防：控制体重、健康饮食、规律运动 → 防止发病
        ├─ 二级预防：早筛查、早诊断 → 防止并发症
        └─ 三级预防：规范治疗 → 延缓并发症进展
```
