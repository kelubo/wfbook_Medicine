## 学习路线

### 中医学习路线

```
中医基础理论
        │
        ├─ 中医理论体系 → 阴阳五行 → 脏腑经络 → 气血津液
        │
        ├─ 中医诊断学 → 中医治疗学
        │
        └─ 中医专科
            ├─ 中医内科：呼吸、循环、消化、泌尿、神经系统疾病
            ├─ 中医外科：疮疡、皮肤病、肛肠疾病、乳房疾病
            ├─ 中医妇科：月经病、带下病、妊娠病、产后病
            └─ 中医儿科：新生儿疾病、呼吸道疾病、消化道疾病
```

### 现代医学学习路线

```
基础医学
        │
        ├─ 解剖学 → 生理学 → 病理学 → 药理学
        │
        ├─ 临床医学
        │   ├─ 内科学：呼吸、心血管、消化系统疾病
        │   └─ 外科学：外科基础、普通外科、骨科、泌尿外科
        │
        ├─ 辅助医学
        │   ├─ 医学影像学：影像技术、报告解读
        │   └─ 检验医学：血液检验、生化检验、免疫检验
        │
        └─ 专科领域
            ├─ 皮肤科：皮肤疾病诊断和治疗
            ├─ 骨科：骨骼系统疾病
            ├─ 眼科：眼部疾病
            └─ 耳鼻喉科：耳、鼻、咽喉疾病
```

### 疾病与健康学习路线

```
常见疾病
        │
        ├─ 慢性病：糖尿病、高血压
        │
        ├─ 心血管疾病：冠心病、心律失常、心力衰竭
        │
        ├─ 呼吸系统疾病：肺炎、COPD、哮喘、肺癌
        │
        ├─ 消化系统疾病：胃炎、消化性溃疡、肝硬化、胰腺炎
        │
        └─ 健康管理
            ├─ 营养学：营养素、健康饮食
            ├─ 运动医学：运动类型、运动处方、运动损伤
            └─ 心理健康：心理问题、心理治疗
```
